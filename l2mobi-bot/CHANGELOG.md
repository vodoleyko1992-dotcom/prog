# L2Mobi Bot — история версий

## 1.0 — 16.11.2026
Первая версия для l2mobi.pro.
- Автофарм: моб со страницы «Мир», умения по откату, обычная атака, сбор добычи.
- Выбор моба по уровню, чёрный список, «только белые имена».
- Отдых по HP/MP или «Полное восстановление» у баффера.
- VIP-бафф по таймеру, набор галочками.
- Алтарь раз в день: награда за вход, задания, колесо.
- Остановка при капче, смерти, вылете на страницу входа; один бот на браузер.
