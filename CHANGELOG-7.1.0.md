# L2wap Bot v7.1.0 — Control Center

**База:** рабочая Chrome-сборка v7.0.1.

## Интерфейс
- Новый тёмный модульный Control Center с компактным состоянием, быстрыми переключателями режимов и отдельной навигацией.
- Главная вкладка «Обзор»: показатели сессии, подсказки по работе, переходы к игровым подсистемам.
- Режим эпических боссов и катакомбы имеют отдельные вкладки; контролы перенесены без переименования ID.
- 92 контекстных пояснения «?» по действующим настройкам, подробные объяснения «Как это работает» сохранены.
- Поле поиска настроек продолжает работать по всем карточкам и новым вкладкам.
- Узкая встроенная в игру панель адаптирована под горизонтальную навигацию; широкая Chrome-панель получила боковое меню.
- Изменены только popup.html, popup.js (событие смены раздела и стартовый обзор), добавлены ui-v7.css и ui-v7.js.
- Алгоритмы фарма, боя, рыбалки и сетевые обработчики сохранены без изменений.

## Совместимость и проверки
- Все 238 исходных HTML ID сохранены, новые ID уникальны.
- Проверены 13 вкладок и переключение между ними в headless Chromium с эмуляцией API расширения.
- Проверены контекстная подсказка, переход из обзора в модуль, отсутствие ошибок JavaScript.
- Проверена адаптивность шириной 375 px: body не имеет горизонтального переполнения.
- Регрессионные тесты предыдущих версий и дополнительные тесты UI пройдены.
- В Chrome как установленном расширении и в реальной игре версия пока не проверялась.

**Обновление:** распаковать поверх текущей папки расширения и нажать «Обновить» в chrome://extensions/. Перед обновлением сделать экспорт памяти.
