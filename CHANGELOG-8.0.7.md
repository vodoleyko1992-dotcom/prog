# 8.0.7 — планшет и Firefox для Android: меню не закрывает игру

Игрок 11.10: «заработало, но на планшете с фаерфоксом из-под андроида всё немного криво-косо».

Что нашлось в Firefox 140, открытом в размерах планшета, на копии страниц игры (снимки игрока + стили игры):
- **Портрет (800×1280):** рядом с игрой места нет. Меню бота стояло поверх правой половины игры (список мобов, кнопки), а индикатор внизу налезал и на меню, и на кнопки игры.
- **Меню из «⋮ → Расширения»** (на Android открывается отдельной вкладкой) было окошком 738×600 в углу «экрана шириной 980 px», ниже пустота: у меню не было мобильной разметки.
- **Ландшафт (1280×800):** игра по центру, индикатор слева, меню справа — так и остаётся.

## Что сделано
- **Нет места рядом с игрой → меню свёрнуто.** Справа остаётся крупный язычок ◀ (36×64, под палец), нажатие открывает меню поверх игры, шириной до 460 px. Что меню открыто, запоминается только на этом устройстве (общую настройку «свёрнуто» с ПК бот не трогает). Когда место рядом с игрой есть, всё как раньше.
- **Индикатор поверх игры** — 3 строки (статус, запасы). Пока меню открыто поверх игры, индикатор спрятан.
- **Меню отдельной вкладкой** — на весь экран, раскладка как у встроенной панели. Мобильная разметка (viewport), окно значка в Chrome не изменилось.
- **Шрифт:** отключено «раздувание шрифта» Firefox для Android (font inflation) в меню и индикаторе.

## Проверено / не проверено
**Проверено:**
- 152 PASS (новый v807-tablet), node --check, геттеры модулей;
- браузерный смоук v807-tablet-browser в Chromium: широкий экран — меню рядом с игрой; портрет 800×1280 — меню свёрнуто, язычок открывает, индикатор прячется, общая настройка не меняется; меню вкладкой — на всю высоту;
- скриншоты в Firefox 140 (портрет и ландшафт планшета, копия страниц карты и боя со стилями игры);
- остальные смоуки Chromium, смоук Firefox (ПК и режим без API Android), zip Chrome загружен в Chromium.

**Не проверено:** на самом планшете — размеры экрана, панель адреса Firefox и масштаб у планшетов разные. Если что-то ещё криво — пришли скриншот.
