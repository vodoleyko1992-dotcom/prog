# 8.0.6 — пакет для Firefox (ПК и Android)

Просьба игрока: «собери пакет под фаерфокс, чтобы и на андроидном фаерфоксе работало».

## Что мешало Firefox для Android
- **Фоновый скрипт падал на первой строке с горячими клавишами.** На Android у Firefox нет `chrome.commands` (Alt+Shift+B), и обращение к нему выбрасывало ошибку. Всё, что идёт ниже в background.js, не регистрировалось: журнал, замок вкладки, запись памяти. Бот на телефоне не работал бы вовсе («Receiving end does not exist» — проверено в Firefox). Теперь горячие клавиши, значок «ON», уведомления и снимок экрана включаются только там, где они есть.
- **Меню из «⋮ → Расширения → L2wap Bot» открывается на Android отдельной вкладкой.** Кнопки «панель», «подсказать», «снимок DOM» обращались к «активной вкладке», а это само меню. Теперь они находят вкладку игры. Панель внутри страницы игры (док) работает как раньше.

## Пакет
- `tests/tools/firefox-build.cjs` собирает `l2wap-bot-v<версия>-firefox.zip`: фоновая страница вместо service worker, `browser_specific_settings.gecko` (id `l2wap-bot@local`, Firefox 128+) и `gecko_android` (128+), без полей только для Chrome. 128 — первая версия с `world: "MAIN"` для hook.js.
- `tests/tools/firefox-smoke.cjs` — смоук в настоящем Firefox (headless, подставная https://l2wap.com/). Флаг `--android` убирает API, которых нет на Android.

## Проверено / не проверено
**Проверено:**
- 151 PASS (новый v806-firefox), node --check, геттеры модулей, браузерные смоуки Chromium, zip Chrome загружен в Chromium;
- Mozilla web-ext lint: 0 ошибок (28 предупреждений про innerHTML, тексты экранируются);
- Firefox 140 ESR: дополнение ставится, hook.js и content.js работают на странице, фоновый скрипт отвечает, базовый профиль применился (лимит CoL 0), меню открывается. То же самое — с выключенными API Android. Старый background.js в этом режиме падал.

**Не проверено:** на настоящем телефоне с Firefox для Android. На Android вкладка в фоне или с погасшим экраном засыпает — бот там стоит, держи игру открытой на экране.
