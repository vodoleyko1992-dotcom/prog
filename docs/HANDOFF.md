## 3. Правила игрока для бота (обязательно)

- **MP не экономим — приоритет ДПС.** Банки MP легко купить. Экономные тактики по умолчанию выключены.
- **Бот стоит, где его оставили** (пока «Автофарм» выключен): бьёт ★-цели квестов, иначе мобов этой локации, **но не ниже героя −5** (иначе не падают FA). Сам никуда не улетает.
- **TvT по умолчанию ВКЛ и важнее всего**, пока идёт (за 3 мин до старта задачи не начинаются, из PvE-боя — на арену).
- «Проверять карту каждые 0 боёв» = никогда (только цепочка «Охотиться дальше»).
- **Чемпионы** (обновлено15.10): синих/зелёных разрешено; **оранжевых/жёлтых теперь разрешено только при положительной ожидаемой окупаемости**, красные остаются запрещены. Режим `champCancel=efficiency`: совокупно время боя, риск потери FA-баффов, накладные расходы перехода и резерв20% (40% без своего замера ДПС) против награды по существующей шкале EXP+FA в секундах обычного фарма. Это оценка, а не точный денежный учёт расходников. Нет данныхHP/EXP/темпа — пропуск. Квесты и источники ресурса не обходят расчёт. Старый допуск с карты нельзя переносить на нового моба цепочки. Однократная миграция разрешает оранжевых, включает этот режим и оставляет красных выключенными; последующие ручные настройки сохраняются. FA: синий10%, оранжевый20%, красный60%, не ниже героя−5. Предыдущее решение14.10 о полном запрете оранжевых заменено этой просьбой.

- Заряды строго под надетое оружие (грейд оружия → грейд зарядов; маг. оружие → blessed spiritshot).
- **Магистр (новое решение 14.10):** пользователь попросил изучить гильдию магов и учить новые навыки автоматически **сразу при включении и затем каждый +1 уровень**, с учётом активного класса. Прежнее правило «автомагистр выключен» заменено: новая одноразовая миграция включает его и шаг 1, последующий ручной off сохраняется. Обучение берёт текущий серверный каталог и отдельный прогресс класса/слота, сохраняет резерв SP/исключения и подтверждает конкретный новый ранг. Профессию не меняет. Непрерывную охоту прерывает после подтверждённой победы, затем возвращается на карту/в прежние катакомбы; без срока обучения цепочку не прерывает. Stop, передача вкладки, смена героя/режима, проверка активности и неподтверждённая запись состояния запрещают оплату. 409 даёт паузу и новое чтение; после сбоя отметка prepared не доказывает отсутствие запроса. Неизвестный исход сверяется по рангу и ревизии: при неизменной ревизии через минуту допустим только тот же battleId/expectedRevision, с повторной проверкой условий; 409 такого повтора не стирает возможный исход оригинала. После чтения персонажа повторно проверяет TvT/антибот перед продолжением цепочки. Проверки: 66 новых Node-сценариев, 9 браузерных с настоящим публичным рендером и 6 независимых MV3/main сценариев с заменёнными API (бой→уровень→гильдия→карта/катакомбы, Stop, 409, мало SP, принятый POST→Stop→reload→Start без повторной оплаты); ручной live Weapon Mastery 34→35 за 390000 SP подтверждает контракт страницы, живой проход новой автоматики пока отдельно не подтверждён. Функция пока только в исходниках: опубликованный ZIP 10.0.15 её не содержит.
