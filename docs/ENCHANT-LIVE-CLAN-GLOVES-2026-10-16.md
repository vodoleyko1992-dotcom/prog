# Живая проверка автозаточки: клановые магические рукавицы

16.10.2026, 15:52 Asia/Vladivostok (UTC+10). Проверен runtime после PR #185, commit `cb7b25874c3915d942531ff1c90e8eab822097d1`, без пересборки опубликованного ZIP 20.2.

## Разрешение и условия

Пользователь попросил зайти в игру и проверить автозаточку на клановых магических рукавицах, затем сообщил «герой свободен». До этого, после ответа «Сейчас аккаунт занят», выполнялось только чтение; заточка не запускалась.

Warlock, уровень 78, вне боя. Надеты «Кланові магічні рукавиці», itemId `9002298`, target `eq:lg`, S-grade, +0. В сумке 23 обычных свитка брони S (`910518`), благословенных брони S нет. Для живой проверки выбрана одна попытка обычным свитком до +1; максимумы попыток и свитков равны 1. На +0 неудача не снизила бы уровень ниже +0.

В отдельном облачном профиле браузера загружено настоящее расширение из репозитория. Вещь, политика, лимиты и запуск выбраны через интерфейс popup. Модуль заточки сам открыл штатную страницу и нажал её кнопку; отдельный скрипт POST заточки не отправлял. Дополнительный сетевой ограничитель разрешал только один запрос заточки этой цели, одним имеющимся обычным свитком S, без покупок и других игровых расходов.

## Подтверждённый результат

Штатный запрос:

```json
{"expectedRevision":304790,"targetInstanceId":"eq:lg","payment":"scroll","count":1,"scrollItemId":910518}
```

Сервер ответил HTTP 200: `attemptedCount=1`, `successCount=1`, `failCount=0`, `scrollConsumedCount=1`, `coinConsumed=false`, `previousEnchantLevel=0`, `currentEnchantLevel=1`, `updatedTargetInstanceId="eq:lg"`, revision `304791`.

Свежий GET `/character` подтвердил:

- те же надетые клановые рукавицы, +0 → +1; UID и три клановых свойства не изменились;
- обычные свитки брони S: 23 → 22;
- Adena: 368 026 310 → 368 026 310;
- Coin of Luck: 425 → 425.

Модуль сохранил `status="done"`, причину «Все цели достигнуты», одну подтверждённую успешную попытку и один списанный свиток; `pending=null`, неизвестных исходов нет. Повторного запроса не было. После проверки нажат общий Stop, тестовый клиент закрыт.

## Границы

Это одна успешная реальная попытка на надетых клановых магических рукавицах. Не проверялись живые неудачи, другие уровни, вещи в сумке, массовые серии, покупки или заточка во время TvT. Проверка не доказывает отсутствие всех возможных сбоев. Функциональных изменений кода для этого запуска не потребовалось. Версия и опубликованный ZIP 20.2 не менялись.
