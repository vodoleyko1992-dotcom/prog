# 20.56 Chrome — A-плащ Goddard выбирается целью Маммона

Быстрая сборка по команде John 23.10 «сборка, без проверок быстрая». База — 20.55 + PR #388.

## Что было
John 23.10: «Не определяется А плащ и не могу его прокачать». В списке целей кузнеца Маммона вместо плаща стояло клановое оружие без имени («★ #9002284»), а выбранная цель с клановой вещью мешала выбрать Cloak of Goddard Guardian (920017).

## Что сделано (PR #388)
- В цели кузнеца попадают только вещи, которые Маммон улучшает (номера 910618–929999); клановое оружие (9002282/9002284) больше не показывается.
- Одноразовая миграция `mmGoalClan2056` снимает уже выбранную клановую цель.
- Меню Маммона фильтрует надетое тем же правилом.

## Проверено
- Тест v2056-mammon-clan-goal и полный Node-набор — в PR #388.
- При сборке: синтаксис JS, состав ZIP. Длинные проверки (браузерные смоуки, загрузка ZIP в Chromium) по просьбе игрока пропущены.

## Не проверено в живой игре
- Само улучшение плаща Lv.0→1 (нужно 3,5 млн адены, 3 CoL, Crystal A 320, Crafted Leather 15).
