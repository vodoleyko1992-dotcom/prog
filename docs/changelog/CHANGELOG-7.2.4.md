# 7.2.4 — настройки рыбалки игрока по умолчанию (скрин 10.10)

**«Сделай базовой настройкой».** Настройки рыбалки со скрина стали значениями по умолчанию: в меню, в кнопке «лучшие настройки рыбалки», в базовом профиле (новая установка). У текущей установки их выставит разовая миграция `fish724`.
- Наживка: «Авто — по замеру Proof/ч» (хорошая — только бесплатная, из Old Box).
- Рыболовные заряды: вкл.
- Докупать наживку и заряды за адену: вкл.
- Наживка за раз: 1000 пакетов по 10 (было 100) — 1 000 000 аден.
- Заряды под наживку (авто-соотношение): вкл. Раньше авто брало не больше 400 пакетов, теперь до 1000. Иначе на 1000 пакетов наживки (≈6 800 рыб × ≈5,5 заряда) зарядов не хватало бы до конца наживки. По расчёту выходит ≈750 пакетов (3,75 млн аден).
- Зарядов за раз, если авто выкл.: 750 пакетов (было 75).
- Остановиться после N забросов: 0 (без лимита).

**Proof за час рыбалки (по логу 10.10 18:17–19:45, удочка +0…+2, обычная наживка, с зарядами):** ≈562 рыбы/ч. Разделка 302 рыб + обмен → +99 Proof, 297 рыб → +97 Proof. Итого ≈0,33 Proof с рыбы, **≈185 Proof за час ловли**. Час обходится примерно в 2,7–3,4 млн аден: время 2,3–3 млн (пакет 6 ч — 14 млн), заряды ≈300 тыс., наживка ≈60 тыс. Это ≈15–18 тыс. аден за 1 Proof.

**Проверено:** 78 PASS (новый `v724-fish-defaults`: значения в ядре, меню, кнопке, базовом профиле, миграции; авто-соотношение на 1000 пакетов ≈749 пакетов), node --check, геттеры модулей, смоуки Chromium (service worker, рантайм, рыбалка вкл/выкл, список фарма — PASS). Собранный zip загружен в Chromium: версия 7.2.4, меню новой установки показывает наживку «Авто», 1000 / 750 пакетов, заряды 1000/5000; сумка из сети и окно — как в 7.2.3.

**Не проверено в живой игре:** покупка 1000 пакетов наживки и ≈750 пакетов зарядов одним запросом. Если магазин рыбака не примет столько за раз, бот сам перейдёт на покупку по 1 пакету и через 30 мин снова попробует полную пачку (так было и раньше).
