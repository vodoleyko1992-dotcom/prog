# 20.82 — Chrome и Firefox, 30.10.2026

Собрано по просьбе John «Сборка хром и фаер», база `490a21d` (после PR #460 и #461).

- **Бафф суммона без лимитов** ([PR #461](https://github.com/vodoleyko1992-dotcom/prog/pull/461), John 30.10: «убери вообще лимиты на бафф кота, адены как грязи»). Полный баф суммона больше не проверяет потолок цены набора `petFullMaxPrice` и резерв адены `petFullReserve`/`shopReserve`. Бот покупает набор, пока адены хватает на сам набор. Возврат после бафа больше не проверяет резерв и лимит снабжения `shopMaxSpend`, поэтому решён открытый вопрос ревизии 28.10 о походе, который стоял на телепорте. Поля лимитов убраны из меню. Как и раньше, бот не покупает повторно при неизвестном исходе оплаты, не перекупает до конца уже оплаченного срока, учитывает выключатель автообновления и не тратит CoL/FA.
- **Масс-магия в подземелье** ([PR #460](https://github.com/vodoleyko1992-dotcom/prog/pull/460), John 30.10: «старайся убивать в подземелье мобов Масс магией»). Настройки и базовый профиль не заменяются. Firefox ZIP неподписан, Gecko ID прежний.
