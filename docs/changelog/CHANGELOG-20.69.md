# Firefox 20.69 — режим Rebirth и восстановление охоты, 27.10.2026

Сборка по прямой просьбе John для Firefox после отдельного режима Rebirth (PR #433). Включены также исправления Wizard/Greater из PR #431 и ожидания HP-сверки/сдачи Dion из PR #432. Только Firefox: Chrome ZIP остаётся 20.66, Lite — 1.8.1.

## Rebirth-подземелья

По журналу02:58 бот не продолжал подземелье из каталога: отдельной задачи не было. Полный журнал03:20 подтвердил300мобов, чемпиона, выбор из16РБ и логово выбранного РБ. Добавлены основная задача «Rebirth-подземелья», собственная панель и быстрый запуск. Уже открытый собственный одиночный поход продолжается через штатные кнопки игры, включая чемпиона и выбранного РБ.

По умолчанию выбраны Easy и ручной вход. Галочка «Автоматически входить в следующий поход» разрешает новый вход и повтор после подтверждённого завершения. Перед списанием проверяются свежая цена, ключи, резерв и отсутствие активного похода. Подтверждённые цены —2/4/6ключей за Easy/Medium/Hard; неизвестная цена или исход действия требуют сверки. Дневной лимит мобов общий с обычной охотой.

РБ по умолчанию выбирает игрок в игре. Можно явно выбрать повтор наблюдённого варианта «РБ с одноручным посохом (как в последнем походе)»; названия и выбор остальных15РБ не выдумываются. Отправленные вход, бой и выбор РБ переживают перезагрузку без повторного списания при неизвестном исходе. Сам режим и автоматические входы изначально выключены; новый герой их не наследует.

## Кот, Greater и продолжение охоты

- Wizard после Rebirth включён в прежнюю подготовку котовода и полный бафф суммона. Сохраняются проверка слуги, каталог, бюджет/резерв адены и запрет повторять неизвестную оплату.
- При отсутствии эффекта герой восстанавливает последний подтверждённый Greater того же героя/класса, если он доступен в свежем каталоге. Ручной Magnus больше не подменяется Water по умолчанию; явный выбор в настройках имеет приоритет. Набор героя — маг, Greater, Noblesse и резисты.
- После ошибки чтения типа цели по HP проверка повторяется через3→6→12с вместо ожидания до минуты. Неизвестная цель по-прежнему не разрешает удар.
- Готовая глава Dion без доступной кнопки сдачи ожидает нужного уровня или повторной проверки, а разрешённая местная охота продолжается. Устраняется цикл повторного открытия главы/похода к тому же NPC.

Предыдущая оптимизация журнала20.68 сохраняется. Настройки скорости, рабочие профили и Gecko ID `l2wap-bot@local` не меняются.
