# L2wap Bot 10.0.18

Chrome-сборка от 15.10.2026 по команде «Собирай», включает PR #123–127.

## Что вошло

- Исправлена первопричина неполного чтения РБ: компактные кнопки страниц, переход между группами, ожидание обновления строк. Защита от частых повторов при сетевой ошибке сохранена.
- АОЕ учитывает живых дополнительных мобов и может опережать одиночный добивающий удар при достаточных данных об уроне; срочное лечение имеет приоритет.
- При фарме ресурса или рецепта плановая проверка карты — раз в 50 побед. Слабый моб в цепочке больше не вызывает выход. Безопасность, снабжение и завершение задачи сохраняют приоритет.
- Оранжевые чемпионы разрешены при положительной оценке затрат времени относительно EXP/FA. Это оценочная модель с резервом, не точный денежный учёт расходников. Красные запрещены. Разовая миграция включает новый режим оценки оранжевых.
