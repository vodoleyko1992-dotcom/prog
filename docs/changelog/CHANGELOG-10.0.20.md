# L2wap Bot 10.0.20

Chrome-сборка от 15.10.2026 после обратной связи игрока: 10.0.19 установлена, но S-заряды с уже надетым клановым кастером не покупались и не ставились на панель.

## Исправлено

- После победы бот раз в 10 минут сверяет надетое оружие по GET /character без выхода из катакомб на карту. Если кастер был надет до запуска расширения, старое значение A в памяти заменяется на подтверждённое S, таймер закупки сбрасывается.
- Включённый старый заряд на панели не мешает замене на подходящий S-заряд духа.
- Добавлены проверки ручной смены оружия до запуска бота, Stop во время запроса и включённого старого слота.

## Проверки

- 230 Node-файлов, синтаксис runtime JS и envcheck28 модулей PASS. Базовый профиль без auth/пароля.
- ZIP: 60 файлов, 1200631 байт, SHA256 `3ebf3b355589431c9663e0a996782d6afc1c44aa19d27b84b9439d45f0f90c9c`; исходники и зависимости сверены, tests/kb/docs исключены.
- Распакованное расширение загружено в Chromium: версия 10.0.20, 208 ключей cfg, бот выключен, auth отсутствует, 0 ошибок JavaScript.
- Chromium MV3 с локальными ответами игры: серверное S-оружие при сохранённом A-кэше обновляет грейд и снимает паузу закупки; нехватка S-зарядов определяется. Старая включённая соска заменяется в модульном тесте.

- Публичная ссылка скачана повторно; файл побайтно совпал, SHA256 тот же.

- `smokes.sh`: 45 браузерных скриптов PASS; один сценарий загрузки тестовой страницы прошёл при отдельном повторе, итого 46/46. Два DOM-теста пропущены без снимков.

Живые покупки на аккаунте игрока пока не подтверждены; Firefox не запрошен.

Распакуйте поверх прежней папки расширения и нажмите ↻ в chrome://extensions, чтобы сохранить память.
