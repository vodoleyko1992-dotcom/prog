# Firefox 20.73 — восстановление Rebirth после сетевого сбоя

28.10.2026. John: «сборка» после исправления зависания подземелий; прежняя просьба «без проверок» сохранена. База — `7d2e05f`, исправление [PR #441](https://github.com/vodoleyko1992-dotcom/prog/pull/441). Выпускается только Firefox 128+ для ПК и Android. Chrome 20.71 и Lite 1.8.1 не пересобираются.

## Что исправлено

В TXT/learn 03:12 после победы над mob231 произошёл сетевой таймаут. Пока бот ждал повторной сверки 60 секунд, метка победы устарела. После этого продолжение без прежнего контекста уже не доходило до серверного чтения: 1748 ожиданий, три перезагрузки и передышка; до следующего старта прошло 56 минут 14 секунд. Ускорение 20.72 этот путь не закрывало.

- Точный URL и сохранённая связь собственного боя вместе со свежими серверными данными героя и того же одиночного похода разрешают бесплатный возврат в каталог.
- Штатные «Продолжить» / «Бой» возобновляют уже оплаченный поход. Из устаревшей победы бот не повторяет старый `next` и не оплачивает новый вход ключами.
- Stop, смена владельца или контекста, антибот, квота и квитанции неизвестных запросов сохраняют запреты. Общий сторож зависаний остаётся включённым.
- Включены параллельные сверки Rebirth и память подтверждённой пользы массовых атак из 20.72.

## Проверки и ограничения

**По сохранённой просьбе пользователя все проверки этой сборки пропущены:** Node, синтаксис, геттеры, линтеры, браузеры, аудит ZIP и проверка скачивания. Новых PASS нет. Прежние 692 Node-файла и три локальных Chrome-сценария относятся к исходному исправлению PR #441 и не являются проверкой Firefox 20.73.

Живая игра, Firefox и физический Android при упаковке не открывались. Исправление не объявляется проверенным в живом походе. Пакет неподписан; Gecko ID и формат профиля прежние. Ранние `invalid_spawn` и общий `fish→next` этой сборкой не объявляются устранёнными.

Обновление: распаковать поверх в прежнюю папку, перезагрузить дополнение на `about:debugging#/runtime/this-firefox` и обновить вкладку игры. Следующий шаг — полный журнал установленной 20.73, особенно восстановление после сетевого сбоя.
