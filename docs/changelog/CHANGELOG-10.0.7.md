- **Кристаллы и другое сырьё из магазина у цели Маммона** (игрок 13.10 02:38, скрин раздела «Сырьё»: «Кристал: ранг D · нет в фарме», нужно 900, есть 0; «кристаллы покупаются в магазине»). Бот знал только два источника сырья — дроп/спойл по базе фарма и крафт — и всё остальное подписывал «нет в фарме».
  - `modules/mammon.js`: таблица `MM_SHOP` — сырьё, которое продаёт gm-shop (Розхідники › грейд › Ресурси; по снимку магазина 11.10, `kb/data/game-shop-drops.json`): Кристал D/C/B/A/S (650 / 3 000 / 9 000 / 15 000 / 25 000 аден), Самоцвіт D–S, Soul Ore, Spirit Ore. В плане цели такое сырьё помечено `shop {g, a}`; строка плана для меню — `[имя, нужно, есть, не хватает, фарм, грейд магазина, цена]`.
  - Меню «Маммон → Сырьё»: вместо «·нет в фарме» — «·магазин ≈650», в колонке «Не хватает» — ≈ сумма в адене, под таблицей строка «🛒 Докуплю в магазине: Кристал: ранг D 900 ≈ 585 000 аден». В журнале/статусе цели — «докуплю в магазине: … ≈ … аден».
  - Покупка — через обычную закупку расходников (`economy.shopPlan` берёт `mammon.mmShopWant()`): вкладка грейда предмета, подраздел «Ресурси», ровно недостача по плану; резерв адены и лимит трат за раз (раздел «Закупка») действуют как и для зарядов; цена в Coin of Luck — отказ, как раньше. Новая галка «Докупать сырьё из магазина» (`cfg.mmShopBuy`, ВКЛ); выключена — в таблице «продаётся в магазине (докупка выключена)», бот ничего не покупает.
  - Цель фарма (`mmFarmGoal`) не выбирает сырьё, которое докупится в магазине.
  - Попутно: на скрине «Залізна руда · нет в фарме», хотя «iron ore» в базе фарма есть — справочник предметов загружен не на каждой странице, имя сырья было украинским, а база — по английским именам. Теперь источник ищется по всем именам предмета (справочник, рецепты, имя со страницы кузнеца).
