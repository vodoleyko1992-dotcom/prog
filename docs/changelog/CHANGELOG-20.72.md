# Firefox 20.72 — скорость подземелий Rebirth

28.10.2026. John: «сборка на фаерфокс без проверок». База — `c2d30ef`, исправление скорости из [PR #439](https://github.com/vodoleyko1992-dotcom/prog/pull/439). Выпускается только Firefox для ПК и Android; Chrome 20.71 и Lite 1.8.1 не пересобираются.

## Что изменилось

В журнале 20.71 / 01:32 типичный цикл start→start занимает 3,155 с, при этом от первого действия до победы — 0,390 с. Перед первым ударом проходит 1,080 с, от победы до следующего старта — 1,529 с. Разрыв около пяти минут между походами связан с ручными действиями игрока и из активного темпа исключён.

- Независимые свежие сверки перед боем и после победы выполняются одновременно. Подтверждения своего героя, цели, одиночного похода и этапа остаются обязательными; действие разрешается после всех ответов. Stop, владелец вкладки, антибот, дневная квота и квитанции неизвестных входов сохранены.
- Подтверждённая модель массовых атак сохраняется между мобами одного точного похода. Другой run, этап, сложность, вид, уровень, роль, герой, класс или слот не используют чужой прогноз. Слабая массовая атака вслепую не навязывается.
- В сборке сохранены отдельный режим Rebirth, собственная подготовка кота и прежние разрешения расходов.

## Проверки и ограничения

**По прямой просьбе пользователя проверки этой сборки не выполнялись:** Node, синтаксис, геттеры модулей, линтеры, браузеры, privacy и аудит ZIP пропущены. Новых PASS нет. Прежние 691 Node-файл и три локальных Chrome-сценария относятся к исходному исправлению PR #439 и не являются проверкой Firefox 20.72.

Живая игра, Firefox и физический Android при упаковке не открывались. Процент ускорения в игре не измерен. Пакет неподписан; Gecko ID и формат профиля прежние. Ранние `invalid_spawn` и общий `fish→next` этой сборкой не объявляются устранёнными.

Обновление: распаковать поверх в прежнюю папку, перезагрузить дополнение на `about:debugging#/runtime/this-firefox`, затем обновить вкладку игры и выбрать «Подземелья». Следующий шаг — полный журнал установленной 20.72 для измерения темпа похода.
