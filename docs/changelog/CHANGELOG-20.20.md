# L2wap Bot20.20 — две быстрые сборки

19.10.2026. Chrome и Firefox128+, база20.19 + PR #272.

- Обычные мобы рядом с живым РБ учитываются сразу в общей статистике и дневном счётчике «Лимитов».
- Полный поток смертей учитывает длинный бой; reload, повторные ответы, сбросы статистики и новый респ не повторяют уже учтённые убийства.
- Дневной итог: автофарм + катакомбы + обычные мобы рядом с РБ. Сам босс в дневные обычные мобы не входит. Лимит приостанавливает автофарм/катакомбы; тур РБ продолжается.
- Исторический недосчёт без точной исходной точки не переписывается. Все исправления20.19 сохранены.
- Firefox ZIP неподписан: временная установка на ПК, постоянная/обычный Android требуют подписи Mozilla. Инструкции в README-CHROME.txt и README-FIREFOX.txt.

Проверки и точные результаты — WORKLOG: полный Node runner, синтаксис/envcheck, целостность и сверка ZIP, загрузка Chrome ZIP в Chromium, Firefox lint, выборочные MV3 счётчиков РБ и лимитов/логов. Полный исторический browser-runner, настоящий Firefox/Android и живая игра в быструю сборку не входят.
