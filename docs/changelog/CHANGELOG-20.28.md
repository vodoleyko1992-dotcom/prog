# L2wap Bot 20.28 — Chrome и Firefox 128+

Обе быстрые сборки по прямому запросу игрока. Основа — 20.27 + PR #293, исправления инженерного аудита автономности. Новых обязательных настроек нет; цели, выбранные задачи и ограничения пользователя сохраняются. Автозаточка остаётся отключённой.

## Что изменилось

- Исправлено сохранение прогресса при Stop, повторном запуске, продлении аренды вкладки и смене героя. Неудачная запись не должна терять очередь или переносить состояние другому герою; позднее завершение Stop проверяет текущий запуск перед освобождением управления.
- Старт ждёт сохранения выбранных задач. Ошибка чтения или сохранения блокирует запуск с прежними настройками. Герой и значения формы фиксируются до асинхронной операции; поздние ответы не меняют настройки и статус другого героя.
- Если дневные счётчики недоступны, новая добыча под дневным лимитом ждёт подтверждённой сверки, а независимые службы и восстановление получают управление. Старая отметка активного заброса сверяется с сервером перед новой добычей.
- Восстановление неизвестного заброса ограничено тремя перезагрузками за десять минут; затем продолжается сверка с паузой без нового заброса. Когда сервер подтвердил отсутствие улова и рыбалка временно недоступна, бот может продолжить другую выбранную задачу и позже вернуться. Изменение героя, режима или команды прерывает длинное ожидание.
- Некорректный или пустой ответ HTTP 2xx больше не считается подтверждённой оплатой: неизвестная операция сохраняется до сверки фактического результата. Слепой повтор покупки не разрешается.
- Очистка больших диагностических снимков теперь применяется и к вложенным поддеревьям: значения полей, скрипты и известные секретные параметры не обходят фильтр ускоренной ветки. Это не универсальное распознавание секретов в произвольном тексте.

Из 20.27 сохранены серверные сутки, свежая сверка дневных результатов при явном Старте/новом дне и обмен камней на АА партиями до 100 000. Все предыдущие исправления входят в обе сборки.

## Ограничения

- Нужны запущенный браузер и открытая игра. Автозапуск ОС и расписание разрешённых часов не добавлены. Многодневная продуктивная автономность не доказана.
- Одновременные изменения задач в двух меню одного героя могут затереть друг друга. До отдельного исправления редактировать настройки через одно меню.
- Произвольный непустой JSON ещё не проверяется по строгому контракту каждой покупки. Исправление некорректных/пустых ответов не закрывает этот остаточный риск.
- Подтверждённый сервером улов на другой странице при снятой задаче рыбалки автоматически не доводится. Капча, отсутствие входа, конфликт ограничений и постоянная ошибка хранилища требуют участия пользователя. Аренда не координирует разные браузеры и устройства.
- Firefox ZIP неподписан. Временная установка может потерять данные после закрытия браузера; перед закрытием нужен экспорт. Для постоянной установки в обычный Firefox и для обычного Firefox Android требуется подписанный пакет через Mozilla. Нативная совместимость этим выпуском не подтверждена; инструкция — `README-FIREFOX.txt`.
