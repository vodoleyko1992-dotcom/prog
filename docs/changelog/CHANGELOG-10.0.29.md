# L2wap Bot 10.0.29 — Chrome, 16.10.2026

По запросу «Правь и сборка», поверх PR177 и всей10.0.28.

- Обычный рейдовый тур атакует живых разрешённых игрой РБ в выбранном окне уровня. Старые «не по силам», неизвестный DPS/боевые характеристики, оценка выгоды/длительности, выключенная проба и старые пробы не запрещают цель. Прогноз остаётся справочным; порядок определяется уровнем.
- Бой не прерывается только из-за30с, смены состава, отсутствия модели или регена босса. Реально низкий HP и опасные измеренные удары вызывают штатный выход; факт выхода сохраняется до навигации, опасная цель/подтверждённая смерть получают паузу30мин. Неподтверждённый выход, явный пропуск, неизвестная оплата, уровень/живость/запрет игры, цена/средства/лимиты, TvT и антибот сохраняются. Эпики не переведены на эту политику.
- Исправлен ошибочный фильтр цвета чемпиона у обычного РБ. Настоящие чемпионы сохраняют свои фильтры.
- Включён PR177: прерванный/дополненный FA-набор без повторной оплаты и ложного60с ожидания; подтверждение улучшения баффа; обновление пустой очереди; устранение двойного учёта префикса полного журнала боя. Подробности и границы исходных логов — [разбор](../BUFF-RAID-2026-10-16.md).
