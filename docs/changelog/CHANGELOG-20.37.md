# L2wap Bot 20.37 — Chrome

По команде «Сборка на Хром» выпущена основная Chrome-версия с PR #311 поверх20.36.

После подтверждённого ответа сервера больше не добавляется пауза реакции150–450мс (наРБ100–220), а к общему КД — лишние60мс. Родной GET `/character`, адаптивные интервалы готовности интерфейса и серверный запас40мс сохранены. Ответ привязан к rid, действию и владельцу; ожидание пробуждается сетевым событием, таймер страхует. Таймаут6с не разрешает отправить следующий запрос до ответа на первый.

Перед кликом бот повторно проверяет текущий выбор и КД: изменение целей, MP или доступности навыка отменяет устаревший удар. Короткое намерение «агро → лучший доступный массовый удар» сохраняется после отказа первого AoE, повторное агро из-за такого отказа не требуется. Восстановление MP снимает только MP-задержку; общий КД не превращается в личный. Учтены массивы `skillCooldowns` и полные безопасные боевые данные из hook.

В ходе сборки функциональный код не меняется: только версия/описание/header и инструкция. Базовый профиль и настройки сохраняются. Firefox остаётся20.36.

Проверки выпуска — `docs/evidence/build-20.37/validation.json`. Живую игру при выпуске не открывали, реальный прирост ДПС ещё не измерен. После установки обновить расширение и вкладку игры, затем записать контрольный боевой лог.
