# 20.65 Chrome + Firefox — меньше нагрузка ЦП и памяти

Сборка по просьбе John «Новая борка на хром» (26.10.2026). Основа — `74f86d8`, включая PR #418 и #420 поверх Chrome 20.64. По дополнительной просьбе John «и на фаерфокс тоже» собирается также Firefox 20.65 из того же кода; Lite 1.8.1 не пересобирается.

## Охота и рыбалка: маленькие записи вместо всей памяти героя

Раньше дневной лимит мобов переписывал всю память героя два раза на моба, рыбалка — 4–5 раз на заброс. В журналах игрока память занимала 0,5–1 МБ. Теперь частые поля (`kills`, квоты и `fish*`) записываются отдельно, в ключ `hot`; фон, игровая вкладка и меню читают объединённое состояние. На сохранённом профиле 150 КБ запись на моба составляет около 0,3 КБ.

Полная запись остаётся при изменении остальных полей, для маленькой памяти и при очередной записи после минуты накопления. Стоп/Пауза сначала останавливают бота, затем сохраняют накопленные счётчики; импорт памяти сбрасывает прежний `hot`. Проверяются герой и исходные значения: чужая или устаревшая запись не подмешивается. Экспорт памяти сохраняет прежний формат.

## Журнал, замеры боя и меню

- Журнал кэширует число событий вместо полного `count()` после каждого пакета; ошибки записи обрабатываются с откатом пакета.
- Длинные описания состава боя заменяются отпечатками; последние шесть полных составов сохраняются отдельно. Прежняя память облегчается однократно.
- Просроченный каталог оружия удаляется отложенной записью. Прокси настроек пересчитывает задачу только для нужных ключей.
- Убраны постоянное мигание индикатора и размытие фона окна бота.

Предыдущие исправления 20.64 (Frenzy на эпиках, регистрация TvT, восстановление неотправленного заброса) сохранены.
