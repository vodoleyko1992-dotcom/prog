## Alt+R — загрузить таймеры боссов из файла (игрок 12.10 14:26)

- В меню бота: Alt+R открывает раздел «👑 РБ → ⏱ Таймеры боссов» и сразу окно выбора файла (то же, что кнопка «📥 Загрузить таймеры из файла слежки»); подсказка в нижней строке меню.
- На странице игры (фокус не в меню): Alt+R открывает то же окно выбора файла; таймеры сливаются с таймерами героя, сверху на 5 с надпись «⏱ Таймеры загружены: N боссов», строка в журнал. Фон принимает со страницы игры только таймеры (команда rbtImport, только l2wap.com), остальную память не трогает.

Проверено: тест v1003-rbt-hotkey, смоук v1002-rbtimer-browser (Alt+R в меню и на странице игры, окно выбора файла, слияние). В живой игре не проверено.
