## Полный бафф суммона для голема Warsmith перед РБ (лог 22.10 09:03, John «не взял бафф на суммона перед РБ»)

- В журнале: Warsmith 49 (саб крафтера) с призванным Mechanic Golem, «Автобаф суммона» включён в 08:59; в 09:03 тур РБ сходил к бафферу только за восстановлением HP и полетел к Fafurion's Page Sika без набора для голема.
- Причина: платный «Повний баф сумона» (`modules/warlock.js`) и ожидание набора в туре (`raid.js`) знали только кота Warlock/Arcana Lord и пантеру Dark Avenger/Hell Knight. У Warsmith задача молча стояла «нужен класс Warlock…», тур проверку пропускал.
- Исправлено: класс Warsmith/Maestro и суммон `*golem*` поддержаны (`warlock.fullClass`), тур РБ ждёт набор голема так же, как у кота; меню автобафа разрешает включение у Warsmith. Правила оплаты прежние: 10 млн адены за набор на 5 ч, бюджет `petFullBudget`, резерв, сверка квитанции, неизвестная оплата не повторяется.
- Голем живёт 60 мин: перепризванный голем теряет набор, а за оплаченный срок бот повторно не покупает (early-loss). Поэтому у голема «купить нельзя по правилам» (бюджет, цена, резерв, автообновление, срок прошлого суммона, архив) — тур идёт без набора и пишет причину один раз. У кота/пантеры ожидание прежнее.
- Тест `tests/v2045-golem-summon-buff.test.js`. Живая покупка набора голему не проверялась (принимает ли сервер набор `summon` для голема — увидим в следующем журнале).
