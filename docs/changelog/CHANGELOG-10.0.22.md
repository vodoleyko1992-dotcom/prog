# L2wap Bot 10.0.22 — общая сборка очереди исправлений

15.10.2026, Chrome. Сборка по прямому запросу пользователя; Firefox не запрошен.

## Что входит

- Тур РБ: единый цикл подготовки/оценки/перехода/боя, замер полного DPS с питомцем, вампиризм и запас HP, ограниченные пробы вместо вечного «не по силам», точная текущая цель, продолжение после победы. Городской/FA-бафф и полный бафф кота подтверждаются до входа. Победа не превращается в отход по дедлайну пробы (PR136–151).
- S-заряды: сверка надетого оружия с сервером, восстановление после отказа по грейду, закупка/панель/включение. Dark Panther и быстрые чемпионы включены вместе с прежними исправлениями.
- Ashen Bastion отделён от катакомб. Старый режим «РБ между мобами» удалён; основной тур сохранён. Ресурсная цепочка — карта раз в50 побед, без выхода только из-за слабого обычного моба.
- Эпики: ручное открытие списка обновляет сведения; неизвестный новый респ не выдаётся за точное время.
- Автообучение танка: чтение каталога конкретного учителя при пустом общем ответе (PR148).
- АОЕ: выбор по убийствам группы, а не только HP главной цели; обучение боковому урону/убийствам и суммарный учёт наград без потери одинакового дропа (PR152).
- TvT: регистрация приоритетна над всеми режимами; подтверждение сервером, лимит20мест, повтор после отказа. Полный каталог разрешённых умений, отказ от недоступного Vampiric Touch и быстрые переходы по ответам сервера (PR153).
- Дополнительный переключатель ширины панели ×2 (PR150).
- Семь ошибок экспертного аудита: отмена переходов после Stop, неизвестная цена/валюта, гонки профилей/сторожа, опрос Маммона и ошибочное отсутствие клана (PR147).
- Сохраняются отдельные режимы заточки, Warlock/PvP, рыбалка и обслуживание, крафтер/почта; они уже были реализованы и повторно проверяются общим набором.

## Найдено при общей проверке

1. Опрос TvT догоняет пропущенные первые10с регистрации после задержки/сна вкладки, пока окно ещё открыто.
2. PvE-бой больше не ждёт GET статуса TvT с тайм-аутом8с: опрос идёт один в фоне, известная открытая регистрация прерывает бой сразу. Ошибка сети не создаёт GET на каждый удар; повтор ограничен5с.
3. Инструмент проверки ZIP использует Playwright/Chromium текущей среды вместо обязательного старого пути `/opt`.

## Проверено

Итоговые результаты выпуска записаны в [RELEASE-CHECK-10.0.22.md](../RELEASE-CHECK-10.0.22.md).

## Границы

Локальные воспроизведения логов, VM-тесты, браузерные проверки с подставными ответами и загрузка ZIP не равны новому живому прохождению игры. Живой TvT и автономный тур на установленной10.0.22 ещё требуют подтверждения. Два старых DOM-смоука требуют отсутствующие конкретные снимки. Расширение не приобретает сабклассы; собственный крафт будущего Warsmith и новые серверные механики без наблюдений не объявлены готовыми. Исторические отчёты и их ограничения сохранены.
