# Firefox 20.67 — исправления SP, квестовых целей и Rebirth, 27.10.2026

Сборка по просьбе John «сборка на фаерфокс». Только Firefox, база `990f076817a69d29abc160775cf7b46d93f66ba6`; включает PR #422/#423/#425/#426/#427. Chrome ZIP остаётся20.66, Lite —1.8.1.

- После исходной нехватки SP магистр возвращается к разрешённым навыкам на том же уровне, когда свежий серверный баланс подтверждает достаточный запас. Резерв и защита повторной оплаты сохраняются.
- Обычный квестовый Tumran Bugbear больше не попадает в цикл «неизвестный чемпион→карта→тот же моб». Исторического HP недостаточно для такого вывода: при неоднозначности проверяется собственный текущий бой. Запреты цветов чемпионов сохранены.
- Уже оплаченный этап обычных мобов Rebirth продолжается штатной кнопкой без обычной плановой проверки карты. Старое продолжение отменяется, если игрок успел открыть нового моба. Полные имена «Rebirth · вид» сохраняются, фоновые запросы чата не задерживают бой.
- Впервые в Firefox вошли исправления Chrome20.66: Start из почты возвращается в подтверждённый незавершённый бой; после возврата от баффера кота в Ashen освобождается фарм без повторного телепорта.
- Настройки и память не сбрасываются, прежние оптимизации20.65 сохранены. При сборке игровая логика не менялась.
