# L2wap Bot20.31 — Chrome + Firefox, подготовка Frenzy/Zealot

Быстрая сборка по просьбе игрока20.10.2026:20.30 + исправление PR#297. В журнале11:28–11:31 Titan оставался выше95%HP из-за вампиризма; лимиты не включались, BattleTrance был запрещён общей ротацией.

- Отдельная включённая настройка для Destroyer/Titan: BattleTrance → выбранные готовыеFrenzy/Zealot → обычные банки/BattleRoar. Работает на обычных мобах иРБ.
- Перед кликом проверяются текущий класс, HP/MP и готовность; наРБ — запас25%HP под измеренные удары и стоимость баффов. Неизвестный исход не приводит к повторному сбросу. ПриHP10% сначала аварийное восстановление.
- Настройку можно выключить в менюРБ. Случайная атакующая/лечащая роль не разрешает BattleTrance. Базовый профиль включает единственный новый ключ `destroyerLimits`; память установленного расширения сохраняется при обновлении в той же папке.

Проверки: полный Node-runner, синтаксис/envcheck, аудитZIP, загрузка пакета вChrome и целевыеMV3 ВКЛ/OFF/Stop. Итоговые результаты — HANDOFF/WORKLOG. Живую игру и полный исторический browser-runner при быстром выпуске не запускали. По последующей команде «и фаерфокс сборка тоже» добавлен Firefox20.31 с тем же runtime и специальным manifest128+. FirefoxZIP неподписан; проверка пакета/lint выполняется без живой игры и настоящегоFirefox/Android.
