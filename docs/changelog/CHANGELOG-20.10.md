# L2wap Bot 20.10 — бой без застывших откатов и наживка «Авто»

17.10.2026. Chrome-сборка по команде пользователя «Сборка»: 20.9 плюс доводка реворка PR #231 и исправления PR #232–#233. Настройки пользователя и память не сбрасываются.

- **Реворк PR #231** (в 20.9 его не было): общий контроль Stop/паузы через фон, поколения управления (старые ожидания и восстановления не управляют новой сессией), подтверждённое сохранение настроек с видимой ошибкой, единая проверка MP перед атаками/лечением, подтверждение надетого оружия, владелец квоты после полуночи, состояние бота и выбранные задачи в начале «Обзора». Подробности — `docs/BOT-REWORK-2026-10-17.md`.
- **Застывший рисунок отката навыка (PR #232).** Если игра перестаёт стирать затемнение слота, а сервер уже считает навык готовым, бот через 1,2 с жмёт его по серверному дедлайну этого нажатия; после двух потерянных или отклонённых нажатий снова верит рисунку. Раньше так спасалась только обычная атака (10.0.26). В журнале один раз на слот: «рисунок отката … застыл».
- **Причина простоя в бою (PR #232).** Воин, который больше 6 с ничего не жмёт, пишет в журнал, каких навыков ждёт и почему (откат, нет MP, недоступно до конца боя). Та же строка видна в «Обзоре»: «Бой ждёт: …».
- **Старт (PR #232).** Если между нажатием «Старт» и чтением хранилища сменилось поколение, бот перечитывает состояние до трёх раз вместо отказа «start_superseded».
- **Возврат после проверки оружия (найдено при сборке).** После реворка своя запись настроек бота (подстановка оружия в меню, снятие ручного выбора) считалась сменой задач и отменяла его же возврат: бот оставался стоять на странице сумки «без дел». Теперь своя запись, меняющая ровно свои ключи, не прерывает маршрут; изменения из меню и другой вкладки по-прежнему прерывают. Ломались браузерные проверки Tyrant (кастеты) и кланового S-кастера, теперь обе PASS.
- **Наживка «Авто» (PR #233).** Хорошая наживка («Якісна наживка» из Old Box) используется, пока она есть в сумке; кончилась — бот переходит на обычную. Раньше по замеру Proof/ч «Авто» навсегда выбирало обычную, а хорошая лежала без дела. Замер теперь только советует, стоит ли покупать хорошую за Proof.

## Проверено
- Полный Node-runner (387 файлов, новый v2010-own-cfg-generation), синтаксис JS, envcheck 30, профиль без `auth`/паролей.
- Полный набор браузерных смоуков (98) с настоящим расширением, включая рыбалку на публичном рендере игры (5 сценариев наживки). Firefox-смоук пропущен (браузер не установлен).
- ZIP загружен в Chromium: версия 20.10, ошибок JavaScript нет.

## Не проверено в живой игре
- Живые бои и рыбалка из облака не запускались. Нужен журнал после установки: бой воина (строки «рисунок отката застыл» / «воин … без действий») и рыбалка в момент, когда хорошая наживка кончается.
- Firefox не собирался (только по отдельной просьбе).

Обновление: распаковать поверх в ту же папку, нажать ↻ в chrome://extensions/, затем обновить вкладку игры.
