# L2wap Bot 10.0.24 — кандидат стабилизации

По просьбе15.10: один кандидат после проверки последовательностей.

- Служебный маршрут имеет одного сохранённого владельца. Очереди баффера, магазина, суммона и рейда не перехватывают друг у друга переходы.
- Stop, новая цель/режим и потеря управления вкладкой запрещают запоздалые действия. TvT и восстановление имеют приоритет; длинные сканы умеют уступать выполнение.
- Платёж фиксируется до отправки. При неизвестном результате GM, баффер, рейдовый телепорт и Маммон сверяют результат без повторной оплаты. Учёт суммона/заточки также блокирует другие траты.
- В текущем бою неизвестная оплата не отключает защиту и обработку результата. Проверки состояния ограничены по частоте; переходы без продвижения останавливаются с причиной.
- В ZIP также входят ранее слитые PR159–162: сохранение подходящего Greater ПП/автонаборов, новые ударные навыки танка и полный бафф пантеры. Платный автобаф суммона по-прежнему включается пользователем.

Проверки выпуска: 270 файлов Node, синтаксис JS, envcheck30, браузерные смоуки, включая18 сценариев actual MV3 с локальным сервером. ZIP отдельно загружается в Chromium. Итог полного прогона фиксируется в WORKLOG.

Не проверено: живая игра, Firefox, отсутствующие исторические снимки DOM. Неизвестная оплата без доказательства результата остаётся блокирующей; это не разрешение повторить запрос по тайм-ауту. Полные правила и ограничения: [ACTION-COORDINATION.md](../ACTION-COORDINATION.md).
