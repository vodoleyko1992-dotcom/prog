# L2wap Bot 20.40 — ожидания статистики и native-урон

Быстрая Chrome-сборка по команде «потом быстрая сборка». Включён PR#316: после подтверждённого спойла/добычи бот не ждёт завершения телеметрической записи перед следующим действием. Данные остаются в общей очереди, обязательные квоты, проверка владельца и сохранение перед переходом сохранены.

Разбор новых native power-строк Whirlwind/Wild Sweep выделяет настоящий основной урон, отделяет power/число целей и splash, проверяет ID36/245. Подтверждённые массовые удары снова обучают групповую модель. Готовый Whirlwind учитывается против соседей, одиночный Wild Sweep не становитсяAOE. Изменений игрового кода во время упаковки нет; настройки и профиль сохранены, Firefox остаётся20.36.

Проверки выпуска — [доказательства](../evidence/build-20.40/validation.json). Использован локальный Chrome с модельными HTTP/задержками хранения. Живую игру, Firefox/Android и полный исторический браузерный runner в быстрой сборке не запускали. Реальный прирост фарма ещё не измерен; после обновления нужен полный боевой лог. Известный allDPS при исчезновении панели соседей не служит доказательством их убийства.
