# L2wap Bot 20.24 — Chrome

19.10.2026. Быстрая сборка Chrome по прямому запросу. База 20.23 + [PR #282](https://github.com/vodoleyko1992-dotcom/prog/pull/282). Для Firefox остаётся прежняя сборка 20.23.

- В разделе «Маммон» появилась кнопка анализа рюкзака. Она работает и при остановленном боте: читает полный инвентарь с сервера, не запуская бой, перелёт, крафт или оплату.
- При выбранных задаче «Маммон» и вещи-цели анализ выполняется автоматически после запуска, смены цели, успешного получения письма и раз в 5 минут. Повтор после ошибки — не чаще раза в минуту; переходы между страницами не создают повторные чтения свежего снимка.
- Отчёт показывает «нужно / есть / не хватает» отдельно для готовых материалов ближайшего уровня, сырья и промежуточного крафта до выбранной цели. Учёт по точным itemID: Oriharukon Ore и готовый Oriharukon считаются отдельно. Без цели виден список найденных ресурсов.
- Видны время последнего успешного чтения, ошибка новой попытки, оценочные цены и неподтверждённый уровень вещи вне экипировки. Ошибка сохраняет прежний снимок; поздний ответ после Stop, смены цели, героя, класса или управляющей вкладки не подменяет актуальные данные. Паузы улучшений и состояние оплат сохраняются.
- Все исправления 20.23 и ранее включены. Обновление Chrome — поверх той же папки расширения с предварительным экспортом настроек; затем обновить расширение и вкладку игры.

Проверено при выпуске: полный Node runner 460 PASS / 0 FAIL, синтаксис 54 JS и envcheck 31 модуля, чистый Chrome ZIP из 64 файлов (CRC, manifest/HTML-ссылки, побайтовая сверка со всеми исходниками, профиль без auth/passw). Распакованный архив загружен в Chromium: версия20.24, 205ключейcfg, 0ошибок. На файлах именно этого ZIP пройден настоящий MV3 анализа Маммона: ручной OFF, автоматическое обновление, почта, пять минут, ошибки/смена цели и ширина360px; всеHTTPS-ответы синтетические,0POST/0ошибок. Независимый аудит пакета PASS. Подробности — WORKLOG.

Полный исторический browser-runner, настоящий Firefox/Android и живая игра в быстрый Chrome-выпуск не входят. Проверки функции из PR#282 (24backend+16UI сценариев и независимое ревью) также сохраняются.
