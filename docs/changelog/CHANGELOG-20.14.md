# L2wap Bot 20.14 — панель слева, быстрый старт, РБ до 30 мин, масс-спойл у РБ

18.10.2026. Быстрая Chrome-сборка по просьбе пользователя («быстрая сборка»): 20.13 плюс влитые PR #244–#252. Настройки и память не сбрасываются.

## Что вошло
- **Панель (#244, #246):** вкладки разделов колонкой слева, строка поиска настроек во всю ширину.
- **Кнопки РБ (#245):** «Тур по РБ» и «Эпики» можно выключить; у «Ещё один РБ» своя кнопка выключения.
- **Быстрый старт (#247):** под кнопкой «Старт» — На месте / Автофарм / Рыбалка / Катакомбы.
- **Бой с РБ (#248, #252):** предел боя 20 → 30 мин (`rbMaxKillMin`, миграция заводского значения); тур пропускает РБ за пределом ещё до выбора цели, FA и телепорта.
- **Спойл у РБ (#249):** масс-спойл (Spoil Festival) и AoE/Whirlwind по обычным мобам рядом с РБ. Spoil Festival нужно поставить на панель Bounty Hunter.
- **Банки (#251):** усиленные «Велике зілля HP/MP» (#920044/#920045) пьются раньше обычных.
- **Логи 18.10 (#250):** PvP-опрос с «signal is aborted» больше не валит бота, заряды рыбалки не по 50 шт., меньше спама журнала.

## Проверено / не проверено
Node-тесты (`tests/run-all.cjs`), `node --check`, геттеры модулей, загрузка zip в Chromium. Полные браузерные смоуки не гонялись; в живой игре изменения не проверялись.
