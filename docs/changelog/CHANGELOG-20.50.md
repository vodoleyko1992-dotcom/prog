## Поведение Detect

- Warlord/Dreadnought готовит выбранные в «Баффах» (`nBuffs`) Detect Insect75, Animal87 и Plant104 вне боя. Используются настоящие штатные кнопки native-панели, без новых GET. Общий автоматический список баффов остаётся закрыт для этих навыков; подготовкой управляет отдельная служба.
- При включённых авторолях каждый доступный навык добавляется один раз по ID. Старые собственные баффы сохраняются, английские и украинские имена не создают дубли. Поздно появившийся Plant добавляется отдельно. Выключенные автороли и последующее ручное удаление Detect сохраняются.
- Перед действием проверяются текущий персонаж, Warlord/Dreadnought, выбранная роль, владелец вкладки, Stop, аренда, MP, откат и действующий эффект. Намерение сохраняется с подтверждением записи до клика. Для признания собственного применения нужна квитанция именно этой попытки и свежие сведения о персонаже.
- Неопределённый отправленный результат защищён от повторения на630с; выход из ожидания требует свежего снимка. Короткий переход в той же вкладке допускает перенос собственного подтверждения до30с. Работа подготовки ограничена60с, неудачная попытка откладывает повтор на120с. Эти границы защищают от повторных нажатий и долгого удержания основной задачи.

Постоянные Focus317/Vicious312 из20.49 сохраняются: выбранные стойки Warlord/Dreadnought поддерживаются ON, Focus требует подтверждённую надетую пику; низкий процент MP сам по себе не вызывает OFF.
