# L2wap Bot 10.0.10 — в работе (правки 13.10 по логу 08:58 нового героя alt1)

Лог 13.10 17:54–18:58 (новый Human Fighter «alt1», 1 → 17 ур.): игрок — «не понятна логика выбора моба, выхода на карту и выбора моба». Разбор каждого решения «карта / моб» показал два настоящих бага и одно ожидаемое поведение.

## Цикл «чемпион → отход → тот же чемпион» (18:13:01–18:13:51)

Красный Hook Spider 16 при герое 8 (+8, окно +5): бот зашёл, через 8 с ушёл («не пробиваю: за 8 с снято 3 %… снова попробую, когда вырастет сила»), вышел на карту и сразу снова выбрал того же — пять раз за 50 с, пока игрок не нажал паузу. Причины:
- уровень героя при записи вердикта читался на переходе со страницы боя как 0/1 → «разрыв» вердикта выходил 15–16, при следующем выборе (разрыв 8) вердикт не действовал;
- «сила выросла» срабатывала от скачка среднего ДПС после 1–2 боёв;
- окно уровней (+5) при непрочитанном уровне героя не проверяется вовсе.

Исправлено:
- `content.js heroLvl/heroLevel` — последний ненулевой уровень из шапки запоминается (на переходе между страницами шапка пуста); сброс при смене персонажа;
- `modules/champs.js` — вердикт пишется от уровня героя на входе в бой (`ctx.heroLvl0`), держит **5 мин всегда** (кроме нового уровня), рост урона считается только по устойчивому замеру (ДПС по РБ или ≥ 10 боёв), ДПС из боя «не пробиваю» не запоминается, при неизвестном уровне чемпиона свежий вердикт по цвету держит;
- `modules/mobfarm.js candidates` — чемпион без записи в кэше спавнов берёт имя и уровень из строки списка на экране, окно уровней работает.

## «Не по зубам» по имени вида с чемпиона (18:31:07, Elven Ruins)

Красный Tracker Skeleton 17 (29 880 HP, предел чемпиона 188 с) через 15 с получил общее «не пробиваю — убить ≈134 с → этот вид 2 ч не бью» с меткой по ИМЕНИ, и обычных Tracker Skeleton 996 HP (рядом с ★ целью квеста) бот дважды отказался бить («не по зубам… не бью, на карту»). То же в 18:56:15 с Hook Spider. Теперь у чемпиона метка по имени не ставится — отход идёт через память чемпионов (`champs.learn`, вердикт по цвету до роста силы), `modules/combat.js`.

## Как бот решает сейчас (по коду, простыми словами)

1. После победы — «Охотиться дальше» (цепочка, ≈1–2 с на моба), если моб цепочки не выше героя +5 и не «не по зубам». На карту уходит: раз в N боёв (cfg.deepEvery / champEvery 20), за ★ целью квеста, когда цепочка не сработала, по делу вне боя (магазин, баффы, Маммон).
2. На карте: список «Окрестности» = все мобы вокруг героя по расстоянию (395 строк, 3 страницы по умолчанию). Цель — по приоритету из меню («[квест] → [чемп] → [все]»), внутри приоритета красный/оранжевый FA-чемпион первым, затем по EXP/с вида, уровню (до +5), близости. Отсекаются: ниже героя −5 (FA не падает), выше +5, «не по зубам» 2 ч, чемпион по вердикту/цене/«Cancel».
3. Своих уровней на первых страницах нет — ищет по всему списку («иду к … на стр. 25 без телепорта»); нет нигде — автофарм летит в зону по КПД.
