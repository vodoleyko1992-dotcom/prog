# L2wap Bot 10.0.10 — в работе (правки 13.10 по логу 08:58 нового героя alt1)

Лог 13.10 17:54–18:58 (новый Human Fighter «alt1», 1 → 17 ур.): игрок — «не понятна логика выбора моба, выхода на карту и выбора моба». Разбор каждого решения «карта / моб» показал два настоящих бага и одно ожидаемое поведение.

## Цикл «чемпион → отход → тот же чемпион» (18:13:01–18:13:51)

Красный Hook Spider 16 при герое 8 (+8, окно +5): бот зашёл, через 8 с ушёл («не пробиваю: за 8 с снято 3 %… снова попробую, когда вырастет сила»), вышел на карту и сразу снова выбрал того же — пять раз за 50 с, пока игрок не нажал паузу. Причины:
- уровень героя при записи вердикта читался на переходе со страницы боя как 0/1 → «разрыв» вердикта выходил 15–16, при следующем выборе (разрыв 8) вердикт не действовал;
- «сила выросла» срабатывала от скачка среднего ДПС после 1–2 боёв;
- окно уровней (+5) при непрочитанном уровне героя не проверяется вовсе.

Исправлено:
- `content.js heroLvl/heroLevel` — последний ненулевой уровень из шапки запоминается (на переходе между страницами шапка пуста); сброс при смене персонажа;
- `modules/champs.js` — вердикт пишется от уровня героя на входе в бой (`ctx.heroLvl0`), держит **5 мин всегда** (кроме нового уровня), рост урона считается только по устойчивому замеру (ДПС по РБ или ≥ 10 боёв), ДПС из боя «не пробиваю» не запоминается, при неизвестном уровне чемпиона свежий вердикт по цвету держит;
- `modules/mobfarm.js candidates` — чемпион без записи в кэше спавнов берёт имя и уровень из строки списка на экране, окно уровней работает.

## «Не по зубам» по имени вида с чемпиона (18:31:07, Elven Ruins)

Красный Tracker Skeleton 17 (29 880 HP, предел чемпиона 188 с) через 15 с получил общее «не пробиваю — убить ≈134 с → этот вид 2 ч не бью» с меткой по ИМЕНИ, и обычных Tracker Skeleton 996 HP (рядом с ★ целью квеста) бот дважды отказался бить («не по зубам… не бью, на карту»). То же в 18:56:15 с Hook Spider. Теперь у чемпиона метка по имени не ставится — отход идёт через память чемпионов (`champs.learn`, вердикт по цвету до роста силы), `modules/combat.js`.

## Как бот решает сейчас (по коду, простыми словами)

1. После победы — «Охотиться дальше» (цепочка, ≈1–2 с на моба), если моб цепочки не выше героя +5 и не «не по зубам». На карту уходит: раз в N боёв (cfg.deepEvery / champEvery 20), за ★ целью квеста, когда цепочка не сработала, по делу вне боя (магазин, баффы, Маммон).
2. На карте: список «Окрестности» = все мобы вокруг героя по расстоянию (395 строк, 3 страницы по умолчанию). Цель — по приоритету из меню («[квест] → [чемп] → [все]»), внутри приоритета красный/оранжевый FA-чемпион первым, затем по EXP/с вида, уровню (до +5), близости. Отсекаются: ниже героя −5 (FA не падает), выше +5, «не по зубам» 2 ч, чемпион по вердикту/цене/«Cancel».
3. Своих уровней на первых страницах нет — ищет по всему списку («иду к … на стр. 25 без телепорта»); нет нигде — автофарм летит в зону по КПД.

Тест `tests/v1010-champ-repick.test.js` (+ правка `v1005-champ-hunt`). В живой игре не проверено.

## Сюжетный квест новичка на авто (PR #88)

Лог 13.10 18:17–18:58 (v10.0.8), новый герой **alt1** (Human Fighter, 12 → 17 ур.). Вопрос игрока: «почему не выполняет на авто квесты по прокачке».

## Что было в логе
- 18:17:09 игрок сам открыл письмо «Сюжетный квест», 18:17:15 сам нажал «Взять квест» (POST /game/story-quests/starter-saga/accept), 18:25:23 сам нажал «Телепорт» к Elven Ruins.
- Бот убил 15 из 20 Skeleton (★ в списке локации — цели он видит), 18:31:57 игрок переключил на рыбалку, 18:54:43 снова автофарм — бот улетел по КПД в Neutral Zone (18:17:37 «мобы тут 4–7 ур., а герой 12 → лечу в Neutral Zone»), квест остался 15/20.
- 18:31:07 красный чемпион Tracker Skeleton (29 880 HP) → «не пробиваю — урон ≈174.9/с, убить ≈134 с → этот вид 2 ч не бью». 18:31:15 и 18:31:21 обычный Tracker Skeleton (996 HP) — «не по зубам, на карту» дважды.

## Почему
- Кампания (сюжетные квесты) выключена с 7.2.1 (`once camp721`: игрок на Warlock вёл квесты сам), кнопка «📜 Кампания» в меню спрятана (`hidden`). Код кампании цел, но до него не доходит.
- Даже при включённой кампании страница «Путь новичка» до принятия квеста — без целей, только кнопка «Взять квест» (#starter-story-actions button[data-action=accept]). `campaign()` считала её «главой без целей» и приостанавливала кампанию на 10 мин; кнопку действия жал только `goCampaign`, а на страницу квеста ведёт сам её адрес → `campaign()`.
- «Не пробиваю» за 15 с боя (combat) писал `rt.hardMobs` по имени вида и для чемпиона — 10.0.5 исправил это только в итоге боя.

## Что сделано
- `modules/quests.js`: `sagaNote` — ответ `GET /game/story-quests/starter-saga` (карта опрашивает сама) → `rt.storySaga` {stage, completed, minLevel, lvl, title}. `campAuto()`: квест новичка не пройден, уровень ≥ minLevel и герой **< 40** → кампания включается сама (журнал «веду кампанию сам (авто)», `rt.campAutoOn`); `campEnabled() = cfg.campaign || campAuto()` вместо `cfg.campaign` в campActive/campMobOpen/campOn/campaign(). У Warlock 67 ничего не меняется.
- `campaign()`: страница без невыполненных целей + кнопка действия («Взять квест», «Поговорить», …) → `pressAction` (до 4 раз, потом 10 мин пауза); общий код с goCampaign. `goCampaign`: адрес главы не запомнен, квест новичка идёт → сразу `/starter-story-quest.html`.
- `content.js`: `cfg.campAuto: true` (DEF_CFG), проводка сети → `sagaNote`, геттер `heroLvl` у quests, `campEnabled` в farmGoal / autonomyMode / farmDb; `modules/mobfarm.js`: смена зоны автофарма и farmStep — через `campEnabled()` (кампания держит на точке квеста).
- `modules/combat.js`: «не пробиваю» за 15 с на чемпионе — только выход из боя, вид не метится (обычные мобы вида бьются).
- Меню: кнопка «📜 Кампания» снова видна; «Охота» → галка «★ Сюжетные квесты новичка — вести самому (герой до 40 ур.)» (`campAuto`, вкл.); сводка режима «📜 кампания (авто: Путь новичка…)». `base-profile.json`: campAuto true.
- Тест `tests/v1010-starter-campaign.test.js` (кампания авто по уровню/галке/пройденности, «Взять квест» со страницы, телепорт к точке, предел 4 попыток, прямой переход, проводка, чемпион без hardMobs); обновлены v721-chain, v803-rbbetween, v100-modes. 127 PASS.

Вместе с резервом «не больше половины сумки» (PR #89): 204 960 аден → ≈2 000 зарядов вместо 23. Богатому Warlock ничего не меняется.

- `modules/combat.js`: «Охотиться дальше» подсовывает чемпиона выключенного цвета или того, от кого бот только что ушёл, → нетронутый бой не начинается, на карту (★ квест и чемпион главы — бьются).
- Меню «Охота»: блок «Каких чемпионов бить». `base-profile.json` — те же умолчания.
