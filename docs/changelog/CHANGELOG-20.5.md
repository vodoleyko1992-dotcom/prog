# L2wap Bot 20.5 — рыбалка без зависания покупки наживки

16.10.2026, повторная Chrome-сборка; включает PR #192, #193, #195 и #197 поверх20.4.

- #197: исправлено наложение панелей при масштабе ×2; адаптивная сетка задач и отдельная полоса кнопок. #196 обновляет рабочие инструкции и в runtime не входит.
- #193: подтверждение оплаты баффов РБ по точной native-квитанции и восстановление старой оплаты по однозначному журналу, без повторного списания. Недоказанный результат остаётся заблокированным.
- #195: меню обнаруживает несовпадение версии файлов и зарегистрированной версии Chrome, показывает уведомление и кнопку перезапуска. Замена файлов под тем же номером версии не обнаруживается; после установки повторной20.5 нажать ↻ расширения вручную.

Пересборка:353Node-файла PASS; до #197 полный браузерный прогон с полным повтором одного исправленного теста, после #197 — новый layout и повторы затронутых UI. Всего79уникальных браузерных файлов; два DOM-теста пропущены. ZIP64файла, Chrome20.5,cfg209,errors0; скачивание побайтно проверено. Результаты первоначального ZIP ниже относятся к прежнему составу; подробности пересборки в WORKLOG.

В журнале07:48 бот остановился на покупке наживки:17:47:24–17:48:45 ждал подтверждения. Native-магазин при focus/GET перерисовывает кнопки; клик по старой удалённой кнопке не доходил до обработчика, а намерение уже считалось отправленным. После ручной покупки рыбалка продолжалась.

Теперь после асинхронной подготовки бот заново находит строку/кнопку, сверяет количество, цену и итог. Отсутствующая, удалённая, скрытая или disabled-кнопка отменяет только ещё не отправленное намерение. Настоящий неизвестный ответ на уже отправленную оплату сохраняет защиту от повторной покупки. Настройки игрока и профиль не меняются; автоматическая покупка времени остаётся управляемой своей настройкой.

Механизм воспроизведён на публичном renderer с синтетическими API. 349Node-файлов и76уникальных браузерных файлов прошли с учётом полных повторов; два старых DOM-теста пропущены без снимков. Подробные результаты выпуска и архива — в WORKLOG. При выпуске аккаунт не открывался. Отдельная причина пропуска обучения Reeling по обрезанному журналу не установлена; эта сборка не объявляет её исправленной. Подробности — [разбор журнала](../FISHING-LOG-2026-10-16-0748.md).
