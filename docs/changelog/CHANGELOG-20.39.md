# L2wap Bot 20.39 — переходы катакомб

Включён PR#314: после выбора следующего моба старый экран победы больше не запускает повторный выбор/навигацию до ухода документа. В журнале20.10,19:36:24 команда следующего боя сменялась повторной загрузкой и возвратом в подземелье через239мс. Ожидание ограничено10с, отменяется поStop/контексту и не задерживает цикл нового документа.

Быстрая сборка Chrome по прямой команде игрока «сборка быстрая». Исправленный VIP Greater из20.38 и прежние настройки сохранены. Firefox20.36 не пересобирается. В ходе выпуска меняются только версия/описание/инструкции; игровой код остаётся из слитого исправления.

Проверки выпуска — [доказательства](../evidence/build-20.39/validation.json). Браузер использует локальные ответы. Живую игру не открывали, фактический прирост скорости фарма не измерен; полный исторический browser-runner не запускается в быстрой сборке. После установки нужен полный боевой лог.
