# L2wap Bot 20.23 — Chrome и Firefox

19.10.2026. База 20.22 + PR #279/#280 и исправление Маммона по журналу 07:27, обе быстрые сборки по прямому запросу.

- После снятия «Тура РБ» его сохранённая сессия завершалась только внутри уже выключенного тура и бессрочно блокировала Маммона. Теперь снятый тур завершает сессию на границе списка задач, сохраняя покупки и статистику. Реальная активная сессия и неподтверждённые оплаты по-прежнему защищены; новый запуск сессии сохраняется атомарно с разрешением тура. Отложенная отмена старой сессии не затирает новый запуск.
- По журналу 19.10 перед поражениями Barakiel, Skylancer и Sheshark бот простаивал 20–47 с. Нативные Whirlwind/Wild Sweep теперь освобождаются по точному серверному дедлайну с прежними защитами. Готовый удар не отбрасывается ради недоступной атаки; раннее восстановление интерфейса после 6 с работает и у воина.
- Одно поражение больше не увеличивает счётчик после каждого Start. История, восстановление и счётчики сохраняются вместе до остановки; ошибка записи вызывает явный стоп. Ручное воскрешение и autoRevive сохраняются.
- Исправлен отдельный дефект общего резерва HP: обычные и усиленные банки учитываются вместе, вместо блокировки лечения по запасу одного вида. Эта ошибка не объясняла три поражения с остатками 68/63/37 при резерве 10.
- Включены все изменения 20.22 и ранее. Настройки и допустимые уровни боссов сохраняются. Firefox ZIP неподписан; инструкции в README-CHROME.txt и README-FIREFOX.txt.

Проверки и итоговые результаты — WORKLOG: полный Node runner, синтаксис/envcheck, целостность и сверка обоих ZIP, Chrome ZIP в Chromium, Firefox lint. 18 новых сценариев Маммона и настоящий MV3 перехода между задачами PASS. Проверки предыдущих исправлений выполнены в PR #279/#280, включая 76 новых сценариев боя/восстановления и MV3 с застывшей панелью. Полный исторический browser-runner, настоящий Firefox/Android и живая игра в быструю сборку не входят. Точный смертельный удар в журнале обрезан; нужен контрольный журнал установленной версии.
