# L2wap Bot 20.25 — Chrome

19.10.2026. Быстрая сборка по запросу игрока. Основа — последняя успешная Chrome20.24 + PR#284/#285/#286. Firefox остаётся20.23.

- Обмен камней печати на АА теперь обслуживается диспетчером: по кнопке и автоматически, в том числе при «Только задачи». Новая команда не стирается отменой прежнего маршрута. После запуска изOFF бот снова выключается; остатки в меню обновляются сразу. Бой, улов, TvT и заточка откладывают обмен; авто не прерывает заход на РБ/эпика.
- Бесплатный полный городской бафф на время действующего VIP: воин/спойлер → warrior, маг → mage. Работает при выбранном обычном наборе и включённой галочке рядом с ним. Перед применением проверяются серверныйVIP и обе нулевые цены; запрос ограничен0адены/0CoL. По окончанииVIP — обычный набор. ПокупкаVIP и автоматические Greater/резисты не добавлены; summon остаётся платным и в этот набор не входит.
- Выбор конкретного оружия для ЛС: надетое и C/B/A/S из рюкзака. Чтение доступно приOFF. Выбранную вещь из рюкзака нужно сначала надеть вручную. Перед серией сверяется тот же экземпляр; другая надетая вещь не подменяет цель.
- Все изменения20.24, включая анализ рюкзака в Маммоне, сохранены.
