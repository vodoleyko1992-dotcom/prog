# 20.53 — Chrome, 23.10.2026

Быстрая сборка Chrome по просьбе игрока «собери на хром» (после «все ок жду»). Основа — `6d5a875` ветки по умолчанию: всё влитое после 20.51, включая PR, которых не было в Chrome/Firefox 20.52 из черновика [PR #370](https://github.com/vodoleyko1992-dotcom/prog/pull/370). Firefox и Lite не пересобирались.

## Что нового по сравнению с 20.51

- **Скорость** ([#371](https://github.com/vodoleyko1992-dotcom/prog/pull/371), [#372](https://github.com/vodoleyko1992-dotcom/prog/pull/372)): отдельный раздел «Скорость», дополнительная пауза между действиями 0–5 с с шагом 0,1 с. По умолчанию **0 — без задержки**; свои положительные значения сохраняются, серверные откаты и Stop не меняются.
- **Заряды по оружию** ([#373](https://github.com/vodoleyko1992-dotcom/prog/pull/373), журнал 22:41): перед заменой слота зарядов другого грейда бот сверяет надетое оружие свежим GET /character; заряды A больше не меняются на B по старой памяти. Ошибка сети оставляет панель как есть.
- **Ручной телепорт к РБ** ([#375](https://github.com/vodoleyko1992-dotcom/prog/pull/375), журнал 23:17): если игрок сам нажал «Телепорт», пока бот готовил оплату, тур не зависает на «исход телепорта не подтверждён»; бесплатный перелёт без квитанции снимается через 15 с.
- **Noblesse** ([#369](https://github.com/vodoleyko1992-dotcom/prog/pull/369)): нет цикла «Мои квесты ↔ страница Noblesse» каждые ~4 с; бот возвращается на карту к ★ целям.
- **Кот** ([#368](https://github.com/vodoleyko1992-dotcom/prog/pull/368)): на активном Warlock / Arcana Lord задача «Автобаф суммона» включается сама.
- **Опасные РБ** ([#367](https://github.com/vodoleyko1992-dotcom/prog/pull/367), журналы 02:08/02:15): после выхода без подтверждения бот сверяет бой и не входит повторно в тот же РБ; HP-банка не тратится при полном HP; восстановление сверки сумки работает и на странице подземелья.
- **Сумка** ([#365](https://github.com/vodoleyko1992-dotcom/prog/pull/365)): после затяжных отказов проверки сумки карта обновляется сама (с проверками и паузой 5 мин).
- **Detect Monster 80 / Dragon 88** ([#366](https://github.com/vodoleyko1992-dotcom/prog/pull/366)): Monster поддерживается боевой кнопкой, Dragon не жмётся как удар.
