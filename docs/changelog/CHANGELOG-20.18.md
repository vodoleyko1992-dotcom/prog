# L2wap Bot 20.18 — Chrome и Firefox

19.10.2026. Быстрая сборка по прямой просьбе игрока, база20.17 с PR #265–#268.

- Групповые убийства учитываются по полному ответу боя, даже когда добыча вытеснила строки из короткого журнала. Одинаковые имена мобов сохраняются, поздний рост сервера не дублирует результат; учитываются соседи, убитые перед поражением.
- После обновления страницы рыбалка восстанавливает подтверждённую попытку по квитанции запроса, включая потерю netStart и отключённый журнал. Неизвестный исход без доказательств не повторяется вслепую.
- Десять разделов меню: отдельно Маммон, автозаточка, ЛС и сервис.
- Каталог21эффекта ЛС, выбор цели и явная серия с лимитом, только имеющиеся материалы; неизвестный исход блокирует повтор.
- Отдельные Chrome и Firefox128+ пакеты и инструкции. Firefox ZIP неподписан: временная установка на ПК, для постоянной установки и обычного Android требуется подпись Mozilla.

Проверки: полный Node runner, синтаксис JS, envcheck; загрузка распакованного Chrome ZIP в Chromium; выборочные MV3 счётчика и рыбалки; Firefox manifest/background и lint. Точные результаты — WORKLOG. Полный исторический browser-runner, настоящий Firefox/Android и живая игра в быстрой сборке не проверяются.
