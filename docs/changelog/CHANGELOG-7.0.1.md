# L2wap Bot v7.0.1 — критическое исправление Chrome

Дата: 09-10-2026.

- Исправлен вызов native `setTimeout` и `clearTimeout` в `L2EngineCore.withTimeout`. В Chrome присваивание нативного таймера полю объекта и вызов через это поле может приводить к `TypeError: Illegal invocation`.
- Ошибка ранее нарушала IPC и сохранение состояния, после чего срабатывали восстановление, перезагрузка и пауза.
- Добавлен браузерный регрессионный тест вызова `withTimeout`, проверки IPC, записи `setRt` и функций модуля рыбалки.
- Все остальные игровые алгоритмы сохранены без изменений.

## Ограничения

Проверка проведена в Chromium в изолированном тестовом DOM, без подключения к серверам игры. Фактическая работа в игре требует проверки.
