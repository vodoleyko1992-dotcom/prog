# 8.0.8 — планшетная раскладка только на Android

Игрок 11.10: «основная версия не нужна под андроиды всякие, там ничего не меняем» и «сборка фаерфокс-модели только по моему запросу, стандартно собираем основную модель».

## Что сделано
- **Раскладка для планшета из 8.0.7 включается только на Android** (по userAgent). Это свёрнутое меню поверх игры, язычок под палец, индикатор в 3 строки, меню вкладкой на весь экран. На ПК всё как в 8.0.6: в узком окне меню открыто компактно (380 px), индикатор полный, окно значка не меняется.
- Остальное из 8.0.6/8.0.7 на ПК ни на что не влияет: проверки «есть ли горячие клавиши/значок» в фоне, viewport, отключение раздувания шрифта.
- **Сборка:** стандартно — только основная версия (Chrome). Пакет Firefox (ПК/Android) — только по запросу (правило записано в CLAUDE.md и в навык сборки).

## Проверено / не проверено
**Проверено:**
- 152 PASS, node --check, геттеры модулей;
- смоук v807-tablet-browser в Chromium в двух режимах. Обычный ПК: широкий экран — меню рядом с игрой; узкое окно — меню открыто компактно 380 px, индикатор полный, меню вкладкой не меняется. Android-планшет: свёрнутое меню, язычок, индикатор прячется, меню вкладкой на весь экран;
- остальные смоуки, zip загружен в Chromium.

**Не проверено:** на живом планшете.
