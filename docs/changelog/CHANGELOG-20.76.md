# Chrome + Firefox20.76 — переключение Rebirth→фарм РБ

Сборка по просьбе «сборка» с сохранением прежнего «без проверок». База9b6996b / PR #447.

Журнал06:42: после переключения на тур РБ старая победа Rebirth вызывала выключенный обработчик и оставляла героя на месте9мин до сторожа. Теперь завершённый бой после сохранения памяти и проверок контекста бесплатно выходит на карту к выбранному режиму. Живой бой не прерывается; старый hunt не нажимается; run и квитанции сохраняются. Активный Rebirth продолжает работать прежним способом.

Дополнительный журнал06:45 показывает работающий тур, закупку, бои и победу Sebek. Ручные повторные входы в нём не объявлены автоматическим циклом; тактика боя в20.76 не менялась.

При упаковке тесты, синтаксис, envcheck, браузеры, линтеры, privacy, аудит архива и проверка скачивания не запускались. Новых PASS нет; прежние699Node-файлов/119целевых относятся только к исправлению #447 до упаковки. Живую игру не открывали. Включены прежние исправления20.75.

Только Firefox128+ПК/Android, прежний Gecko ID и профиль, пакет неподписан. Chrome20.71/rollback20.66/Lite1.8.1 не пересобирались. Далее обновить дополнение и вкладку в прежнем профиле, получить лог смены режима на победе и в живом бою.


## Дополнительная сборка Chrome20.76

По просьбе «Сборка на Хром» упакована та же функциональная база9914ec3 / PR #448, включающая исправление #447 и предыдущие изменения20.72–20.75. Номер20.76 сохранён. Исходный Chrome MV3 с service_worker и minimum_chrome_version116 используется без Firefox-преобразования manifest; функциональный код при упаковке не меняется.

Прежняя просьба «без проверок» сохранена: тесты, синтаксис, envcheck, браузеры, линтеры, privacy, аудит ZIP и проверка скачивания не запускались. Новых PASS нет; исторические699Node/119целевых выше относятся к исходному исправлению #447, не к сборке Chrome. Живую игру не открывали.

Chrome20.71 оставлен для отката; Firefox20.76 и Lite1.8.1 не пересобирались. Обновление Chrome: распаковать поверх прежней папки, нажать ↻ в chrome://extensions и обновить вкладку игры. Далее нужен контрольный журнал переключения Rebirth→тур РБ на победе и в живом бою.
