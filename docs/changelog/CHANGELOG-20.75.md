# Firefox20.75 — восстановление Rebirth без вечного ожидания

Сборка по просьбе «сборка без проверок», на основе PR #445 (`4978d6e`).

В журнале06:11 версия20.74 восстановила HP после смерти, затем остановилась на missing-run до ручного входа. Теперь смерть своего похода и успешное собственное восстановление подтверждают повторный вход при включённом AutoEnter и свежем отсутствии run на сервере. Сложность, цена, резерв, квота и лимит смертей сохраняются. Неизвестная оплата не повторяется; несделанный клик и явный отказ сервера не оставляют вечного ожидания.

Старый экран победы при свежем activeRun:null возвращает в бесплатный каталог по точной связи героя и боя. Квитанция продолжения сохраняется, старый hunt не повторяется. Свежая победа РБ доводится до штатного next/none.

Для существующего зависшего состояния без нового маркера смерти нужен один ручной Start после обновления. Далее новые смерти записываются автоматически.

Проверки сборки, скачивания, тесты, синтаксис, envcheck, браузеры, линтеры, privacy и аудит архива не запускались по прямой просьбе пользователя. Новых PASS нет. Прежние698Node-файлов и125целевых сценариев относятся к исправлению #445 до упаковки, не к Firefox20.75. Живую игру не открывали.

Только Firefox128+ (ПК/Android), прежний Gecko ID и формат профиля; пакет неподписан. Chrome20.71 и Lite1.8.1 не пересобирались.
