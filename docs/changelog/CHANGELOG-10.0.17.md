# L2wap Bot 10.0.17

Chrome-сборка от15.10.2026 по прямой команде «сборка», включает влитые PR119–121.

## Что вошло

- Автозаточка вынесена из «Боя» в самостоятельный раздел и режим с быстрой кнопкой. Очередь, лимиты и аналитика сохранены. Серия запускается явно, смена режима ставит её на паузу, завершение не возобновляет фарм.
- Обычный тур РБ выбирает подходящих боссов снизу вверх по уровню. Исправлены пропуск первых страниц, устаревшая цель и ожидание после изменения условий; меню показывает реальные причины пропуска.
- Flame Strike: основной удар и дополнительные цели учитываются раздельно, урон не выдаётся за лечение. Учтён лог16:20; тактика мага не изменена.
