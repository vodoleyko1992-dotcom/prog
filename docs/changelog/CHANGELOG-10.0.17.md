# L2wap Bot 10.0.17

Chrome-сборка от15.10.2026 по прямой команде «сборка», включает влитые PR119–121.

## Что вошло

- Автозаточка вынесена из «Боя» в самостоятельный раздел и режим с быстрой кнопкой. Очередь, лимиты и аналитика сохранены. Серия запускается явно, смена режима ставит её на паузу, завершение не возобновляет фарм.
- Обычный тур РБ выбирает подходящих боссов снизу вверх по уровню. Исправлены пропуск первых страниц, устаревшая цель и ожидание после изменения условий; меню показывает реальные причины пропуска.
- Flame Strike: основной удар и дополнительные цели учитываются раздельно, урон не выдаётся за лечение. Учтён лог16:20; тактика мага не изменена.

## Проверки

- 223 Node-файла PASS; синтаксис runtime JS, envcheck28 фабрик и отсутствие auth/пароля в базовом профиле проверены.
- ZIP: 60 файлов,1186924 байта, SHA256 `de1c6fe44f996e148d1948cd63be3ab4f1a30a23948573ca3b10ffceef7efbbc`. Все файлы совпадают с исходниками; зависимости manifest/popup присутствуют, tests/kb/docs/.git/.claude исключены.
- Архив распакован и загружен в Chromium: MV3/popup10.0.17,207 ключей cfg, бот выключен, auth отсутствует, самостоятельная навигация и быстрая кнопка автозаточки,0 ошибок JavaScript.
- Общий `smokes.sh` и точечные повторные запуски:46 браузерных скриптов PASS. Два DOM-теста пропущены без исходных снимков; Firefox не запрошен. Первый общий прогон дал15 ошибок: устаревшие fixtures/счётчики разделов, обращение Node fetch без облачного прокси и два нестабильных запуска. Все упавшие и четыре сетевых пропуска проверены повторно; итогов с ошибкой не осталось. Внешний снимок теста явно помечен `_src:menu`, контекст настоящего fire включает PvP guard; проверки сценариев не удалены.
- Для публичных скриптов игры Node24 использует `NODE_USE_ENV_PROXY=1`, когда настроен HTTP(S)_PROXY; авторизованные игровые ответы во всех сценариях локальные.
- Публичная ссылка скачана заново: файл побайтно совпал, SHA256 тот же.

 Живые покупки, заточки и атаки при сборке не выполняются; браузерные проверки используют локальные ответы. Firefox не запрошен.

Распакуйте поверх прежней папки расширения и нажмите ↻ в chrome://extensions, чтобы сохранить память.
