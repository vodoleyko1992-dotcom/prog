# L2wap Bot v7.1.4 — Raid Safety

- Убраны ошибочные локальные откаты HP/MP-банок из Interlude; серверный общий КД сохранён.
- Очищаются устаревшие значения КД банок без сброса остальной статистики.
- Вне боя расчёт запасов HP-банок берётся из последней проверенной сумки, затем из наблюдений боевого интерфейса.
- Добавлена оценка спецудара и p90 обычного удара для индивидуального РБ.
- Усилена проверка до платного телепорта с учётом прежнего вердикта и запаса банок.
- Уточнены адаптивная полоса HP и предпочтение банок перед вампиризмом в опасном бою.
- Лечение импульсами учитывается по одному импульсу, а не как одномоментные 4.5 секунды регенерации; для предварительного прогноза принят наблюдавшийся минимальный интервал 2.2 с.
- В меню добавлена отключённая по умолчанию экспериментальная настройка отступления с обычного РБ.
- Экспериментальный режим отхода с обычного РБ реализован за флагом `rbChipRetreat=false` (по умолчанию выключен): необходимы реальные тесты и подтверждение сервером.
- Прежние пользовательские настройки и модульная архитектура сохранены.

**Ограничение:** изменения в живой игре ещё не проверены, исходные расчёты из ТЗ не являются гарантией результата.
