# Chrome 20.78 — Rebirth без цикла у баффера

29.10.2026. Сборка основной Chrome-версии по прямой просьбе John «сборка без проверок». База `ab52b0b` после [исправления #453](https://github.com/vodoleyko1992-dotcom/prog/pull/453).

## Что изменилось

В Chrome20.77 с09:51 до10:28 бот491раз отправлялся из каталога Rebirth к бафферу при полных5198/5198HP и2271/2271MP. Каталог планировал бафф по свежему серверному снимку, а восстановление — по HUD/старой памяти VIP; нужный шаг пропускался и маршрут начинался снова.

Собственное восстановление Rebirth теперь использует уже полученный и проверенный свежий снимок героя, как каталог. Проверки владельца, Stop, класса/слота, ревизии и нулевой цены сохранены; сильные баффы не понижаются. Обычный маршрут не менялся, новых GET/разрешений трат нет. Подробности — [разбор цикла](../REBIRTH-BUFF-LOOP-2026-10-29.md). Все исправления ревизии20.77 включены.

## Упаковка и границы

Только основная Chrome MV3/service_worker, Chrome/Chromium116+. Firefox20.76 и Lite1.8.1 не пересобирались. Функциональный runtime при упаковке не менялся: обновлены version/version_name/description, первая строка content.js и пять ожиданий версии в тестах, README и история.

По прямой просьбе **«сборка без проверок»** не запускались Node-тесты, синтаксис, envcheck, браузеры, линтеры, privacy, аудит ZIP и проверка скачивания. Новых PASS нет. Прежние715Node/2Chrome и связанные143сценария относятся к исходному исправлению #453 до этой упаковки; не являются проверкой Chrome20.78. Живую игру не открывали.

ZIP сформирован по явному списку69файлов Chrome20.77 из текущих исходников. Chrome20.77 оставлен для отката. Старый Chrome20.76 сохранён в work/build-20.78-chrome и git-истории, убран из текущихZIP; SHA256-история сохранена, внешняя папка сборок недоступна.

Обновление: остановить бота, сохранить экспорт, распаковать поверх прежней папки, нажать ↻ в chrome://extensions/ и обновить вкладку игры. Далее нужен короткий журнал подготовки у баффера и возврата в Rebirth. Открытый вопрос постоянного отказа резерва адены после бафа кота этим исправлением не менялся.
