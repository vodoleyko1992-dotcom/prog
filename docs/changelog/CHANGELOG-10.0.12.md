# L2wap Bot 10.0.12 — новая пагинация списка мобов

14.10.2026, сборка по просьбе пользователя, PR #103.

Игра заменила строку «5 / 27 (398)» кнопками «1 2 3 4 5 >>». Старый бот не распознавал готовый список: `pagerInfo()` возвращал `null`, навигация к странице выбранного моба прекращалась.

Теперь бот читает текущую страницу и количество мобов из `data-l2-around-sig`, нажимает нужный номер в текущей группе и переключает группы по пять страниц через `>>`/`<<`. Номер страницы в подписи игры начинается с нуля; для кнопок он переводится в обычную нумерацию. Старые индикатор и стрелки поддерживаются. При отказе клика или отсутствии смены списка попытка завершается без бесконечных нажатий.

Добавлены Node-регрессии и Chromium DOM-проверка переходов 1 → 24 → 3, последней неполной группы, единственной страницы и отказов. В UI-смоуке путь для скриншотов использует `L2_SHOTS` либо `/tmp`, чтобы проверка работала без записи в `/mnt/data`.

Проверки сборки: все 134 файла `node tests/run-all.cjs` прошли, синтаксис 201 JS/CJS-файла и все 25 геттеров модулей проверены. Прошли 23 доступных сценария стандартного набора смоуков (после повторного запуска UI-сценария с доступным путём скриншотов и двух сценариев с прокси/браузерным User-Agent), отдельный Chromium DOM-тест пагинации и загрузка распакованного ZIP (версия 10.0.12, ошибок JavaScript 0). Два сценария боя на снимках страниц заблокированы отсутствием исходных HTML; Firefox не проверялся и не собирался.

Работа установленного бота с новой пагинацией на сервере игры пока не подтверждена: пользователь проверяет сам. Обновление — распаковать поверх той же папки расширения и нажать ↻ в `chrome://extensions`, чтобы сохранить настройки.
