# L2wap Bot20.34 — авто-ЛС во встроенном меню Firefox

Скрин20.10 14:31 UTC+10 показал точную ошибку: chrome.tabs is undefined. Встроенный iframe Firefox имеет runtime/storage, но не tabs. Старые браузерные проверки запускали отдельное окно меню и не покрывали этот путь.

- Все кнопки ЛС во встроенной панели передают команду через фон в родительскую игровую вкладку, верхний frame0. Фон проверяет отправителя/страницу/героя; существующие проверки lease, Stop, контекста, неизвестной попытки и точного оружия сохранены. Расход не запускается при чтении.
- В отдельном меню скан выбирает подтверждённую вкладку нужного героя. Проверка адресата не захватывает управление, не читает сервер и не отправляет команду в каждую вкладку.
- Постоянный статус чтения/результата/ошибки рядом с кнопкой, блокировка повторного клика до завершения. Предыдущий список и черновики сохраняются, смена героя убирает прежнее сообщение.
- Безопасные диагностические причины HTTP/таймаута/JSON/формы инвентаря и каталога записываются в журнал. Весь GET с телом ограничен8секундами; платёжная серия использует прежние проверки и счётчики.

Проверки и доказательства — HANDOFF/WORKLOG и docs/evidence/build-20.34/. НастоящийFirefox проверяется на локальном HTTPS-стенде, Chrome — actual-MV3 и модель ограничения tabs iframe. Живую игру и Android не открывали. FirefoxZIP неподписан: временноabout:debugging, перед закрытием экспорт настроек.

Останови бота, сохрани экспорт, замени файлы в той же папке, перезагрузи расширение и обнови вкладку игры.
