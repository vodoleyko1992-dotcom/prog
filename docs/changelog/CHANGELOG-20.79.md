# Chrome 20.79 — меню без раннего postMessage

29.10.2026. John: «сборка» после исправления предупреждения меню; сохранена предыдущая просьба «без проверок». Только основная Chrome-версия, база `22349ac` / [PR #455](https://github.com/vodoleyko1992-dotcom/prog/pull/455).

Первое сообщение доку уходило сразу после добавления iframe, пока его окно ещё имело origin страницы игры. Chrome сообщал в content.js:4790: `The target origin provided ... does not match the recipient window's origin`. Это предупреждение браузера, try/catch его не скрывал.

Теперь состояние отправляется после сигнала готовности текущего iframe. Готовность связана с его WindowProxy; после пересоздания новое окно ждёт собственного сигнала, старый/посторонний источник игнорируется. Точный адрес расширения сохранён. Игровые действия и оплаты не менялись. Включён прежний фикс цикла Rebirth/баффера20.78; подробности — [отчёт](../DOCK-MIN-READY-2026-10-29.md).

Во время упаковки функциональный runtime не менялся: только version/version_name/description, первая строка content.js, пять ожиданий версии, README и история. Chrome MV3/service_worker/minimum116 сохранены. Firefox20.76/Lite1.8.1 не пересобирались.

По сохраняющейся просьбе **«без проверок»** Node/syntax/env/browser/lint/privacy/ZIPaudit/download не запускались. Новых PASS нет; прежние716Node/2Chrome и55целевых сценариев относятся к исходному исправлению #455 до упаковки, не к Chrome20.79. Живую игру не открывали.

ZIP сформирован по списку69файлов Chrome20.78 из текущих исходников. Chrome20.78 оставлен для отката; старыйChrome20.77 сохранён в work/build-20.79-chrome и git-истории, убран из текущихZIP. SHA-история сохранена, внешняя папка сборок недоступна.

Обновление: остановить бота, сохранить экспорт, распаковать поверх прежней папки, нажать ↻ в chrome://extensions и обновить вкладку игры. Далее контроль появления/сворачивания меню без нового предупреждения. Постоянный отказ резерва адены после бафа кота остаётся отдельным открытым вопросом.
