# L2wap Bot 20.38 — дополнительный VIP Greater

Исправлена повторная жалоба после Chrome20.37: скриншот и сохранённый реальный каталог показывают выбор отдельной Greater-иконки (`pickByIcon:true`). Прежний код отправлял только `set:greater`, а тестовый сервер ошибочно применял все7 эффектов одновременно. Старые проверки не доказывали работоспособность дополнительного баффа.

Теперь запрос содержит выбранный `skillId`; в квитанции один совместимый Greater, Noblesse1323 отдельно. Для мага по умолчанию Water1357, для воина Pa’agrio1414; явный список имеет приоритет, уже действующий совместимый Greater сохраняется. Результат принимается по свежему собственному персонажу, ревизии, выбранным эффектам и классу. Старые base-only/all7 квитанции и зависший bulk-запрос перепроверяются и восстанавливаются.

Сильный обычный бафф не отменяет отдельную Greater-иконку и не понижается; неполный основной набор не объявляется полным VIP. После уже полученного основного набора дополнительный запрашивается сразу; настоящий отказ сохраняет задержку повторной попытки. Изменение выбора, Stop, класса и владельца перед POST отменяет старое действие. Цена каждого запроса должна быть подтверждена0/0; неизвестный исход не повторяется вслепую.

Исправленный Chrome выпускается как продолжение установки20.37, о дефекте которой сообщил игрок. Настройки/базовый профиль сохранены; Firefox остаётся20.36. Проверки — `docs/evidence/build-20.38/validation.json`.

Границы: используется реальный сохранённый каталог/DOM и строгая локальная модель сервера. Живой запрос из аккаунта не выполнялся, wire-payload Greater непосредственно не снимался; чтение публичного town-buffer.js вернуло403, обходов не было. После установки нужен контрольный лог фактического применения.
