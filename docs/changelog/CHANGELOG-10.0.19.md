# L2wap Bot 10.0.19

Chrome-сборка от 15.10.2026 после сообщения игрока, что клановый S-кастер +25 уже надет. Включает PR #129 поверх 10.0.18.

## Что исправлено

- При S-оружии старые заряды души на панели больше не считаются запасом благословенных S-зарядов духа. Бот пересчитывает сумку и докупает подходящие заряды по настройкам закупки.
- При замене заряда на панели учитываются и грейд, и тип. Старый неподходящий заряд не активируется.
