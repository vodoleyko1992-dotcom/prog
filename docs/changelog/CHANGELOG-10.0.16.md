# L2wap Bot 10.0.16

Тестовая Chrome-сборка от14.10.2026 по прямой команде «тест сборка сейчас». Включает готовые PR114–117 и исправление кланового кастера.

## Что вошло

- Обучение у магистра сразу после включения и при каждом новом уровне.
- Отдельная автоматическая заточка оружия/брони с очередью, лимитами и аналитикой; неизвестные результаты не повторяются автоматически.
- Warlock: отдельный раздел, автобаф кота, лечение/перепризыв и общая модель вампирика/РБ по логам15:01–15:10.
- PvP: отдельный раздел, точные цели и ранний штатный возврат после смерти от игрока.
- Клановый кастер распознаётся как S с требуемым уровнем76. При +25 его M.Atk694 сохраняется вместо Daimon A+8 с M.Atk215. Неизвестное оружие не заменяется по предположению; грейд зарядов сверяется заново перед включением и покупкой.

Свежая доработка Flame Strike по логу16:20 **не включена**: она остаётся отдельной следующей правкой. Предыдущие проверки и ограничения функций описаны в MAGISTER, AUTO-ENCHANT, WARLOCK, PVP и CLAN-WEAPON-SELECTION в docs.

- Исправление кланового оружия:4 actual MV3/main сценария с локальными API — сохранить S, надеть точный экземпляр, отказ метаданных, обычное A.

Полный длинный smokes.sh повторно ради срочного номера версии не запускался. Старые DOM smoke без требуемых снимков остаются пропущенными; Firefox не запрошен.
