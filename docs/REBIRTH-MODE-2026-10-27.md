# Отдельный режим подземелий Rebirth

Запрос John: бот не фармит подземелья Rebirth, нужен отдельный режим. Выбраны Easy по умолчанию и галочка автоматического повторного входа. При выключенной галочке игрок входит вручную, бот продолжает уже открытый поход. По новым TXT/learn03:20 игрок дошёл до конца и выбрал РБ с одноручным посохом. Вложения используются только как данные игры.

## Что подтвердили журналы

В02:58 после ручного входа старый набор задач оставался без фарма; затем игрок включил farm. Ранее открытый обычный бой давал `rebirth_raid_in_battle`409 при попытке входа. Старое продолжение Rebirth работало внутри боя, но отдельной задачи и маршрута из каталога/инстанса не было.

Полный цикл03:20: 300обычных мобов → native `GET /game/rebirth-raids/next?after=…mob_300` → `phase:champion` → победа над Rebirth Champion · Wasp Worker → экран выбора одного из16РБ. Имя фазы до выбора не попало в экспорт; оно не выдумывается.

Ручной выбор: `POST /game/rebirth-raids/enter-boss`, `{bossSlot:3}`. Ответ: `phase:rb_active`, `selectedBossSlot:3`, `selectedBossSlotEncoded:true`, `selectedBossSpawnId:l2dop_rb_25098`. Это закодированный слот, не порядковый индекс DOM. Далее `/rebirth-raid-lair.html`, Rebirth Sejarr’s Servitor, победа и native next → `{phase:none,spawnId:null}`. После этого новый ручной Easy `{difficulty:1}` успешен. Связь выбранного РБ с одноручным посохом подтверждает пользователь; фактический выпавший предмет журналом не доказан. Названия/слоты остальных15РБ не восстановлены.

## Поведение режима

- Основная задача `rebirth`, панель «Подземелья Rebirth». Easy1 по умолчанию; Medium2/Hard3 доступны как настройки, подтверждённые меню цены2/4/6ключей проверяются перед новым входом.
- `rebirthAutoEnter:false`: автоматическое списание ключей изначально выключено. Галочка разрешает новый вход с выбранной сложностью при отсутствии похода и повтор после подтверждённого завершения. Настройка резерва ключей учитывается до оплаты.
- Уже оплаченный собственный одиночный поход продолжается независимо от галочки и выбранной сложности следующего входа. Чужой/групповой/неполный контекст ждёт проверки. Незаконченный собственный бой заканчивается прежде нового входа.
- Режим удерживает маршрут Rebirth после общих приоритетных служб и ручных команд, не уходит в обычный фарм. Уважает Stop, владельца вкладки, героя, профессию/слот, поколение действий, PvP/TvT, антибот и общий дневной лимит мобов. У Rebirth нет отдельной сессионной цели автофарма; его убийства входят в общий счёт мобов.
- Продолжение использует существующие кнопки игры: каталог → активный инстанс → бой; при пустой странице — числовой переключатель страниц. ID следующего моба арифметически не вычисляется. После300 разрешены чемпион, выбор РБ и логово.
- Выбор РБ по умолчанию ручной. Дополнительный вариант «одноручный посох» использует только наблюдённый `{bossSlot:3}` после свежего собственного одиночного похода,300мобов, текста победы над чемпионом и16доступных ворот. Остальные варианты не придумываются.
- Новый платный вход использует нативную кнопку после проверки видимого баланса и изолированной цены выбранной сложности. Неизвестная цена/валюта/исход запроса запрещают повтор. Подготовка Start вызывается только перед новым входом; текущий поход возвращается под управление Rebirth после более приоритетных служб, например обучения у магистра.
- Отправленные вход/бой/выбор РБ сохраняют ожидание результата. Потерянный ответ сверяется свежим собственным run; произвольное исчезновение похода не разрешает новый расход. Завершение требует native next→none из подтверждённой победы над выбранным РБ того же похода. Известное отсутствие отправки отделяется от неизвестного исхода с привязкой к настоящему ID вкладки браузера, переживающему reload и отличающемуся у копии вкладки.
