# L2wap Bot v7.0.0

## Изменения относительно Chrome v6.0.0

1. Выделены 15 автономных областей видимости игрового кода; из основного content script вынесено 249 функций.
2. Все режимы подключены как отдельные контент-скрипты в предсказуемом порядке перед `content.js` в Manifest V3.
3. Сохранены публичные точки входа `content.js`: вызовы, порядок задач, приоритеты, схема настроек и хранилище v6.0.0.
4. Введены отдельные интерфейсы зависимостей по модулю и динамические ссылки на `cfg`/`rt`, чтобы модуль не запоминал состояние предыдущего персонажа.
5. Включены карта экспортов и зависимостей MODULE_MAP.json и генератор из неизменённой v6.0.0 для воспроизводимости миграции.
6. Добавлены тесты инициализации 15 модулей в изолированном JS-контексте, дымовые тесты основных публичных функций, проверка обновления состояния персонажа.
7. Удалены дубли тестовых папок.

## Совместимость и риск

- Совместимая конфигурация Chrome Manifest V3.
- Изменения направлены на организацию кода; алгоритмы боя и игровые сценарии сознательно не переписаны заново без проверочных логов.
- Общие сервисы и постоянное состояние требуют следующей фазы для полной изоляции модулей.
- Интеграционные проверки на реальном сайте ещё необходимы.
