# L2wap Bot — контекст для работы в Claude Code

Браузерное расширение (Chrome MV3 + сборка для Firefox 128+), бот для браузерной игры **l2wap.com** (Lineage-2-подобная; интерфейс игры у игрока на русском (переключатель UA|RU в настройках персонажа), сообщения сервера, имена заклинаний и предметов — по-украински; журнал бота на русском). Текущая версия: **10.0.16** (тестовая Chrome-сборка). Код — ванильный JS без сборщика, ~12 000 строк. Все комментарии и журнал — по-русски, в комментариях принято ссылаться на версию и лог, по которому сделана правка («7.1.26 (лог 10.10 14:11): …»).

**Журнал работ с ChatGPT/Codex:** `docs/WORKLOG.md` — перед работой прочитать последние записи и открытые PR `codex/*`, после — добавить свою запись в том же PR (правила Codex — `AGENTS.md`). Там же строка «Ведущий» и общая команда смены режима «работаем на ГПТ» / «работаем на Клоде»: получив её, обновить строку в своём PR; пока ведёт ChatGPT, Claude код без прямой просьбы не правит.

**Передача дел:** `docs/HANDOFF.md` — правила пользователя, персонажи, решения, открытые темы (общий файл для всех проектов/аккаунтов Claude; обновлять при важных решениях).

## Игрок и его правила (обязательно соблюдать)

- Персонажи: **Warlock** (Human Wizard → Warlock, 2-я профессия взята 10.10), 56 ур. (11.10), маг с котом-слугой (Kai the Cat — основной DD, +25 % от M.Atk; с 11.10 слот «Summon Feline Queen» (l2_1331) на L2WAP — **бафф кота Blessing of Queen** (с 11.10 21:21, после переделки админом: шанс физ. крита +30 % и урон крита +25 % на 20 мин → с 12.10 снова **2 мин** (новость игры 11.10, код l2-hud-companion.js; 10.0 IL_FIX 1331 dur 120); у всех слуг точность 70 %, шанс крита 50 %, MP 87 — кот ≈×2 урона; ставится всегда, как истёк), не призыв — IL_FIX 1331, роль «Баффы кота») — основной. **Спойлер** (гном: Scavenger/Bounty Hunter) — «спойлить ресурсы на крафт». West (воин) — редко.
- Спойл: **Sweeper не нужен** — игра собирает спойл сама; бот только считает «Спойл: X ×N» как ресурс X. Фарм ресурса/рецепта — по базе форума (дроп + спойл у спойлера): телепорт к лучшей точке, источники — цели при любом уровне, автофарм с точки не уводит.
- **Никогда не собирать zip без явной команды «сборка».** Закончили правки → **спросить игрока, нужна ли сборка** (игрок 11.10: «сразу не собирай пакет, спрашивай надо ли, мы же разрабатываем 9 версию бота»; прежнее правило 10.10 «сразу собрать» отменено). Версию в manifest/тестах поднимать только при сборке; правки к 9.0 копятся в CHANGELOG-9.0.md с пометкой «в работе». С 10.0.7 файлы CHANGELOG-X.Y.Z.md лежат в `docs/changelog/`, в корне — одно оглавление `CHANGELOG.md`; папка docs/ в zip не входит (вместе с tests/ и kb/). Стандартная сборка — **только основная** `l2wap-bot-v<версия>.zip` (Chrome). `l2wap-bot-v<версия>-firefox.zip` (Firefox ПК/Android, `node tests/tools/firefox-build.cjs`) — **только по явному запросу игрока** (11.10: «сборка фаерфокс модели ток по моему запросу всегда, стандартно собираем основную модель»). **Основную версию под Android не меняем** (игрок 11.10): всё планшетное/андроидное — за проверкой `/Android/` в userAgent (content.ANDROID, popup tabbed), на ПК поведение прежнее. В имени никаких суффиксов вроде «fix chrome». Нумерация последовательная: после 7.1.31 — **7.2** (по просьбе игрока), дальше 7.2.1…7.2.5, затем **8.0** (игрок: «готовь версию 8»), дальше 8.0.1 / 8.1…
- **Перед каждой сборкой и каждым коммитом — все проверки** (игрок 10.10: «тесты нужно проводить всегда, чтобы я баги не ловил»): `node tests/run-all.cjs` (все PASS), `node --check` всех js, проверка геттеров модулей, на каждое исправление — новый тест; перед сборкой — ещё браузерные смоуки и загрузка собранного zip в Chromium. Что не удалось проверить — честно написать в ответе. Пакет расширения — без tests/, архив `-src.zip` с тестами — только по просьбе.
- Рабочий цикл: игрок **просто присылает логи** (`l2bot-log-*.txt`, `l2wap-pages-*.html` — снимки страниц, `l2bot-learn-*.html`, иногда `l2bot-memory-*.json` / `l2bot-settings-*.json`). Задача — самому найти ошибки и повторы багов и исправить. Каждую находку в ответе объяснять простым языком: что было в логе (со временем), почему, что исправлено, что проверено, что НЕ проверено в живой игре.
- **Чемпионы 73+ и «Cancel»** (второй анонс 13.10, собрана в 10.0.8, docs/changelog/CHANGELOG-10.0.8.md; в меню «Охота» выключатель обхода: «Обход ВКЛ…» (paid, по умолчанию) | «Обход ВКЛ (жёстко)» (never) | «Обход ВЫКЛ: бить всегда» (always)): оранжевые/красные ≥ 73 ур. — HP ×3, атака/защита ×4 (цифры сервера уже с усилением: красный Hot Springs Yeti 75 — 476 тыс. HP, M.Def 6 014; EXP не умножен) → отдельный класс в champs (dpsH, red73, без замера ДПС ÷ 4, отход при HP < 50 %); «Cancel» (третий анонс 13.10 заменил 10/30/60 %) — удачный физ. удар чемпиона снимает до 3 баффов: синий 3 % раз в 30 с, оранжевый 5 %, красный 7 % без задержки (промах и удары по коту не снимают) — правило игры как цена: champs.cancelCost (удары ≈ бой ÷ 1,3 с × 0,8 × шанс × 3, не больше висящих платных за FA, × 150 с за FA) против цены чемпиона; cfg.champCancel paid (по умолчанию) | never | always; buffs.cancelRisk для чемпиона с цветом → null. Копья/масс-умения магов не цепляют чемпионов/РБ (только основной целью) — в коде ничего. `kb/champions.md`.
- **Чемпионы** (13.10, игра: FA с синих 10 %, оранжевых 20 %, красных 60 %, только не ниже героя −5): поиск ВКЛ, карта раз в 20 боёв (cfg.champEvery), modules/champs.js — цена чемпиона в секундах фарма, проба, отход «не пробиваю/долго/мало HP», вердикт до роста силы (rt.champLearn); красные/оранжевые первыми (cfg.champFa); FA в журнал (rt.faDrop). `kb/champions.md`.
- **TvT по умолчанию всегда ВКЛ.** «Проверять карту каждые 0 боёв» = никогда не проверять карту (только цепочка «Охотиться дальше»). Исключение (выбор игрока): активная цель «ресурс»/«рецепт» на своей точке — карта раз в 5 боёв (farmMapOn, не реже 10 при большом N).
- Бот должен **стоять там, где его оставили** (пока «Автофарм» выключен): бить ★-цели квестов, иначе мобов этой локации — но **не ниже героя −5** (игрок 13.10: «фарм мобов −5 лвл максимум, иначе не падают ФА»; явные задачи — ★ квест, источник ресурса — исключение). Никуда не улетать самостоятельно.
- Автомагистр включён по новому решению игрока 14.10: учит доступные ранги сразу при включении и после каждого +1 уровня; отдельный прогресс активного класса/слота, резерв SP/skip, подтверждение ранга, возврат после победы. Одноразовая миграция заменяет старый force-off, последующее ручное выключение сохраняется. Профессии не меняет; доступность навыков (включая Spoil и мастерства) определяет актуальный canLearn сервера. Кубиков у Warlock на этом сервере пока нет (игрок написал админу).
- **Общая автозаточка (14.10):** по умолчанию выключена, очередь пуста, лимиты попыток/свитков 0 запрещают запуск. Только выбранные точные экземпляры и имеющиеся свитки, по одной попытке через родную страницу; покупки, адена, CoL и FA не расходуются. Общий Start не создаёт серию: нужен явный запуск в подразделе. Неизвестный исход блокирует повтор; после сверки доступно явное завершение с сохранением резерва/истории и новым ручным выбором. Stop, другой герой/вкладка и приоритетные задания останавливают действия. Статистика отделяет подтверждённый результат от неизвестного; модель шанса не обещает исход. Детали — `docs/AUTO-ENCHANT.md`.
- Заряды (соски) — строго под **надетое** оружие: грейд оружия → грейд зарядов; маг. оружие → «Благословенний заряд духу» (blessed spiritshot), физ. → «Заряд душі воїна» (soulshot). Сейчас надет Sprite's Staff (B) — с 10.10 21:07.
- Настройки и память игрока встроены как **базовый профиль** (`base-profile.json`): применяется только в пустую установку (важно для Firefox: временное расширение стирает данные при перезапуске). Обновлять по присланным `settings`/`memory` экспортам.
- **Безопасность**: пароль автологина (storage-ключ `auth`) никогда не попадает в журнал, снимки, экспорт, базовый профиль. Никакого автоматического решения капчи/антибота.
- **MP не экономим — приоритет ДПС** (игрок 10.10: «банки МП всегда можно легко купить… нас интересует ДПС, нам ещё РБ убивать»). Никаких «экономных» тактик по умолчанию, которые стоят времени (добивание котом — по умолчанию ВЫКЛ). Режим экономии MP — только когда банки MP нет вообще.
- **Coin of Luck** бот не тратит, кроме одного (игрок 12.10): улучшение у кузнеца Маммона вещи-цели из раздела «Маммон» до выбранного уровня (9.2.5, cfg.mmUpgrade, modules/mammon.js upgrade). FA не тратим никогда.
- Удочки можно случайно продать — бот сам покупает одну; наживка: обычная «Fishing Lure» за адену, «Якісна наживка» только из Old Box/за Proof.

## Структура

```
manifest.json          MV3, version + version_name (тесты сверяют строку версии!)
background.js          service worker: замок вкладки (lockAcquire/Renew/Release, эпохи), statePatch/menuPatch (MAX_PATCH_KEYS 400),
                       charSwitch, heartbeat/watchdog, applyBaseProfile (install/update/startup), журнал в IndexedDB
hook.js                MAIN world: перехват fetch/XHR игры → postMessage {__l2bot:'net'|'netStart'} (пароли/токены вырезает)
content.js             ядро (~3700 строк): main() цикл, setRt/rtWriter (очередь патчей), DEF_CFG/DEF_RT, миграции once(),
                       сетевой обработчик (profQuestNote, weaponEquipNote, SHOP_BUY, PET), автообучение, док-панель
engine-core.js         createPatchQueue, domRace и прочие чистые функции (тестируются)
battle-cooldown.js     модель откатов: серверный GCD + индивидуальные, привязка к spawn
modules/*.js           фабрики L2V7Factories.<name>(env) → L2V7Modules.<name>; зависимости только через env.X
popup.html/js, ui-v7.* меню: 7 разделов (overview, hunt, rb, fish, panel, supply, svc; бывшие — подразделы с меткой
                       #tab-<старый>, TAB_GROUP в popup.js), «Чем занят бот» (setMode/paintModes — ровно один режим),
                       скрытие по классу (data-cls="fighter|mage|spoil" + html.cls-mage/cls-fighter/cls-spoil, «показать всё»)
skills-il.js, items-il.json   справочники Interlude (скиллы по id, предметы: грейд, тип, P/M.Atk)
zone-db.js             9.0: встроенная база зон (90 точек телепорта, 438 мобов: уровень/EXP) — из kb/data, `python3 -I tests/tools/zone-db-build.py`
zone-kpd.js            9.0: модель КПД зоны (L2Kpd: learn/zoneEst/rank/route) — чистые функции для navigation и popup
base-profile.json      базовый профиль игрока (cfg + chars.Warlock.rt + learn + farmDb)
tests/                 node tests/run-all.cjs (214 файлов), *.py — playwright-смоуки (CHROMIUM=/opt/pw-browsers/chromium)
CHANGELOG.md           оглавление истории версий (ссылки); сами CHANGELOG-X.Y.Z.md — в docs/changelog/ (в zip не входят, код их не читает)
```

**Важное правило модулей:** модуль обращается к ядру только через `env.X`. Для каждого `env.X` в content.js у фабрики этого модуля должен быть геттер `get X(){return X}` в объекте `L2V7Modules.<name> = L2V7Factories.<name>({...})`. Пропущенный геттер = `undefined` в рантайме. Проверять скриптом (сравнить `env\.(\w+)` в модуле с `get (\w+)\(\)` в его фабрике); тест `v7-modules.test.js` ловит часть.

Модули: combat (бой, magePlan/dpsPlan/debuffPlan, кот, банки, potSlotRestore, сторожа), mobfarm (карта, candidates, цепочка «Охотиться дальше», автофарм-кик), navigation (zoneRate/zoneScore/zonePick, zoneForLevel, телепорт), quests (кампания, isQuestName), economy (магазин: shopPlan/shopBuyOne, shotGrade/weaponIsMage), equipment (сканер инвентаря, rankWeapons — грейд важнее цифр, никогда не даунгрейд), fishing (рыбалка целиком), raid, epics, tvt, buffs, resources, loot, survival, dungeons, mammon (9.0: заказ торговца из сумки, цель «копить на улучшение у кузнеца», цены кузнеца; свои GET — `content.gameGet` с токеном страницы, без него сервер отвечает 401), subclass (10.0.7: заготовка под сабы — роль класса, свой крафт, помощник основного/передача; см. выше). story (9.0: квесты сабкласса и Noblesse — прогресс из `/game/story-quests/*`, сдача готовой части у NPC, РБ квеста первыми, свой Noblesse не за FA; смена класса → память класса в `rt.classStash`, CHANGELOG-9.0-story.md). enemies (9.2.1, «☠ Лист врагов»: убийца из `pvpDefeat` → `rt.enemies`, враг на локации (`nearbyHeroes`, свой GET `/game/map/around` раз в 30 с) → нападение ником на карте с проверкой сил, ответ на `pvpIncoming`; CHANGELOG-9.2.1.md). fightlab (9.2, анализатор боя: ход за ходом из ответа сервера — hook `bt` с полным `delta.logTail`; точные цифры хода для замера скилла `turnFor`; память на цель `rt.fightMem` (РБ по spawnId, мобы по имени; урон скиллов по цели, ДПС, удары по нам, спецудар и паузы) — в CLASS_KEYS; подсказки бою `dmgOn`/`killP`/`spikeEta`; профиль класса `role()`; CHANGELOG-9.2.md).

## Как устроено состояние

- `cfg` — настройки (общие + `cfg@Ник`), `rt` — память персонажа (`rt@Ник`), `learn`, `farmDb`, `on`, `paused`, `lock`, `auth`.
- Вкладки пишут в `rt` только патчами через `setRt(patch)` → `rtWriter` → background `statePatch`. Писать может только вкладка-хозяин замка. `rt` в памяти вкладки = `{...DEF_RT, ...storage}`.
- Разовые миграции — `once('flag', fn)` в content.js (~строка 3650): флаг теперь пишется и в `rt`, и в `cfg`. Новые правки настроек по умолчанию делать через `once`.
- Крупные ключи rt: `spawns` (кэш спавн→имя/уровень), `zoneStat` (EXP/ч по зонам и уровням героя), `skills` (замеры урона/MP/КД), `lootStat`, `hardMobs`, `questSeen`, `profQuest`, `weapons`/`weaponEq`, `debuffStat`, `petResummon`.

## Как проверять

```
cd <repo> && node tests/run-all.cjs            # 152 файла; при смене версии обновить строку версии в tests/stage1,stage3,ios-fishing,v71-ui,v6-core
for f in content.js background.js popup.js modules/*.js; do node --check $f; done
```
Playwright-смоуки с реальным расширением (headless Chromium, подмена l2wap.com маршрутами): примеры были в scratchpad (base60.js — базовый профиль, shop60.js — магазин, fishsetup.js — настройка рыбалки, pausetest.js — меню/пауза, equipnet.js — надевание по сети, profq.js — квест профессии, baitswap.js — смена наживки, fishstall.js — зависание рыбалки). Схема: `chromium.launchPersistentContext` с `--load-extension`, `ctx.route('https://l2wap.com/**')` отдаёт мок-страницу, storage через service worker, итог читается из `chrome.storage.local`.

**Сборка:**
```
zip -qr l2wap-bot-v7.1.NN.zip . -x 'tests/*' -x '*.orig'
# Firefox (ПК и Android): node tests/tools/firefox-build.cjs [папка] → l2wap-bot-vX-firefox.zip (background.scripts, gecko + gecko_android 128+)
# смоук: FIREFOX=… GECKODRIVER=… NODE_PATH=<selenium-webdriver> node tests/tools/firefox-smoke.cjs <zip> [--android]; web-ext lint -s <папка>
# проверить: grep -ci 'passw\|"auth"' base-profile.json → 0
```
Firefox ставится как временное дополнение (`about:debugging#/runtime/this-firefox`); после перезапуска браузера данные стираются → срабатывает базовый профиль. Android: в обычном Firefox неподписанный zip не ставится — нужен Firefox Nightly (about:config `xpinstall.signatures.required`=false, «Установить дополнение из файла» в секретном меню) или подпись на AMO (unlisted) аккаунтом игрока. В Firefox для Android нет chrome.commands/notifications/значка/снимка экрана; меню из «⋮ → Расширения» — отдельная вкладка; фоновая вкладка/погасший экран засыпают.
