# Автоскан страниц игры (ogx-pagescan 1.1.0)

Скрипт сам обходит страницы игры Aeternum и складывает их в один ZIP, который можно прислать Claude.

## Как запустить
Вариант 1, без установки: откройте любую страницу игры, нажмите F12, вкладка Console, вставьте
весь файл `ogx-pagescan.user.js` и нажмите Enter (Chrome может попросить сначала набрать `allow pasting`).
Вариант 2: Tampermonkey/Violentmonkey → «Создать скрипт» → вставить файл → сохранить. Панель будет на каждой странице игры.

Справа внизу появится панель «Скан страниц»: выберите галочки, нажмите «Начать скан», дождитесь «Готово»,
нажмите «Скачать ZIP». На время скана остановите бота Suite (скан переключает планеты; в конце возвращает исходную).

## Что сохраняется
- По каждой планете и луне: overview, buildings, resources, research, верфь (флот/оборона), fleetTable, galaxy, transport.
- Общие: imperium, techtree, premium, ressprem, officier, trader, fleetDealer, statistics, alliance, search,
  records, battleHall, banList, rules, questions, settings (поля e-mail и пароля пустые), tournament, battleSimulator.
- Детали построек/исследований/кораблей/обороны (JSON с TechnologyDetailsAjax, ResearchDetailsAjax, ShipDetailsAjax).
- Новые страницы, найденные по ссылкам (до 60, только безопасные ссылки).
- Почта по категориям — только если включить галочку: сервер помечает открытые письма прочитанными.
- index.json (список файлов) и log.txt (журнал запросов).

## Приватность (что НЕ попадёт в архив)
- Страницы notes (заметки), ticket (тикеты поддержки), buddyList (друзья), GiveBonus (ваучер) и satinal (покупка) не открываются
  вообще — ни из списка, ни по найденным ссылкам.
- В каждой сохранённой странице: значения полей e-mail и пароля пустые, все textarea пустые, любые адреса e-mail заменены на `<email>`.
- В log.txt нет User-Agent — только семейство и версия браузера (например `browser=Chrome 130`).
- Панель перед сканом перечисляет, что попадёт в архив. Почта (переписка) — только по галочке, по умолчанию выключена.

## Безопасность
Только GET, пауза 0.3–0.6 с, около 150 запросов (~1.5 мин для 4 планет). Не открывает fleetStep, vote, donatebis,
relocate, logout и любые ссылки с cmd/action/delete/cancel/send/buy и т.п. При выходе из сессии скан останавливается,
собранное всё равно можно скачать.
