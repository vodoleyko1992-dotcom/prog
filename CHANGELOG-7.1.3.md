# L2wap Bot v7.1.3 — Stop trace + API outage recovery

- Атомарно фиксируется источник выключения: кнопка Стоп, клавиатурное сокращение, остановка сторожем, `halt` или импорт памяти. Неизвестные внешние выключения также помечаются в журнале.
- Массовый сбой HTTP 5xx обнаруживается по минимум трём запросам к двум различным игровым API за 30 секунд. Пока API недоступно, действия приостанавливаются.
- При восстановлении серверного API проверяются успешные ответы от двух различных путей.
- После временной недоступности сервера перезагружается текущая страница, чтобы не терять URL боя.
- Автоматического включения после `on=false` нет: осознанную остановку не отменяем.
- Причина исторической остановки 19:23:48 по старому журналу неизвестна: 502 начались позже, в 19:24:54.

Локальные проверки не гарантируют работоспособность на игровом сервере.
