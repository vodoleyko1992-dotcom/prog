# Правки в L2wap Bot

## Стиль
- Ванильный JS, без сборщика. Плотные однострочники как в окружающем коде.
- Комментарии по-русски, со ссылкой на версию и лог: `// 8.0.4 (лог 11.10 10:32: четыре телепорта подряд…): что и почему`.
- Тексты журнала — по-русски, понятно игроку.

## Модули
- Модуль `modules/<name>.js` = фабрика `L2V7Factories.<name>(env)`; к ядру — **только через `env.X`**.
- Для каждого `env.X` нужен геттер `get X(){return X}` в объекте `L2V7Modules.<name> = L2V7Factories.<name>({...})` в content.js. Проверка: `node tests/tools/envcheck.cjs .` — все «ok».
- Экспорт функций модуля — в `return { … }` в конце фабрики (тесты вызывают их через vm).

## Настройки и память
- `cfg` (настройки) и `rt` (память персонажа). Писать в rt — только `setRt(patch)` (вкладка-хозяин замка).
- Новое значение по умолчанию: DEF_CFG в content.js **и** DEF в popup.js **и** base-profile.json; для уже установленных — разовая миграция `once('имя803', () => { if (C('ключ') === старое) cf.ключ = новое; })` в блоке миграций content.js (своё число игрока не трогать).
- Вычисляемые флаги лучше хранимых (пример: `rbMode` = `rbEff(cfg)`), чтобы режимы не рассинхронизировались.

## Тесты — на каждое исправление
- Новый файл `tests/v<версия>-<тема>.test.js`, **добавить в список** `tests/run-all.cjs`.
- Предпочтительно поведенческий тест: загрузить модуль в `vm` (образец — `tests/v80-rb.test.js`, `tests/v803-clicklock.test.js` — вырезка `act()`), иначе проверка исходника регуляркой.
- Массивы из vm сравнивать через `JSON.stringify` (разные realm’ы).
- Старый тест сломался из-за осознанного изменения — обновить его с комментарием «8.0.x: …», не удалять проверку.
- После правки: `node tests/run-all.cjs` (все PASS), `node --check`, envcheck, коммит + push.

## Запреты (правила игрока)
- **Coin of Luck** (предмет 4037, донат/ценная) — никогда без явного положительного лимита; «0» = никогда. Неизвестная цена/валюта — отказ.
- **Адена**: никаких платных телепортов «вслепую» — сначала проверка сил по цифрам игры (`raid.rbInfo`, встроенные `RB_KNOWN`).
- Пароль автологина (`auth`) — никогда в журнал/снимки/экспорт/базовый профиль.
- Никакого автоматического решения капчи/антибота.
- MP не экономим — приоритет ДПС. TvT по умолчанию ВКЛ. Бот стоит, где оставили (пока не «Автофарм»).
- Сборку не делать посреди работы (см. `l2-build`).

## Большие правки параллельно
- Несколько независимых групп — агенты в отдельных worktree (`isolation: 'worktree'`), каждая на своей ветке, со своими тестами; затем ревью каждой ветки «опровергнуть»; затем слияние `git merge --no-ff`.
- Конфликт в `tests/run-all.cjs` — объединить списки тестов (без дублей). Конфликт в base-profile.json (одна строка JSON) — трёхстороннее слияние по ключам через `git merge-base`.
- После слияния: удалить worktree (`git worktree remove --force`) и ветки, прогнать все проверки.
