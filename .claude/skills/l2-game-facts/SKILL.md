# Факты об l2wap.com (проверено логами 10–11.10.2026)

## Бой и клики
- Ответ на ход `POST /game/battle/action` — формат `delta` (с 11.10): `delta.serverNowMs`, `delta.skillCooldowns {l2_<id>: untilMs}`, `delta.mysticSkillCdUntil` (смысл не ясен — пишется в «КД сервера»), `delta.characterHp/MaxHp`, `delta.activeSummon`. `globalCooldownUntilMs` игра больше не шлёт; общего GCD нет (соседние ходы принимаются через ≈0,6 с по серверу).
- **Потерянные клики — главный тормоз ДПС**: после ответа на ход игра шлёт свой `GET /character` (≈8 мс после ответа, идёт 0,25–0,56 с); пока он в полёте и ≈30 мс после — клик молча теряется. Плюс ≈0,3 с после ответа даже без видимого GET. Бот: шлюз `combat.gameFree` (запасы A/B, rt.clickLockA/B), hook шлёт netStart/конец с `rid`.
- Откат сервера без FA ≈0,66–0,75 с (Blaze/AB); короче хода → откаты почти не ограничивают. «КД 3,1 с» в старых замерах — артефакт.
- Баффы FA поднимают **урон** (Blaze ≈1730 → 2770–3100, крит 0 → 28–43 %), не темп. Magnus' Chant (1413) +13–18 % — выгоднее «Дара Серафима» (4703, −30 % отката) для мага.
- Выход из боя (`#battle-back-map`) работает и посреди боя с РБ.

## Баффы
- Городской набор — 24 ч; FA-баффы — 3 ч (и «Дар Серафима», хотя в описании «20 хв»). Noblesse (1323, 5 FA) сохраняет баффы при смерти и уходит сам.
- Шапка: `#l2-hud-active-buffs .l2-hud-active-buff[data-skill-id][data-expires-at][data-dur-ms][title]`.
- Новый баффер: `POST /character/town/buffer`; FA: `/character/town/fast-aden-buffer/apply {set, skillId, expectedCostFastAden}`.

## РБ и эпики
- Цифры босса: `GET /game/spawn/<id>/info` → `stats {maxHp, pAtk, pDef, mAtk, mDef}`, drops, rewardExp/Sp. Постоянные → встроены в `raid.RB_KNOWN` (33 шт., сбор: `tests/tools/rbstats-collect.py <папка логов>`).
- Спецудар РБ ≈0,71–0,90 × M.Atk. Удар эпика (Орфен) 0,79–0,90 × M.Atk = 2500–2900 (40–57 % HP героя 56).
- Телепорт РБ: `POST /game/raid-boss/teleport {spawnId, expectedRevision, expectedAdenaCost}` (100 000).
- Эпики: `GET /game/epic-bosses` → `bosses[] {spawnId, level, isAlive, canAttack, attackBlockedReasonUk, coinOfLuckCost, respawnHours}`, `minRaidBossLevel` = герой − 9. Телепорт: `POST /game/epic-boss/teleport {spawnId, expectedRevision, expectedCoinOfLuckCost:1}` → 200 + {character} (явного ok нет). 8 эпиков: 29001 Королева 40, 29006 Ядро 50, 29014 Орфен 50, 29022 Закен 60, 29020 Баюм 75, 29019 Антарас 79, 29028 Валакас 85, 29045 Фринтеза 90.

## Коты (Warlock)
- P.Atk кота = % от M.Atk хозяина: Kai +25 % (основной DD), Mew +20 %, Kat +15 %, «Summon Feline Queen» (l2_1331) с 11.10 — НЕ кот, а бафф кота Blessing of Queen: с 11.10 21:21 (переделан админом) шанс физ. крита +30 % и урон крита +25 % на 20 мин (до того +20 % крит-урона на 2 мин), MP 87, «застосовано до героя та активного слуги» (IL_FIX 1331, роль «Баффы кота»; было: Feline Queen +10 %, бафф физ. крита «Blessing of Queen» — магу бесполезен). Kai Lv.5 P.Atk ≈1381, удар ≈1870.
- Слоты панели: заголовки призывов английские («Summon Kai the Cat») при любом языке.

## Язык интерфейса
- Переключатель UA|RU в `/character-settings.html`. С 10.10 у игрока RU (утро 11.10 — UA).
- По-русски переводится только оболочка страницы (меню, «Победа!», «Бой начат», «промахнулся»). **Остаётся украинским** всё серверное: «Слуга [X] атакує … урону», «Ефект пройшов», «Ціль опирається ефекту» (= провал дебаффа), «Випав …», имена заклинаний («Полум’я», «Опік аури», «Вампірний дотик»), подписи банок/зарядов на панели, окна слота и слуги, `attackBlockedReasonUk`.
- Значит регулярки — двуязычные; поиск элементов — по id/классам/data-атрибутам, не по тексту.

## Рыбалка
- `POST /game/fishing/action` (cast/pumping/reeling…), ответ с `fishing.serverNowMs`, `fishing.cooldowns` (структура пока неизвестна). Откат действия ≥≈0,9–1,05 с; лаг сервера даёт ложные `action_cooldown` — откат считать от времени сервера.
- Наживка: `buy-starter {offerKey:"bait_x10", amount}` — 1 пакет = 10 шт. = 1000 аден; по умолчанию 100 пакетов.
- В фоне вкладки игра оживляет кнопки раз в 1 с — окно рыбалки держать видимым.

## Прочее
- Капчи и антибота на сервере нет (игрок 11.10), хотя в стилях игры есть файл `l2-battle-antibot.css`. Если проверка всё же появится — не решать автоматически, остановиться и написать игроку.
- Вход в игру из облачного Chromium (для живой отладки) — только с логином/паролем из переменных окружения `L2WAP_LOGIN`/`L2WAP_PASSWORD`, никогда из чата; один аккаунт в двух местах — игра может выкинуть игрока; Coin of Luck и FA не тратить никогда без команды; адену можно (игрок 11.10: «без трат Коин оф лак и ФА, адена пофиг»).
- Игрок распаковывает новые версии в новую папку → Chrome стирает память. Всегда напоминать: «распаковать поверх в ту же папку и нажать ↻».
- Сервер игры периодически отдаёт 502 (Cloudflare) / зависает на десятки секунд — бот ждёт, не останавливается.
