L2wap Bot v6.0.0 — сборка для Google Chrome / Chromium (Manifest V3)

Установка:
1. Распакуй архив в ПОСТОЯННУЮ папку (например, L2wap-Bot-Chrome).
2. Открой chrome://extensions/
3. Включи «Режим разработчика».
4. Нажми «Загрузить распакованное расширение».
5. Выбери папку, в которой расположен manifest.json.
6. Открой/обнови вкладку l2wap.com.

Обновление: заменяй файлы В ТОЙ ЖЕ папке, затем нажимай «Обновить» на chrome://extensions/.
Не удаляй старую установленную копию, если хочешь сохранить chrome.storage.local и журналы.

Chrome и Firefox хранят данные расширений раздельно.
Firefox-настройки автоматически не переносятся — понадобится экспорт/импорт настроек.

Проверки сборки: JS синтаксис, Manifest V3, ссылки на файлы, регрессионные тесты.
Автоматический запуск расширения в Chromium в тестовой среде заблокирован администраторской политикой.
Реальная работа на сайте не тестировалась.
