L2wap Bot 20.25 — Google Chrome / Chromium

Установка:
1. Скачай Chrome ZIP и распакуй в постоянную папку.
2. Открой chrome://extensions/
3. Включи «Режим разработчика».
4. Нажми «Загрузить распакованное расширение», выбери папку с manifest.json.
5. Обнови вкладку игры. Меню бота открывается значком расширения.

Обновление: останови бота, сохрани экспорт настроек, замени файлы В ТОЙ ЖЕ
папке и нажми ↻ на карточке в chrome://extensions/. Обнови вкладку игры.
Старую копию не удаляй: так сохраняются её данные.

В 20.25 исправлен обмен камней печати на АА: кнопка и автообмен работают
в том числе в режиме «Только задачи»; остатки в меню обновляются сразу.
При активном VIP обычный городской набор автоматически заменяется полным
по текущему классу только с подтверждённой ценой 0 адены и 0 Coin of Luck.
После окончания VIP — снова обычный набор. Галочка рядом с выбором набора.
В разделе ЛС можно выбрать конкретное оружие из надетого и рюкзака.
Вещь из рюкзака перед запуском нужно надеть вручную; бот не меняет цель сам.
Все исправления 20.24 включены. Firefox остаётся 20.23; настройки браузеров
хранятся отдельно, перенос — экспорт/импорт. Живую игру при сборке не открывали.
