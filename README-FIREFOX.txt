L2wap Bot 20.29 — Firefox 128+ для компьютера

Временная установка неподписанной сборки:
1. Скачай Firefox ZIP и распакуй в отдельную постоянную папку.
2. Открой about:debugging#/runtime/this-firefox
3. Нажми «Загрузить временное дополнение…».
4. Выбери manifest.json из распакованной папки Firefox.
5. Обнови вкладку игры; меню открывается значком расширения.

Обновление: сохрани экспорт настроек, замени файлы в той же папке и нажми
«Перезагрузить» у дополнения на about:debugging. Обнови вкладку игры.

Это неподписанный пакет: после закрытия Firefox временное дополнение удаляется,
его нужно подключить заново; данные временной установки могут быть потеряны.
Перед закрытием сохраняй экспорт настроек. Для постоянной установки в обычный
Firefox нужен подписанный XPI через Mozilla Add-ons. Простое переименование
ZIP в XPI подпись не добавляет.

Manifest также содержит совместимость Firefox Android 128+, но обычный Firefox
Android не устанавливает этот ZIP напрямую: нужен подписанный пакет/каталог AMO.
Проверка в настоящем Firefox и на телефоне в быструю сборку не входит.
Chrome и Firefox хранят настройки отдельно; перенос — через экспорт/импорт.

В 20.29 включены те же исправления Маммона, что в Chrome: подготовка оплаты
больше не переключает рыбалку на тур РБ и не отменяет ещё не отправленный
запрос. Временно отключённая кнопка во время ручного улучшения не считается
неудачей: бот ждёт подтверждения уровня предмета. Перед отправкой повторно
проверяются карточка и кнопка; начатое игроком действие не дублируется.
Запрет повторной оплаты при неизвестном результате сохранён.
Новых обязательных настроек нет. Все исправления 20.28 включены;
автозаточка остаётся отключённой.

Для работы нужны запущенный браузер и открытая игра. Автозапуск компьютера
и расписание разрешённых часов не добавлены. Настройки одного героя меняй
в одном меню: одновременные изменения в двух меню могут затереть друг друга.
Живую игру при исправлении и сборке не открывали.
