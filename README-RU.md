# L2wap Bot v7.1.16 — Chrome / Manifest V3

## Установка

1. Создайте резервную копию настроек через меню действующего расширения.
2. Отключите старый экземпляр L2wap Bot, чтобы два расширения не управляли одной игрой.
3. Распакуйте ZIP, откройте `chrome://extensions`, включите режим разработчика и выберите «Загрузить распакованное расширение» с файлом `manifest.json` в корне.
4. Если устанавливаете в **другую папку** как новое расширение, Chrome может присвоить другой ID и прежнее `chrome.storage.local` не будет доступно: импортируйте резервную копию через интерфейс бота.
5. Для сохранения того же ID обычно обновляйте файлы **в существующем каталоге** распакованного расширения и нажимайте «Обновить» в Chrome.

## Модульность

15 модулей в `modules/`: `fishing`, `epics`, `raid`, `combat`, `dungeons`, `tvt`, `mobfarm`, `quests`, `navigation`, `buffs`, `equipment`, `economy`, `resources`, `loot`, `survival`.

- Вынесено 249 функций с сохранением публичных имён, вызовов и существующих настроек.
- У каждого модуля своя область видимости JS. Зависимости передаются через ленивые геттеры; `rt` и `cfg` считываются при выполнении, а не при создании модуля.
- Централизованное управление вкладками, владением и сохранением состояния сохранено из v6.0.0.
- `content.js` остаётся диспетчером и адаптером совместимости; оставшиеся сервисы будут переноситься по результатам игровых тестов.
- **Это не полная изоляция хранилища:** все модули пока пользуются общими структурами `rt`/`cfg` через централизованные функции. Идея разделения выполнена на уровне кода/областей видимости, а миграция независимых хранилищ — следующий шаг.

## Проверки

Запуск всех локальных проверок: `node tests/run-all.cjs`.
Проверяются исходные регрессионные сценарии v5.6.3–v6.0, регистрация модулей, загрузка в имитированной среде Chrome и смена состояния персонажа.

**Ограничения:** никаких гарантий полной автономности в реальной игре; настоящий Chrome и серверная интеграция в этом окружении не тестировались. Первый запуск рекомендуется на одном персонаже с последующей проверкой логов.

## Панель v7.1 — Control Center

- **Обзор** — статус, статистика и быстрые переходы в модули.
- **Игровые режимы** — фарм мобов, локации, рейд-боссы, эпики, катакомбы, рыбалка.

- Знак **?** рядом с настройкой открывает краткое описание. Длинные разъяснения доступны в «Как это работает».

- Во встроенной узкой панели вкладки прокручиваются горизонтально; это нормальное поведение.
- Вкладки разделяют только интерфейс: игровые режимы контролируются тем же ядром v7.0.1.

## v7.1.5 — светлая iOS-тема и рыбалка

- Светлый высококонтрастный интерфейс, плиточная навигация без горизонтальной прокрутки (5 колонок / 3 во встроенной панели).
- **Что копим за Proof:** по умолчанию «Просто копим Proof», покупка экипировки отключена. При обновлении только прежняя заводская очередь `tattoo_d, cloak_d, belt_d` сбрасывается; выбранные вами другие очереди сохраняются.
- **Заточка удочки:** по умолчанию цель **+10**. Бот расходует Proof на свитки отдельно от покупок экипировки. Для накопления Proof без затрат на свитки вручную установите «Заточка удочки» = 0.
- Режим накопления Proof и цель заточки сохраняются как независимые параметры. Проверка фактической эффективности заточки и получения сундуков требует наблюдений на сервере игры.
- Список исправлений: `CHANGELOG-7.1.5.md`.


## Обновление интерфейса v7.1.6

- **Быстрые режимы:** раскрыть группу переключателей нажатием на строку «Быстрые режимы». В свёрнутом состоянии указаны активные режимы.
- **Разделы:** нажать «Разделы — Все 13» для открытия плиточного меню без горизонтальной прокрутки. После выбора раздела меню закроется автоматически. Esc также закрывает меню.
- **Крупные элементы:** текст от 14 px в настройках, основные кнопки от 44 px, контрастные поля и активные состояния.
- **Рыбалка:** кнопка «Цель: заточить удочку до +10» ставит автоматическую задачу, которая тратит Proof на свитки и после достижения +10 возвращается к накоплению Proof.
- **Время рыбалки:** в разделе рыбалки доступно отключённое по умолчанию автопродление времени с выбором пакета и лимитом остатка.

Обратите внимание: для задачи +10 может понадобиться много Proof. Система не обещает успех заточки без проверки ответа игры.


## v7.1.7 — тактика РБ из v7.0.3 (без отката исправлений 7.1.x)

- Исправлена ошибка единиц времени в Combat: `cdLeft()` возвращает секунды, поэтому порог зарядки должен быть **1,5**, а не 1500. `Focused Force` допускается лишь когда основные сильные удары недоступны ближайшие 1,5 с; настройка «Заряды на РБ» отключает эту тактику.
- `Burning Fist`, `Soul Breaker`, `Iron Punch` получают приоритет при готовности; мощный удар не отбрасывается из-за обычного фильтра сравнительного DPS.
- Автоматическая полоса лечения РБ начинается от 80% HP и повышается с учётом известного специального удара и двух обычных; максимальный стартовый порог — 95%, целевой — до 98%. Автополосу можно отключить.
- Распознаются критические обычные удары и спецудары РБ. Статистика хранится отдельно по идентификатору босса.
- После победы сохраняются фактические адена, EXP, длительность боя для экономического выбора следующего РБ. Экономический тур учитывает их, стоимость телепорта и предполагаемые расходы на банки; устаревший список (старше 10 минут) не используется перед платным перемещением.
- Экономический тур **по умолчанию выключен**, включается в разделе РБ. Значения стоимости EXP и банок — модельные, не рыночный курс.
- Все прежние исправления сохранены: отсутствие ложного отката HP/MP-банок, осторожный прогноз победы с измерением ударов, защита от повторных платных перелётов, отступление только при подтверждённом выходе, рыбалка и оформление iOS.
- Никаких принудительных сбросов/переопределений пользовательских настроек.
- `node tests/run-all.cjs` теперь содержит тест `v717-raid-integration.test.js`.

Реальный игровой сервер не входит в локальные тесты. Перед массовым туром по РБ проверьте несколько обычных боёв на малорисковых целях.

## v7.1.9 — включение рыбалки

Кнопка «Рыбалка» теперь за одно нажатие запускает бота (при необходимости), включает `fishMode` и выключает конкурирующие режимы (эпики, фарм/тур по РБ, катакомбы, кампанию). Если уже идёт бой, переключение произойдёт после завершения текущего действия.

Повторное нажатие выключает только режим рыбалки, не останавливая весь бот. Задача «Заточить удочку до +10» остаётся отдельной и не ставится автоматически обычной кнопкой рыбалки.

## v7.1.10: запуск
Кнопки Старт/РБ/Эпики/Тур/Рыбалка/Кампания отправляют сигнал пробуждения игровому движку. Состояние «Работает» означает свежую связь с игровой вкладкой. Если отображается «Нет активности», проверьте открытую вкладку и журнал. Кнопки сделаны компактнее.

## v7.1.11 — устранение зависания запуска и улучшение управления

- При любом выходе из главного игрового цикла сбрасывается внутренний флаг `running`.
- Если повторяется ошибка JavaScript, бот выдаёт явную причину и прекращает неисправный цикл без трёхминутного ожидания.
- Временные ошибки: ожидание не более 30 секунд. Старые накопленные ошибки предыдущих версий при обновлении не наследуются.
- Пояснения настроек уменьшены до компактных кнопок «i», переключатели 34×20 px.
- Локальные тесты проверяют синтаксис, восстановление, переключение рыбалки, интерфейс и выбор боевого действия на сохранённом HTML боевой страницы.
- Запуск установленного расширения в реальной игре необходимо проверить отдельно.


## v7.1.13: запуск и подготовка мага → Warlock

- Устранена причина `invalid_patch`: полная конфигурация из 122+ полей сохраняется (лимит 400 на один пакет). Если фоновый процесс отвергнет сохранение, команда запуска не продолжится, в панели появится ошибка.
- Для мага откройте «Боевой движок» → «Профиль персонажа» → «Маг → Warlock (кошка)», затем «Распознать» на игровой странице боя и «Применить предложенное» только после проверки списка навыков.
- Бот различает заклинания урона, призыв, баффы и лечение питомца; маги предпочитают доступные Blessed Spiritshot. На РБ маги не используют тактику физической атаки ради вампиризма.
- **В этой редакции кошка не вызывается автоматически и не получает команды атаки:** реальные элементы управления и формат действий сервера за Warlock пока не получены. Автодобавление таких команд без проверки могло бы сломать бой. После достижения профессии нужны новые HTML-снимки и журнал боя с кошкой.
- Тесты мокированного браузера не гарантируют работу на сервере игры. Не запускайте несколько версий расширения одновременно.
