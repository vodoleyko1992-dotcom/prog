# OgameX Suite 0.3.2 beta

**OgameX Suite** — расширение для браузера, которое добавляет в игру удобные подсказки и таблицы:
производство всех планет, стоимость построек, ресурсы в полёте, хронологию полётов, разбор шпионских докладов,
цели, слежку, план построек и многое другое. Это два набора модулей в одном расширении:

- **Live** (7 модулей) — то, что видно прямо на страницах игры: в списке планет, на иконках построек, на странице флота.
- **Infinity** (12 модулей) — боковая панель с вкладками: планеты, империя, цели, шпионаж, ракеты, статистика, полёты, почта и т. д.
- **Бот** — полная автоматизация (сейв, фарм, обломки, стройка, экспедиции). **С 0.3.2 все функции бота включены
  по умолчанию** и он сразу действует сам, без «Пробного режима» (раздел 8.1). Выключить — «Стоп» или галочки модулей.

Версия 0.3.2 сделана для сервера **ogamex.eu, вселенная Aeternum** (движок игры **GALAXYZ 1.8**, это вариант 2Moons,
адреса вида `game.php?page=...`). Всё проверено на 20 сохранённых настоящих страницах этого сервера.
Старые серверы OgameX (клон на Laravel) тоже по-прежнему поддерживаются.

**Главное правило:** модули Live и Infinity **ничего не делают в игре сами**. Флот, постройки, удаление сообщений, отзыв флота —
только после вашего клика (и обычно ещё подтверждения). Исключение — раздел «Бот»: с 0.3.2 он включён сразу
(раздел 8.1). Просмотр систем в галактике стоит дейтерий, поэтому модули Live и Infinity открывают его только по вашей
команде; бот смотрит галактику сам в пределах «Просмотров галактики в час» (по умолчанию 300, 0 = никогда) и
только при включённом «Сканировать галактику» в разделе фарма (по умолчанию вкл.).

## 1. Установка в Chrome (по шагам)

Подходит также для Edge, Opera, Яндекс Браузера.

1. Скачайте файл **`ogamex-suite-0.3.2-beta-chrome.zip`**.
2. Распакуйте его в **постоянную** папку, например `C:\Games\ogamex-suite\`.
   Эту папку потом нельзя удалять или переносить: браузер загружает расширение прямо из неё.
   Внутри папки должен лежать файл `manifest.json`.
3. Откройте в адресной строке **`chrome://extensions`** (в Edge — `edge://extensions`).
4. Справа вверху включите переключатель **«Режим разработчика»**.
5. Нажмите **«Загрузить распакованное расширение»** и выберите папку из шага 2 (ту, где лежит `manifest.json`).
6. Откройте игру `https://ogamex.eu/Aeternum/game.php?page=overview` (или обновите вкладку с ней клавишей F5).
   В левом меню игры, под обычными пунктами, появится пункт **«OgameX Suite»**.

Chrome может при запуске показывать предупреждение о расширениях в режиме разработчика — это нормально для
расширений, установленных из папки. Просто закройте его.

### Как обновить до новой версии

1. Удалите **содержимое** старой папки (саму папку можно оставить) и распакуйте туда новый zip.
   Проще говоря: замените старые файлы новыми в той же папке.
2. Откройте `chrome://extensions` и нажмите круглую стрелку ⟳ («Обновить») на карточке **OgameX Suite**.
3. Обновите вкладки с игрой (F5).

Ваши настройки и собранные данные при этом **сохраняются**: они хранятся в браузере, а не в папке.
Удалять расширение и ставить заново не нужно (при удалении данные пропадут).

### Другие варианты (для опытных)

- **Firefox 128+:** `ogamex-suite-0.3.2-beta-firefox.zip` → `about:debugging` → «Этот Firefox» →
  «Загрузить временное дополнение» → выберите `manifest.json`. Такое дополнение пропадает после перезапуска Firefox.
  В настоящем Firefox автотестами не проверялось.
- **Tampermonkey / Violentmonkey:** установите `ogamex-suite.user.js`. Нет окна расширения (popup), данные хранятся
  в `localStorage` сайта игры. Запускается на страницах GALAXYZ/2Moons и OgameX.

Целостность файлов можно проверить по `SHA256SUMS`.

## 2. Как пользоваться

Нажмите **«OgameX Suite»** в левом меню игры (или `Alt+Shift+I`) — справа откроется **боковая панель**.
Вверху четыре группы:

| Группа | Что внутри |
|---|---|
| **Live** | состояние модулей Live на этой странице и их переключатели; кнопки «Окно OgameX Live» и «Обновить данные всех планет» |
| **Infinity** | вкладки: Планеты, Империя, Цели, Поиск, Шпионаж, Статистика, Слежка, Полёты, Сбор, План, Настройки |
| **Бот** | состояние бота, «Старт»/«Стоп»/«Пауза», «Пробный режим», вкладки модулей бота, «Журнал» (раздел 8) |
| **Логи** | «Логи для разбора» (раздел 6) |

Значок расширения на панели браузера открывает маленькое окно (popup): вкладки **Модули** (включить/выключить
любой модуль), **Серверы** (на каких сайтах работать; пустой список = везде, где найдена игра) и **Логи**.

**Откуда берутся данные.** Расширение читает страницы, которые вы и так открываете. Зашли на планету — её данные
обновились. Зашли в «Империю» — обновились запасы и уровни всех планет. Поэтому после установки один раз пройдитесь
по страницам: Обзор, Империя (`page=imperium`), Постройки, Исследования, Верфь, Флот, Офицеры.

## 3. Модули Live (на страницах игры)

| Модуль | Что делает | Где видно |
|---|---|---|
| **Меню** (`menu`) | Пункт «OgameX Suite» в меню. «Окно OgameX Live»: насколько свежие данные по каждой планете, данные сервера (Aeternum, GALAXYZ 1.8, ресурсы x22000, флот x7). Кнопка «Обновить данные всех планет»: загружает «Империю» и страницу построек каждой планеты, только по вашему клику, после предупреждения; в конце возвращает вашу текущую планету. Часы сервера в подвале галактики | Левое меню; панель → Live; галактика (внизу) |
| **Производство** (`planetbar`) | Под каждой планетой в списке справа: запасы M/C/D в реальном времени, выработка в час, заполнение складов, свободная энергия, сколько нужно «Улучшенных транспортов» (217) и сколько их есть, полоса кораблей, значок «идёт строительство» | Список планет справа |
| **Ресурсы в полёте** (`inflight`) | Блок «Итоги» под списком планет: ресурсы в полёте, на планетах, общий итог, нужные транспорты. Значок прибывающего флота у планеты с подсказкой (миссия, откуда, когда, груз) | Под списком планет |
| **Стоимость построек** (`techcost`) | На каждой иконке построек, исследований, кораблей и обороны — цена следующего уровня (у кораблей — за штуку). Красная — не хватает ресурсов или энергии (совпадает с кнопкой игры). В окне деталей — «нужно / есть / разница», транспорты на недостающее и когда будет доступно | Постройки, Исследования, Верфь, Оборона |
| **Информация о флоте** (`fleetinfo`) | На странице «Флот» у каждого корабля жёлтая метка скорости («скор. 6 000») с подсказкой: груз, топливо, броня/щит/атака с вашими бонусами. Под таблицей кораблей — выбранный флот: сколько кораблей, общий груз, самая низкая скорость | Флот (`page=fleetTable`) |
| **Экспедиции** (`expedition`) | Блок с расчётом экспедиции: стоимость флота, очки экспедиции, свободный трюм, максимальная находка ресурсов и кораблей, сколько транспортов добавить, тёмная материя, слоты экспедиций (красным, если заняты). Кнопка **«Экспедиция» ±N** заполняет цель (позиция 16) и миссию — **отправляете вы сами** | Флот, шаги 1 и 2 |
| **Хронология полётов** (`timeline`) | Список ваших полётов по времени прибытия: обратный отсчёт, миссия, откуда/куда, кораблей, груз; слоты флота и экспедиций («Ф 1/13», «Э 0/2»). Кнопка ⟳ — одно обновление по клику | Справа под списком планет (можно перенести влево под меню или выключить в настройках Live) |

## 4. Модули Infinity (в боковой панели)

| Модуль | Что делает | Где |
|---|---|---|
| **Панель** (`panel`) | Шапка: игрок, место, офицеры (после посещения «Офицеров»), тёмная материя, время сервера. Вкладка «Планеты»: все планеты с полями, ресурсами, производством, кораблями; ссылки на постройки, верфь, флот, галактику | Панель → Infinity → Планеты |
| **Империя** (`empire`) | Таблицы «объект × планета»: ресурсы, постройки, станции, исследования, флот, оборона, поля, с итогами. «Обновить всё» — одна загрузка страницы «Империя» | Панель → Империя |
| **Цели и поиск** (`targets`) | Цветные метки, заметки и звёздочка «в цели» у строк галактики; вкладка «Цели» (ранг, добыча, активность, Шпионить / Атаковать — атака только заполняет форму флота); вкладка «Поиск» игроков, планет, альянсов; карточка игрока | Галактика; Панель → Цели, Поиск |
| **Шпионаж** (`spy`) | Разбирает шпионские доклады: добыча 50%, сколько «Улучшенных транспортов» (217) нужно (рейд — только ими, другого транспорта не предлагается), время полёта и дейтерий, возможные обломки. Значок в каждом докладе и таблица во вкладке. Кнопки: Рейд (с подтверждением), Подготовить, Шпионить (нет зондов на текущей планете — летят с той, где они есть, и игра возвращается на вашу планету; 611 — «на планете нет шпионских зондов»), Симулятор (симулятор самой игры), В цели, Удалить | Сообщения; Панель → Шпионаж |
| **Межпланетные ракеты** (`missiles`) | Сколько МПР нужно на снос обороны цели (с учётом перехватчиков, оружейной и щитовой), строка расчёта в шпионских докладах, кнопка 🚀 в галактике. Окно расчёта; «Запустить» — только после отдельного подтверждения | Сообщения; Галактика; Панель → Ракеты |
| **Статистика** (`stats`) | Итоги боёв, экспедиций, переработки, транспорта по сообщениям; дневная диаграмма. «Сканировать сообщения» — только по клику и с подтверждением | Сообщения; Панель → Статистика |
| **Слежка** (`stalk`) | Журнал активности выбранных игроков по просмотрам галактики. «Сканировать» — по клику и после окна с предупреждением о дейтерии. Автоскан по умолчанию выключен | Панель → Слежка; глазок в галактике |
| **Полёты** (`flights`) | Вкладка «Полёты»: все полёты туда/обратно, «Отозвать» (с подтверждением). Компактная диаграмма над списком передвижения флота. Предупреждение об атаке (⚠ в заголовке вкладки) | Панель → Полёты; страница «Флот» |
| **Резерв и сбор** (`fleethelp`) | «Всё, кроме резерва» и «Транспорт для ресурсов» на странице «Флот», «Все ресурсы, кроме резерва» на шаге 2. Вкладка «Сбор»: что можно свезти на выбранную планету (только «Улучшенными транспортами» 217; если их мало — «не хватает N»). **«Собрать всё»** — одно окно подтверждения со списком всех полётов, после «Да» расширение само отправляет каждый полёт; «Подготовить» / «Пошаговый сбор» только заполняют форму, отправку жмёте вы | Флот; Панель → Сбор |
| **План построек** (`todo`) | Кнопка «+» в правом верхнем углу иконки добавляет уровень в план. Вкладка «План»: стоимость, хватает ли ресурсов, «Построить» (с подтверждением) | Постройки, Исследования, Верфь, Оборона; Панель → План |
| **Почта** (`mail`) | Новое меню сообщений: вкладки с новыми/всего, строка на сообщение, поиск, фильтры, сортировка, массовые «Удалить»/«Прочитано» (с подтверждением), рейд (только 217) и зонды по отмеченным с подтверждением, очистка по правилам. Кнопка «Старый вид» возвращает родную страницу | Сообщения |
| **Настройки** (`prefs`) | Все настройки, горячие клавиши, экспорт/импорт данных в JSON | Панель → Настройки |

**Горячие клавиши** (меняются в «Настройках»): `Alt+Shift+I` — панель; `Alt+PageUp` / `Alt+PageDown` — предыдущая /
следующая планета; `Alt+Shift+1…9` — Обзор, Постройки, Сырьё (настройки добычи), Исследования, Верфь, Флот, Галактика,
Сообщения, Империя; на странице «Флот» `Alt+Shift+A` — выбрать все корабли, `Alt+Shift+R` — сбросить.

### Почта
Страница «Сообщения» открывается в новом виде: вкладки (новые / всего), одна строка на сообщение, поиск, фильтры,
сортировка. Отметьте сообщения галочками — внизу появятся «Удалить», «Прочитано», «Рейд» (только улучшенные транспорты 217)
и «Зонды по отмеченным». Всё массовое — только после окна подтверждения. «Старый вид» — вернуть родную страницу.
Кнопка «Рейд» в строке и клавиши `r` (рейд) / `s` (зонды) тоже сначала показывают окно с планом; без выбранной строки
(↑↓ / j k или клик) клавиши ничего не делают. Автоочистка при включённом боте не трогает его свежие письма (шпионаж,
бои, экспедиции) — настройка «не трогать письма бота моложе, мин», по умолчанию 15.

### Ракеты
Панель → «Ракеты», строка в шпионском докладе или кнопка 🚀 в галактике: сколько межпланетных ракет нужно, чтобы снести
оборону цели. «Запустить» отправляет ракеты только после отдельного подтверждения.

## 5. Что пока не работает или работает частично на GALAXYZ (и почему)

- **Бот** — работает (раздел 8). С 0.3.2 он включён по умолчанию вместе со всеми функциями. Часть разметки игры
  (очередь построек, враждебный флот в списке событий) взята из исходного кода 2Moons и ещё не сверена с живым сервером.
- **Время постройки** в «Плане» показывается как «—»: скорость игры (экономики/исследований) сервер нигде не показывает.
  По той же причине в окне Live скорость экономики и исследований — «неизвестно».
- **Данные других планет** обновляются, только когда вы их открываете или заходите в «Империю». Страница «Империя»
  не показывает склады и потребление энергии, поэтому для таких планет вместо выработки стоит «?/ч» или «—» (а не ложный 0).
- **Окончание текущей постройки** у других планет не видно: игра в списке планет показывает только значок «строится».
- **Список полётов** обновляется при переходе на другую страницу игры или по кнопке ⟳. Фонового опроса нет
  (он держал бы аккаунт «онлайн»). Его можно включить: «Полёты» → настройка «GALAXYZ: обновлять полёты в фоне».
- **Шпионить из доклада** можно, только если игра уже показала ID планеты (вы открывали эту систему в галактике).
  Иначе расширение ничего не отправит и предложит открыть систему — это стоит дейтерий.
- В докладах GALAXYZ нет имени игрока и обломков, поэтому вместо игрока показывается название планеты, обломки — «—».
- **Не проверено на живом сервере** (на сохранённых страницах этого не было, сделано по исходникам 2Moons):
  окно деталей постройки (техстоимость, «+ в план»), шаг 2 экспедиции с выбором времени удержания, чужие и вражеские
  флоты в списке событий (предупреждение об атаке), страницы рейтинга, поиска и карточки игрока, сообщения о боях,
  экспедициях, транспорте и ракетах (статистика помечена «не проверено»). Если что-то из этого выглядит не так —
  пришлите логи (раздел 6).
- Груз собственных кораблей сервера (213–220) взят из данных 2Moons и не подтверждён.
- Луны: у аккаунта пока нет луны, разметка лун на сервере не проверялась.
- **Автоскан слежки**: после того как вы один раз включили его и подтвердили окно про дейтерий, он сам смотрит
  системы в фоне (с ограничением в час, только пока вкладка открыта). Если хотите, чтобы каждый просмотр был только
  по клику — не включайте автоскан и пользуйтесь кнопкой «Сканировать».
- Чтение сообщений через «Загрузить все отчёты» / «Сканировать сообщения» отмечает их прочитанными (так работает игра).

## 6. «Логи для разбора»: как отправить, если что-то не так

1. Повторите проблему: откройте нужную страницу, нажмите кнопку, подождите несколько секунд.
2. Если проблема во внешнем виде — на этой же странице откройте Панель → **Логи** и нажмите
   **«Сделать снимок этой страницы»**.
3. Там же (Панель → **Логи**, или значок расширения → вкладка **«Логи»**) нажмите **«Выгрузить логи»** — один файл
   со всем нужным. Отдельные выгрузки (за сегодня, новое, снимки, самообучение) — в «Ещё».
4. Браузер скачает файл. Пришлите его разработчику вместе с коротким описанием:
   что делали, что ожидали увидеть, что увидели на самом деле. Скриншот тоже помогает.
5. **Логи → «Скан страниц»** (сервер GALAXYZ): расширение само обходит все страницы игры всех планет и лун (только
   чтение, паузы 0,3–0,6 с, бот на это время ставится на паузу) и выгружает один ZIP. Заметки, тикеты, список друзей и
   ваучеры не открываются; e-mail, значения полей почты и пароля и textarea вырезаются. Пришлите его, если разработчику
   нужны страницы вашей игры. Отдельный скрипт без расширения — `tools/pagescan/ogx-pagescan.user.js` (1.1.0): не
   открывает заметки, тикеты и список друзей, вырезает e-mail и User-Agent (подробности в `tools/pagescan/README-RU.md`).

## 7. Приватность

- Расширению **не нужен ваш пароль**: оно работает с уже открытыми страницами игры. Единственное исключение — по вашему
  желанию: поля «Автовход: логин» и «Автовход: пароль» в настройках бота (раздел 8.4). Они хранятся только в хранилище
  расширения в этом браузере и отправляются только в форму входа самой игры. **Пароль** не попадает ни в журнал, ни в
  выгрузки логов, ни в экспорт настроек (даже его длина). **Логин** — обычная настройка: он виден в шапке «Выгрузить
  логи» (настройки модулей, «НАСТРОЙКИ (все, JSON)») и в «Экспорт всего» — учитывайте это, прежде чем делиться файлом.
- **Ничего никуда не отправляется**: нет телеметрии, нет сторонних серверов. Все запросы идут только на сервер игры
  и только те, которые сделала бы сама игра при обычном использовании.
- Все данные хранятся **только в вашем браузере** (хранилище расширения). Удалите расширение — данные удалятся.
- В «Логи для разбора» не попадают пароли, токены, cookie и e-mail; из введённого текста сохраняется только длина,
  в снимках страниц вырезаны скрипты и значения полей. Файлы логов уходят только туда, куда вы сами их отправите.
- Экспорт/импорт: Панель → Настройки → «Резервная копия и обмен» — сохранить все данные в файл и загрузить обратно
  (например, на другом компьютере).
- Разрешение `unlimitedStorage` в манифесте только снимает ограничение 10 МБ на данные расширения в вашем браузере;
  нового запроса при установке оно не добавляет.
- На сайтах, которые не являются игрой, расширение ничего не делает: ни таймеров, ни чтения хранилища, ни изменений
  страницы, ни перехвата запросов.

## 8. Бот

Раздел **«Бот»** (Панель → группа «Бот») — полная автоматизация: сейв флота и защита, фарм неактивных со шпионажем,
сбор обломков и подвоз ресурсов, стройка и исследования, экспедиции и колонизация, снос обороны ракетами. Это единственная часть расширения,
которая действует в игре **без клика на каждое действие**. С 0.3.2 — сразу после установки (максимальная автономность).

### 8.1. Что включено сразу после установки (с 0.3.2 — всё)

- Главный выключатель бота **включён**, «Пробный режим» **выключен**: бот сразу действует в игре сам.
- Все модули бота **включены**, и в каждом включены все функции: стройка на лунах и купола; сейв, шпионаж
  атакующего и ночной сейв; экспедиции, колонизация и постройка колонизатора; обломки, логистика и своз ресурсов
  с колоний; фарм со сканом галактики, достройкой кораблей, быстрым шпионажем и удалением обработанных докладов.
- **Автовход** включён (логин и пароль по умолчанию не сохранены: после вылета бот ждёт пароль от браузера, см. 8.4),
  «Просмотров галактики в час» — 300.
  с колоний; фарм со сканом галактики, достройкой кораблей, быстрым шпионажем и удалением обработанных докладов;
  **ракеты** — снос обороны целей фарма межпланетными ракетами, с постройкой ракет и просьбой построить ракетную шахту.
- **Автовход** включён, «Просмотров галактики в час» — 300.
- Выключены только настройки, которые не функции, а исключения: «Режим сна», «Не сейвить при слабой атаке».
- **Обновление с 0.3.1 и раньше:** при первом запуске 0.3.2 бот один раз включает всё перечисленное, даже если раньше
  это было выключено, и пишет об этом в «Журнал» (запись «Все функции бота включены»). Что вы выключите после
  этого, останется выключенным. Лимиты «Отправок флота в час» 30 и «Заказов построек в час» 1000 (старые значения
  по умолчанию) один раз поднимаются до 500 и 5000 (запись «Лимиты подняты под «всё на авто»»); значения, которые
  вы вводили сами, не трогаются.

### 8.2. Первые шаги

1. **Пройдитесь по страницам игры**, чтобы у бота были данные: Обзор, Империя, Постройки, Исследования, Верфь, Флот
   (`page=fleetTable`), Сообщения. Откройте один раз страницу отправки флота (шаг 1) — так бот узнает скорость флота
   сервера (он узнаёт её и сам из первой отправки).
2. Панель → **«Бот» → «Общие»**: проверьте лимиты (раздел 8.4) и при желании режим сна (раздел 8.5).
3. Первые часы поглядывайте в **«Бот» → «Журнал»**: что бот сделал, с какой планеты, куда, каким флотом и **почему**.
   Если что-то неверно — «Стоп» и пришлите логи (раздел 8.9).
4. **«Стоп»** выключает бота сразу и отменяет очередь, **«Пауза»** приостанавливает его, **«Продолжить»** снимает
   паузу. Сейв и защита флота (приоритет «защита») работают и на паузе — полностью бота останавливает только «Стоп».
   Чтобы бот только планировал и ничего не отправлял, поставьте «Пробный режим».

Модуль можно выключить в любой момент своей галочкой — остальные продолжают работать.

### 8.3. Модули и их настройки

Все настройки — во вкладке модуля. В скобках значение по умолчанию. «МСУ» — металлический эквивалент
(кристалл и дейтерий пересчитаны в металл по курсам из «Общих»: 1,5 и 3).

#### «Сейв» — сейв флота и защита

Следит за враждебными флотами, летящими на ваши планеты и луны. Если атака опасна, незадолго до удара увозит флот
и ресурсы, а после удара отзывает флот домой.

- **Порядок проверки атаки:** белый список → ракеты → только шпионаж → слабая атака → «нечего терять» → сейв.
  На каждую атаку в журнале одно решение с причиной.
- **Когда:** сейв стартует между «Сейв не раньше чем за» (90 с) и «Сейв не позже чем за» (30 с) до удара.
- **Куда («Порядок миссий сейва»):** передислокация на свою луну («Сначала свои луны», вкл.), затем на свою планету →
  транспорт на своё тело → сбор поля обломков рядом (±5 систем) → экспедиция (последний вариант, с предупреждением).
  Тела, которые сами под атакой, не выбираются. Скорость — самая медленная, которая успевает с «Запасом времени
  полёта» (30 %) и на которую хватает топлива.
- **Ресурсы:** «Забирать ресурсы при сейве» (вкл.) — грузит точно, сначала дейтерий, потом кристалл, потом металл;
  «Оставлять дейтерия на планете» (0). Сейв увозит все корабли тела, а ресурсы кладёт **только в трюмы «Улучшенных
  транспортов» (217)** этого флота (малые / большие транспорты и боевые корабли ресурсы не везут); если 217 на планете
  нет, флот улетает без ресурсов (запись в журнале). Отдельных транспортов бот к сейву не добавляет. Сбор обломков как место сейва — только если во флоте есть «Мега переработчики»
  (219).
- **Отзыв:** «Отзывать флот после удара» (вкл.). Отзыв ставится так, чтобы флот вернулся **после** удара (+30 с),
  со случайной добавкой 40–140 с. Пришла вторая волна — отзыв переносится. Отзыв переживает перезагрузку страницы.
- **Ракеты:** «Строить ракеты-перехватчики против МПР» (вкл.) — при ракетной атаке заказывает перехватчики,
  сколько влезет в шахту, по карману и успеет достроиться до удара.
- **Фильтры:** «Не реагировать на шпионаж» (вкл.); «Не сейвить при слабой атаке» (выкл.) и «Слабая атака: наши очки
  больше в N раз» (3); «Белый список игроков» (пусто); «Нечего терять: меньше N очков» (0 = выкл.).
- **«Шпионить атакующего»** (вкл.) — зондов столько, сколько в настройке «Зондов на шпионаж» модуля «Шпионаж» (1100), но не больше, чем есть на планете; только если остаётся свободный слот сверх резерва.
- **Ночной сейв:** «Сейв при засыпании бота» (вкл.), «Только с лун» (вкл.), «Оставлять дейтерия» (0) — когда бот
  засыпает (раздел 8.5), увозит флот до пробуждения.

Сейв — защита: он работает и во сне, и пока вы сами кликаете в игре, и может взять резервный слот.
Флот, который садится на атакуемое тело до удара (возврат рейда или экспедиции), сейв ждёт и увозит вместе с
остальными (или отдельным сейвом, если сейв уже ушёл); нет свободного слота — повтор каждые ~10 с до «удар − 10 с».

#### «Фарм» — фарм неактивных

Ищет неактивных игроков («i» и «I») в вашей галактике, ведёт по ним базу, шпионит, считает добычу, затраты и
окупаемость и атакует, если выгодно.

- **Цели:** из уже просмотренных систем галактики. «Сканировать галактику» (вкл.) — бот сам обходит системы:
  «Где искать цели» = «Вся моя галактика» (по умолчанию: все 499 систем каждой галактики, где есть ваши планеты,
  ближние первыми) или «Только радиус» («Радиус поиска», 15); не больше «Просмотров галактики за один проход» (40) и
  не чаще «Пересканировать систему» (24 ч), одной порцией раз в 5 мин и оставляя 20 % «Просмотров галактики в час»
  другим модулям; работает только если в «Общих» разрешены просмотры галактики (при 300 в час
  вся галактика обходится примерно за 2 ч). «Брать и „i“» (вкл.), «Только игроки с местом не выше» (0 = все), «Исключить» (координаты,
  имена или id). Цели в режиме отпуска не трогаются никогда. Перед каждой атакой бот проверяет, что игрок всё ещё
  неактивен, по строке галактики не старше 1 ч (иначе один просмотр системы): вернулся — пауза 24 ч «игрок активен»;
  у позиции новый владелец — цель начинается заново.
- **Шпионаж:** зондов столько же, сколько в настройке «Зондов на шпионаж» модуля «Шпионаж» (1100; если на планете меньше — сколько есть, но не меньше минимума по формуле 2Moons); если доклад неполный, бот повторяет («Повторов шпионажа», 2); «Доклад старше
  N мин — шпионить заново» (30). Ответ сервера 611 — «на планете нет шпионских зондов». «Удалять обработанные шпионские доклады» (вкл.). «Шпионить быстрой отправкой» (вкл.) — так игра
  отправляет столько зондов, сколько стоит в её настройках «Зондов на шпионаж» (поставьте там 1100); если она отправила
  меньше, бот пишет об этом в журнал и сутки шпионит обычной отправкой с точным числом.
  Сервер создаёт доклад только при загрузке обычной страницы, поэтому после прилёта зондов бот один раз открывает
  обзор и читает почту через 5 с, 30 с, 90 с, 5 и 15 мин (2–3 страницы, если доклад сдвинуло); доклада нет — пауза
  цели 1 ч («нет доклада»), опоздавший доклад её снимает; «зонды уничтожены» — только по самому докладу, пауза 2 ч.
- **Запас зондов:** шпионаж уходит только с планеты, где после отправки останется резерв «Экспедиций» («Не брать в
  экспедиции последние N зондов», когда «Экспедиции» включены) плюс «Зонды: оставлять на теле» (0); сопровождение
  может брать и резерв. Если зондов сверх резерва не хватит на следующий проход, «Зонды: достраивать на главной
  планете» (вкл.) заказывает их на главной (не больше «Зонды: заказывать не больше», 50 000 в час; не заказывает, пока
  верфь уже строит зонды).
- **Атака:** «Минимальная добыча» (10 млн МСУ), «Полёт не дольше» (7200 с), «Топливо не больше доли добычи» (0,1).
  Добычу возят **только «Улучшенные транспорты» (217)**: 40 млн на корабль × бонус «Хранителя» (или вместимость,
  измеренная по данным сервера); малые и большие транспорты бот не берёт никогда. Беззащитную цель грабят только
  транспорты 217 с «Запасом трюма» (10 %). Если у цели флот или оборона — бот подбирает боевое сопровождение
  симулятором боя (сверен с кодом 2Moons). «Смешанный флот» (вкл.): бот пробует и все свои боевые корабли планеты
  вместе, а «Ул. трансп.» сверх нужного трюма идут прикрытием (в 2Moons урон делится по числу кораблей), без
  достройки. Ничья в 2Moons — флот цел, но без добычи, поэтому условия такие: «Вероятность победы» не меньше 0,8 и
  «Вероятность не проиграть (победа или ничья)» не меньше 0,99; потери не больше «доли добычи» (0,25), «Прогонов
  симулятора» (60). Если для атаки нужно достроить корабли, а достройка дольше лимита — бот сначала ищет состав только
  из своих кораблей; нет такого — цель получает пометку «нужен флот: ещё N кораблей» и паузу («Нужен флот больше, чем
  есть: пауза», 6 ч), а не перешпионаж каждые 30 мин.
- **Бедные цели:** добыча ниже порога — бот считает по докладу (шахты × скорость сервера, предел хранилищ), когда
  ресурсы отрастут, и шпионит снова тогда (не раньше 30 мин, не позже недели). Пустые планеты без шахт — раз в неделю
  («Бедная цель: шпионить снова, когда отрастёт», вкл.).
- **База целей** (вкладка «Фарм», таблица «База целей»): по каждой цели — игрок, ресурсы последнего доклада и их
  прирост в час, стоимость обороны и флота, добыча и итог одного рейда после топлива и потерь (и окупаемость ×N),
  сколько рейдов и сколько добыто всего (по боевым докладам; потерянные зонды тоже считаются затратой), оценка
  («выгодно», «нужен флот», «бедная», «сильная защита») и что дальше. Сверху — сводка, кнопка «Скачать базу целей
  (CSV)» открывается в Excel. Цели, которых нет в галактике дольше «Хранить пропавшие цели» (14 дн.), удаляются.
- **Не хватает «Ул. трансп.»:** «Отправлять сколько есть» (вкл.) — атака уходит с теми 217, что есть, только если они
  вывезут не меньше «доли ожидаемой добычи» (0,5); иначе цель пропускается, в журнале «не хватает N Ул. трансп.».
- **Сопровождение:** «Шпионское сопровождение атаки» (вкл.) — зонды прилетают к цели за 90–120 с до флота
  («Сопровождение: зонды прилетают за столько секунд до удара», 90), бот читает доклад до момента «удар − 20 с»; доклада
  нет — атака летит дальше, если разведка моложе 30 мин, иначе отзывается. Если цель
  изменилась (появилась луна, флот, оборона) и «Отзывать атаку, если обстановка изменилась» (вкл.) — атака
  пересчитывается и при необходимости отзывается.
- **Лимит атак в сутки:** «Атак на одну цель за сутки, не больше» (6 — лимит сервера 2Moons); цель на лимите не
  шпионится и не оценивается до конца суток. Ответ сервера «Превышен лимит количества атак в сутки…» — эта цель на
  паузе 24 ч, остальные продолжаются (это не ошибка бота); бот запоминает, после скольких атак пришёл отказ, и дальше
  не шлёт больше этого числа.
- **Ответы сервера о цели:** «Пункт назначения не существует» — «нет планеты»; отпуск — пауза 24 ч; «Игрок слишком
  слаб/силён», защита новичков — 24 ч; «Полёты на администраторов запрещены» — 7 дн.; текст ответа виден в базе целей.
- **Непобедимые цели:** если проигрывает весь наш флот или достройка заняла бы больше 24 ч — пауза 24 ч, затем 48 ч и
  дальше до недели без повторного шпионажа, пока наш флот не вырастет вдвое. Достройка — не дольше 2 ч на верфи и не
  дороже добычи с этой цели за 7 дней.
- **Метки «Целей» (Infinity):** «Метка: никогда не атаковать» (красная) — цель не шпионится и не атакуется; «Метка:
  оценивать первыми» (зелёная, а также отмеченные «цель») — такие цели идут первыми. Работает, когда модуль «Цели»
  отдаёт метки боту.
- **Ограничения:** «Атак фарма в полёте одновременно» (0 = авто: свободные слоты минус резерв и 4 для других модулей,
  не меньше 3; шпионаж идёт и пока атаки в полёте), «Целей за один проход» (10), «Планеты/луны отправки»
  (пусто = все). «Достраивать недостающие корабли» (вкл.), «Достройка + полёт не дольше» (30 мин).

#### «Обломки» — обломки и логистика

- **Корабли:** обломки собирают **только «Мега переработчики» (219, 20 млн на корабль × бонус «Хранителя»)**,
  обычные переработчики (209) бот не берёт; нет свободных 219 — сбор пропускается с записью в журнале. Транспорты
  логистики — только «Улучшенные транспорты» (217); не хватает — «не хватает N Ул. трансп.» в журнале.
- **К боям фарма:** «Посылать переработчики к боям фарма» (вкл.) — переработчики прилетают через 1–2 с после боя
  («Прибытие после боя, мин./макс.»), «Запас переработчиков» (10 %). «Оставлять остаток поля у целей фарма» (вкл.,
  1000) — тогда переработчики можно выслать заранее, к уже существующему полю (лишний трюм 219 заполняется металлом
  с тела отправки; если металла не хватает — поле собирается целиком). «Если поля нет — отправлять сразу после
  боя» (вкл.). Бой отменён — переработчики отзываются. Если у планеты-цели нет луны, бой может её создать, и тогда
  поле обломков пропадает целиком (так в коде 2Moons): бот уменьшает ожидание на шанс луны и не высылает
  переработчики заранее, если ожидаемое поле меньше «Пред-отправка к бою: ожидаемое поле не меньше» (1 млн) — после
  боя он видит настоящее поле.
- **Свои поля:** «Собирать поля обломков у своих планет» (вкл.), не меньше «Своё поле» (10 млн), проверка раз в 30–60
  мин: сначала по уже известной галактике; если система в кэше старше «Проверять свои поля раз в, макс.», бот сам смотрит её
  (не больше двух своих просмотров за проход и не чаще раза в «…раз в, мин.» на систему, в пределах «Просмотров галактики в
  час»; при 0 — только кэш). Ближайшая луна, потом планета.
- **Логистика** (вкл.): «Довозить ресурсы под постройки» — если «Стройке» не хватает ресурсов на колонии, бот везёт
  одним рейсом на «Улучшенных транспортах» (217) ресурсы на цепочку шагов стройки этой планеты — на «Довоз под
  стройку: на сколько минут вперёд» (`botbuild.needAheadMin`, вкладка «Стройка», 45 мин; 0 = только текущий шаг), но
  не больше хранилища. Везёт со «Склада» (пусто = тело с наибольшим излишком; тело, которое само ждёт довоз, отдаёт только те
  ресурсы, которых не ждёт), оставляя на складе дейтерий на «Запас
  (ч производства)» (2). «Свозить ресурсы с колоний на склад» (вкл., от 500 млн; пустой «Склад» = первая планета списка) — с колонии не вывозится то, что ей
  нужно на эти минуты стройки, и запас дейтерия на «Запас (ч производства)», и ничего — с планеты, которая ждёт довоз;
  на главную везётся только то, что влезет в её хранилище. «Вывозить излишек при заполнении хранилища» (90 %) —
  такая колония вывозится всегда, до половины своего хранилища. «Перегонять Ул. трансп. на колонию без них» (вкл.) —
  на колонию без 217 бот передислоцирует нужное их число (не больше 5000) и вывозит на следующем проходе. Отказ
  (нечего везти, склад полон, нет слота) — пауза для этой колонии 15–30 мин; в журнале одна строка на ситуацию в час.

#### «Стройка» — стройка и исследования

По умолчанию работает **тактика застройки** («Стратегия развития» → «Тактика застройки: этапы S0–S5»). На этом
сервере добыча ×22000, а стройка идёт секунды, поэтому главное — ресурсы. Бот на каждой планете делает по порядку:

1. Не хватает энергии — **солнечные спутники** (электростанции не строит).
2. Хранилища — правило «авто» («Хранилище на», 0): запас на 3 ч добычи или на длину ночного сна, но не меньше цены
   следующей шахты. **Сначала шахты**: хранилище строится, только когда без него не накопить на следующую шахту.
3. **Фундамент:** роботы 10, наниты 10, верфь 14 («Верфь до», 14).
4. **Лаборатория 22** на каждой планете («Лаборатория до», 22) — когда планета догнала шахты своего этапа или с этапа S2.
5. **Шахты:** всегда самая низкая шахта среди **всех** планет, колонии раньше главной. Пока колония отстаёт, главная
   свои шахты не качает.
6. Поля кончаются — терраформер («Свободных полей держать», 1).

**Этапы:** S0 — фундамент новой планеты; S1 — колонии догоняют главную (шахты 45/45/41); S2 — все 50; S3 — все 55;
S4 — все 60; S5 — все 65, дальше +5.

**Исследования:** сначала то, что открывает «Улучшенный транспорт» (217) — на нём держится вся перевозка, — потом
«Мега переработчик» (219, ему нужна верфь 15: поднимите «Верфь до», если нужен). Затем астрофизика, пока растёт число
планет, и самая короткая из технологий добычи; сеть лабораторий — по числу планет с лабораторией 22 минус 1. Торговца бот
сам не использует.

**«План застройки»** — на вкладке «Стройка» в панели бота. Видно, на каком вы этапе (полоски с процентами), что
дальше на каждой планете (шаг, цена, когда накопится при нынешней добыче, почему), что мешает (энергия, хранилища,
поля, ресурсы, нужное исследование) и путь исследований. Это только информация: план виден и при выключенном боте,
и в пробном режиме, запросов к игре не делает. Данные берутся из того, что бот или вы уже открывали (лучше всего —
страница «Империя»).

- Старые стратегии «Только шахты» (col_mine90), «С экспедициями» (dis_exp90) и «Свои параметры» (JSON) остались — они
  выбирают шаг по окупаемости (цена ÷ прирост добычи в час); там энергию могут чинить и электростанциями.
- «Строить здания» (вкл.), «Исследовать технологии» (вкл.), «Строить на лунах» (вкл.), «Ставить купола» (вкл.),
  «Компьютерная технология для слотов экспедиций» (вкл.), «Строить университет» (вкл., только старые стратегии).
- Правила игры соблюдаются: заказ только в пустую очередь, нет лаборатории/терраформера во время исследования,
  нет верфи/нанитов во время работы верфи и т. д. Не хватает ресурсов — бот ждёт и резервирует цену.
- «Повторов неподтверждённой постройки» (3) — потом этот пункт на паузе 30 мин. «Случайный порядок планет» (вкл.).
- Строит бот, только когда включены бот и «Стройка», а пробный режим выключен. В пробном режиме он пишет в журнал, что
  заказал бы следующим.

- **Очередь построек** («Построек в очереди планеты сразу», `botbuild.queueDepth`, 5): бот ставит следующую постройку в
  занятую очередь планеты (игра принимает до 5), если склад планеты оплачивает все стоящие в очереди. Игра списывает
  ресурсы за постройку из очереди, когда она начинается. 1 = по одной, как раньше.
- **Спутники пачкой** («Спутники одним заказом», `botbuild.satAheadLevels`, 10): один заказ спутников покрывает нехватку
  энергии плюс 10 следующих уровней всех трёх шахт планеты, если склад планеты платит; иначе — только нехватку.
  Партия не дольше «Партия спутников не дольше» (`botbuild.satBatchMaxMin`, 30 мин работы верфи; на Aeternum 1 с/шт.,
  то есть до 1800 спутников за заказ), чтобы верфь не стояла часами. Пока в очереди верфи есть спутники, новая партия
  не заказывается, а их энергия уже считается.
- **Шахты из излишков** (`botbuild.surplusMines`, вкл.): планета, у которой шахты уже на цели этапа, не стоит, пока
  колонии догоняют: она качает свою самую низкую шахту дальше, но только из своего склада и только из того, что
  остаётся после довоза, который ждут другие планеты. Довоз под такие шахты бот не заказывает.
- **Заказ без чтения страницы:** бот заказывает по своим данным о планете; страница, которую игра возвращает на заказ,
  и есть свежие данные для следующего. Страница планеты читается заново, только если заказ не прошёл, на планету
  прилетел транспорт или данным больше 10 минут.

#### «Экспедиции» — экспедиции и колонизация

- **«Отправлять экспедиции»** (вкл.). Все экспедиции — в свою систему, позиция 16, скорость 100 %.
- **«Режим экспедиций»:** **«Тёмная материя» (по умолчанию)** — в каждый слот «Зондов в одной экспедиции» (5000):
  на Aeternum ТМ экспедиции растёт с очками флота (код движка: очки флота × 0,5–1,5). Последние «N зондов» (2000) бот
  не берёт — они для шпионажа; если зондов меньше, летит сколько есть сверх резерва, а когда сверх резерва ничего
  нет — экспедиция с этого тела не отправляется (зонды достраиваются). Зондов нет совсем — летит один «Малый транспорт»
  (202), это единственный запасной вариант.
  «Достраивать зонды» (вкл.): чёрная дыра забирает весь флот, поэтому бот держит на планете старта «Держать зондов»
  (дома + в экспедициях; 0 = 2 × слоты экспедиций × зондов в экспедиции + резерв, при 4 слотах 42 000) и заказывает
  недостающие на верфи, не чаще раза в 3 мин.
  **«Подбор состава»** — бот по очереди отправляет варианты флота из «Подбор состава: варианты флота» (по умолчанию 1,
  100, 2000 и 10 000 зондов с удержанием 1 ч и 1 зонд на 2 ч), каждый по «полётов на вариант» (8) раз, считает по
  сообщениям о возврате ТМ в час на слот и дальше шлёт лучший вариант (10 % полётов — проверка остальных).
  Таблица «ТМ по составу экспедиций» во вкладке модуля показывает ТМ/ч каждого флота (★ — лучший) в обоих режимах.
  «Ресурсы» — доля
  «Улучшенных транспортов» (217) — других грузовых бот не берёт («Доля», 0,1; «Типы кораблей», пусто = 217;
  «Добавлять 1 зонд», вкл.);
  «Авто» — что выгоднее за слот-час (задайте «Цену 1 ТМ в металлическом эквиваленте»: при 0 тёмная
  материя в расчёте ничего не стоит).
- «Удержание» (1 ч), «Точки старта» (пусто = автоматически), «Пауза между флотами» (5–15 с), «Новый раунд после
  возврата» (3–15 с). Бот не отправит экспедицию, если она вернётся во время сна.
- **Поиск ТМ сборщиками** (раздел «Бот: поиск тёмной материи», вкл.): миссия 11 — флот только из
  «Сборщиков тёмной материи» (220) летит на **свою луну**. Шанс находки 15 % + 0,25 % за каждый корабль (максимум 30 %
  при 60 кораблях, так в коде движка GALAXYZ/Xterium), размер находки на Aeternum неизвестен — итог виден во вкладке.
  При удаче сборщики расходуются. Сервер не показывает, сколько таких флотов можно сразу (счётчик «Астероиды» на
  странице «Флот» — это добыча астероидов, миссия 16): бот считает 5, а если сервер откажет, запоминает настоящее число
  («Флотов поиска ТМ одновременно», 0 = так). Сборщики делятся поровну, каждому флоту хотя бы один. Свободные слоты экспедиций и резерв слотов
  флота бот не занимает. «Строить сборщики» (вкл.) держит на планете старта «Держать сборщиков» (400). Без своей луны
  бот раз в ~6 ч проверяет, не предлагает ли сервер эту миссию на позиции 16, показывает «нужна своя луна» во вкладке
  (в журнал — не чаще раза в 6 ч) и запускается сразу, как только появится луна.
- Во вкладке модуля — **прирост ТМ в час** по счётчику в шапке игры (все источники).
- Если за проход ничего не отправлено, бот проверяет снова через 60 с, потом вдвое дольше — до 10 мин.
- Результаты экспедиций (находки, чёрные дыры, ТМ) собираются в статистику во вкладке модуля. Отчёт и сообщение о
  возврате сервер GALAXYZ создаёт только при обычном (не ajax) запросе, а сообщения бот читает ajax-запросом: поэтому бот
  читает их через 20 с после события и только после обычного запроса (если его 45 с не было — читает страницу флота
  сам), повторяет через 30 с × n, до 6 раз за 15 мин, одним чтением на весь раунд; ненайденные считаются отдельно
  («без сообщения»). «Сдвиг времени» (задержка = плановый возврат + удержание, как в коде 2Moons) переносит ожидаемый
  возврат, и бот ждёт его, а не закрывает экспедицию без итогов.
- **Колонизация** (вкл.): «Цели колонизации» (JSON: галактика, диапазон систем, позиции по порядку), проверка, что
  место пустое, без просмотра галактики; колонизатор загружается ресурсами («Загружать колонизатор», вкл.). Пока список
  целей пуст, бот ничего не читает и не делает.
  «Мин. полей по позиции» — маленькая колония только записывается в журнал, бот **никогда не бросает** планеты.
  «Строить колонизатор, если его нет» (вкл.).

#### «Ракеты» — снос обороны целей фарма

Бот сам **строит межпланетные ракеты (503) и запускает их** по неактивным целям «Фарма», пока оборона цели не
будет снесена в ноль, — **без подтверждения каждого запуска** (это заменяет правило «каждый запуск — два клика»;
ручной инструмент «Ракеты» в Infinity по-прежнему спрашивает подтверждение). Дальше цель грабит «Фарм».

- **Нужен включённый «Фарм»:** цели и шпионские доклады берутся из его базы целей. Цель берётся, если она
  неактивна, не исключена, добыча проходит «Минимальную добычу» фарма, доклад свежий («Доклад не старше», 180 мин)
  и в нём есть оборона.
- **Пусковая планета** — своя планета (не луна) с **ракетной шахтой 4+** и импульсным двигателем 1+; цель в той же
  галактике и не дальше «импульсный × 5 − 1» систем. Из подходящих бот берёт планету, где больше ракет, затем с большей
  шахтой, затем ближнюю. Планета под атакой (угроза) не запускает.
- **Расчёт:** сколько ракет нужно, считает та же математика, что и ручной инструмент «Ракеты» (как в движке 2Moons):
  перехватчики цели (502) сбивают ракеты 1:1 и тратятся; урон ракеты 12 000 × (1 + 0,1 × ваша оружейная);
  прочность обороны — по щитовой технологии цели (настройка «Структура обороны считается по технологии»; если в докладе
  нет технологий — берётся ваш уровень, с запасом). Сверху «Запас ракет» (10 %).
- **Волнами:** шахта уровня N вмещает N × 10 мест, ракета занимает 2 (перехватчик — 1): шахта 4 = 20 ракет. Бот
  строит ракеты до заполнения шахты (или до всей нужды, если меньше), ждёт верфь, запускает волну, после удара просит
  «Фарм» отшпионить цель заново и считает следующую волну по **новому докладу** (доклад о попадании не читается —
  правда в докладе шпионажа). Пока летит волна, новых запусков нет. Ракеты **не занимают слот флота** (в движке
  слоты считают все миссии, кроме ракет), но считаются в лимит «Отправок флота в час».
- **Нет шахты 4 в досягаемости:** не чаще раза в час запись в журнал «Нужна ракетная шахта 4 на планете в пределах
  N систем…»; с настройкой «Просить стройку построить ракетную шахту 4» (вкл.) модуль «Стройка» строит шахту 4
  (с требованиями) на планете, откуда достаётся больше целей.
- **Безопасность:** активных игроков бот не трогает (цель из «Доп. целей» у активного игрока пропускается с записью
  в журнал); отказ сервера (отпуск, защита новичка, слишком сильный, администратор, планеты нет) — пауза цели на сутки;
  отказ пусковой (шахта, двигатель, дальность) — другая пусковая через час; «Пробный режим» — только расчёт и журнал.
- Вкладка **«Ракеты»** в разделе «Бот»: цель, сколько обороны осталось, перехватчики, нужно / запущено, пусковая,
  состояние (расчёт, строятся ракеты, ракеты летят, ждёт доклад, оборона снесена, пауза).

Настройки: «Ракеты на автомате» (вкл.), «Строить межпланетные ракеты (503) под волну» (вкл.), «Просить стройку
построить ракетную шахту 4, если пусковой нет» (вкл.), «Доп. цели g:s:p» (пусто; должны быть в базе фарма),
«Не трогать цели g:s:p» (пусто), «Доклад не старше (мин)» (180), «Запас ракет сверх расчёта (%)» (10), «Структура
обороны считается по технологии» (щитовая, как в 2Moons / броня), «Не больше ракет на одну цель» (2000), «Не больше
ракет за 24 часа» (5000).

Лимит исчерпан — бот ждёт до конца часа (в состоянии написано «лимит исчерпан»).

Строка «Запросов: … (чтений …, из кэша …), построек …, отправок …» в панели бота — счётчик за последний час
(сбрасывается при перезагрузке страницы).

**Автоостановка.** Бот останавливается сам и подаёт сигнал (всплывающее сообщение, мигающий заголовок вкладки, звук),
если игра разлогинила, показала капчу, включён режим отпуска, аккаунт заблокирован или незнакомая страница (не игра:
техработы, страница прокси) приходит 5 раз подряд дольше 10 минут — одна такая страница считается обычной ошибкой
с откатом (в журнале «unknown-page» с началом текста страницы). После остановки он запускается **только вашей
кнопкой** «Старт». После ошибок подряд он делает откаты всё длиннее (5–15 с, 40–140 с,
4–6 мин, 25–35 мин) — отдельно для каждого модуля: ошибки фарма не держат стройку и сейв. После 5 ошибок подряд в одном
модуле бот встаёт на паузу «много ошибок подряд», но не навсегда: раз в 30–60 минут он читает обзор и, если страница
пришла нормально, продолжает работу сам (в журнале «Бот продолжает работу», в панели — время следующей проверки);
«Продолжить» снимает паузу сразу. Сейв и защита (приоритет «защита») работают и во время откатов и паузы: их держат
только «Стоп», вылет из игры и капча.

Ответы игры о фактах — «не хватает ресурсов», «очередь заполнена», «нет лаборатории», цель в отпуске / под защитой
новичков / удалена, «Превышен лимит количества атак в сутки», коды быстрой отправки 601–605, 614–619, 699 — это
**отказы, а не ошибки**: модуль получает текст игры и решает сам, откатов и паузы из-за них нет. Ошибки — это сбои сети,
незнакомые страницы и непонятные ответы. Капчей бот считает только саму форму капчи (поле ввода, виджет reCAPTCHA /
hCaptcha, проверку Cloudflare, страницу `page=captcha`), а не слово «captcha» в названии чужой планеты или в письме.

**Текущая планета.** Игра помнит планету последнего запроса; бот возвращает вашу планету (запрос обзора) только когда
вы можете кликнуть: вкладка видна и вы были активны последние 10 минут или открыта страница с формами (постройки,
верфь, исследования, флот, галактика), либо вы работаете в другой вкладке игры. В скрытой вкладке без вас — ни одного
лишнего запроса; планета вернётся, когда вы откроете вкладку или кликнете. Если вы только что (15 с) кликнули на
странице с формами, действия бота на других планетах ждут (до 60 с), а срочное действие сразу сопровождается
возвратом планеты — ваша форма не уйдёт на планету бота.

**Автовход** (вкл.). Если включён, после вылета (игра ответила «сессия завершена», `index.php?code=3`) бот не
останавливается, а встаёт на паузу (главный выключатель остаётся включённым), открывает в своей вкладке страницу входа
и входит сам:

- **Страница входа ogamex.eu.** Форма входа там спрятана в окне «Авторизация», которое открывают кнопки «Войти»;
  кнопка «Войти» в самом окне стоит вне формы, а игра перед входом проверяет пару логин/пароль запросом
  `login_valid.php`. Бот сам открывает это окно (так браузер подставляет сохранённый пароль в видимое поле) и
  отправляет форму так же, как при ручном входе: через проверку `login_valid.php` и затем вход. Верхнюю кнопку
  «Войти» бот как «вход» не нажимает: она только открывает окно (это и была причина неудачи 2026-11-02 12:51).
- **Без сохранённых логина и пароля** бот ждёт до 10 с, пока браузер подставит сохранённый пароль, и нажимает «Вход».
  Chromium **не отдаёт сохранённый пароль странице, пока вы сами не кликнете по ней** (синтетический клик бота не
  считается), поэтому, если поле осталось пустым, сверху страницы входа появляется полоска «OgameX Suite: бот ждёт
  автовхода — кликните в любом месте страницы, дальше он войдёт сам», а заголовок вкладки начинается с «Нужен клик».
  Один ваш клик (или нажатие клавиши) в любом месте страницы — браузер подставляет пароль, бот ждёт ещё ~1,5 с
  и нажимает «Вход». Если клик пароля не открыл, полоска остаётся и бот ждёт следующий клик; после 3 таких кликов
  (браузер пароль не сохранял) он пишет «браузер не подставил пароль — войдите вручную» и больше не пробует до
  следующего вылета. Если вы сами начали **вводить** логин или пароль, бот не вмешивается («вы вводите логин или
  пароль сами»): входите сами, бот продолжит на первой же странице игры. Если вы сами нажали «Вход» (или Enter),
  это считается первой попыткой: бот ~15 с ждёт результата и не нажимает второй раз, а если входа нет — продолжает
  со следующего способа (см. ниже).
- **С сохранёнными логином и паролем** («Автовход: логин» и «Автовход: пароль» во вкладке «Общие») бот сам вписывает их
  в поля формы входа и нажимает «Вход» — клик не нужен. Пароль хранится **только в настройках расширения этого
  браузера** (хранилище расширения, в котором лежат все настройки): он не попадает в журнал (даже его длина), в
  «Выгрузить логи» (ни в шапку с настройками модулей, ни в блок «НАСТРОЙКИ (все, JSON)»), в состояние бота и в
  экспорт/импорт настроек; отправляется он только в форму входа игры. **Логин** — обычная настройка: он есть в шапке
  «Выгрузить логи» и в «Экспорт всего». Данные вписываются только на странице входа той же вселенной, с которой бот
  вылетел (тот же адрес с `https://` и тот же каталог), и форма всегда отправляется методом POST (пароль никогда не
  попадает в адрес страницы). На время входа бот кладёт копию в свою запись о вылете и удаляет её,
  как только вход выполнен или попытки закончились. Поле пароля в настройках скрыто точками, кнопка «показать» —
  посмотреть.
- **Проверка результата и повтор.** После каждого нажатия бот ~15 с ждёт перехода в игру. Если страница входа
  осталась на месте, в журнал («Бот → Журнал», «Выгрузить логи», события `botcore:autologin`) пишется, что именно
  было нажато (тег, id, класс, надпись), появился ли текст ошибки рядом с формой (до 200 знаков), был ли заполнен
  пароль и какой `?code` в адресе — **никаких значений полей**. Затем повтор другим способом: 1-я попытка — клик по
  кнопке самой формы входа, 2-я (через ~20 с) — отправка формы `requestSubmit()`, 3-я (ещё через ~60 с) — Enter в
  поле пароля. Вход, который прошёл без перехода (AJAX), бот распознаёт одним запросом обзора и сам открывает игру.
- **Ответы игры.** `index.php?code=1` после попытки бота («неправильный логин или пароль») — попытки прекращаются,
  в журнале и на странице: «Автовход: игра ответила «неправильный логин или пароль» — проверьте сохранённые данные»;
  `code=2` (сменился IP) — отмечается в журнале, попытка продолжается; `code=3` или без кода — обычный вход.
- **Ограничения.** Не чаще **3 попыток в час** (считаются все попытки, с повторами), только если вход запросил сам бот
  и не позже 30 мин после вылета. Если вы нажали «Выход» сами, бот 30 мин не входит. Капча и отпуск по-прежнему
  останавливают бота. Во вкладке «Бот» строка «Автовход» показывает последнее событие входа.

**Одна очередь на все вкладки.** Все запросы бота идут по одному, в порядке важности: защита → срочное (переработчики
к бою) → флот → стройка → чтение. Слоты флота перечитываются перед каждой отправкой. Одну цель атакует,
перерабатывает или колонизирует только один модуль (второй флот — «дубликат» в журнале). Сейв при угрозе выполняется
всегда. Если подготовленную точную отправку (шаги 1–2 уже сделаны) остановить паузой, «Пробным режимом» или атакой на
планету отправки, шаг 3 не отправляется.

### 8.5. Режим сна

Вкладка «Общие», **выключен** по умолчанию. «Засыпать в» (01:30) и «Просыпаться в» (07:30) — по **серверному**
времени, каждую ночь со случайным сдвигом 40–140 с. «Откладывать сон, пока флоты в полёте» (вкл.). Во сне работает
только защита (сейв); с «Ночным сейвом» (раздел 8.3) бот перед сном увозит флот и возвращает его после пробуждения.
Флот, который вернулся бы во время сна, бот не отправляет (кроме сейва): это проверяется при решении и ещё раз перед
самой отправкой.

### 8.6. Чего бот не сделает никогда

- Ничего не отправит, пока выключен главный выключатель или включён «Пробный режим».
- Не отправит флот без топлива и не потратит «Дейтерий, который бот не тратит».
- Не займёт последний (резервный) слот флота ничем, кроме сейва, отзыва и защиты.
- Не тронет цели в режиме отпуска; фарм атакует **только неактивных** («i»/«I») и никогда — активных игроков.
- Не отправит флот с планеты, на которую летит враждебный флот (кроме сейва).
- Не откроет галактику, пока «Просмотров галактики в час» = 0.
- Не бросит колонию, не удалит постройку, не продаст ресурсы, не потратит тёмную материю.
- Не превысит лимиты в час и не продолжит после разлогина, капчи или незнакомой страницы.
- Не читает пароль из формы входа и не хранит его, если вы сами не вписали его в «Автовход: пароль» (тогда он лежит только
  в настройках расширения этого браузера и уходит только в форму входа игры); никуда, кроме сервера игры, ничего не отправляет.

### 8.7. Бот работает, только пока открыта вкладка с игрой

Фоновой работы без вкладки нет (у расширения нет таких разрешений). Закрыли все вкладки с игрой или браузер — бот
стоит; открыли снова — продолжает с того же места (очередь и таймеры отзыва сохраняются).

- Лучше всего — **закреплённая вкладка с игрой в отдельном окне**.
- Отключите для ogamex.eu «Экономию памяти»: Chrome → Настройки → Производительность → Memory Saver →
  «Всегда оставлять активными эти сайты».
- Фоновые вкладки браузер притормаживает. Бот использует отдельный точный таймер и просыпается при возвращении флотов,
  но для точных отправок (переработчики к бою, сейв) держите вкладку **видимой**. В состоянии бота появится
  предупреждение, если таймер стал неточным.
- Если открыто несколько вкладок, бота ведёт одна (видимая предпочтительнее). Закрыли её — работу подхватывает другая.
- Компьютер ушёл в сон — бот тоже спит. Сейв в это время не сработает.

### 8.8. Известные ограничения и что ещё не проверено вживую

Бот проверен автотестами на модели игры и на 20 сохранённых страницах сервера, но часть страниц сервера мы ещё не
видели. Эти места помечены в коде [UPSTREAM] (взяты из исходного кода 2Moons) и требуют проверки на живом сервере:

- Как выглядят в списке событий **враждебная атака и ракетная атака** (число ракет), а также **непустая очередь
  построек**. До первой настоящей атаки сейв проверен только на модели.
- Тексты сообщений о **переработке**, **экспедициях** и **колонизации**: если они другие, итоги в статистике будут
  «неизвестно» — это будет видно во вкладке модуля и в логах.
- Формула находки ресурсов в экспедиции (min(свободный трюм, стоимость флота)) и доля чёрных дыр — проверим по
  статистике после 20+ настоящих экспедиций.
- Отзыв флота во время передислокации, ёмкость ракетной шахты на этом сервере.
- Цены и трюм кораблей для режима «Ресурсы» взяты из каталога и не сверены с сервером.
- Цель в режиме отпуска сервер сообщает неоднозначным текстом; новая луна у цели видна только после следующего
  просмотра её системы.
- Скорость стройки и исследований сервера бот узнаёт по первому своему заказу; до этого правило «роботы / лаборатория»
  не применяется. Параметры стратегий подобраны для OgameX и здесь приблизительные. Конвейеры 71–73 бот не строит.
- Уже поставленную в очередь точную отправку нельзя отменить до её запуска: если бой отменился в эти секунды,
  переработчики отзываются после отправки.

### Правки независимого аудита (0.3.2, экспедиции)

- Результаты экспедиций больше не теряются: чтение отчёта/возврата через 20 с после события и только после обычного
  (не ajax) запроса к серверу, повторы 30 с × n (до 6 за 15 мин), одно чтение на раунд; экспедиция без сообщения
  закрывается как «без сообщения» и не висит «в полёте» (раньше такая экспедиция навсегда занижала достройку зондов).
- Сообщения сопоставляются с экспедициями по дате по очереди: чужой отчёт соседней экспедиции не присваивается.
- «Сдвиг времени»: возврат переносится по формуле 2Moons (плановый возврат + удержание + 2–5 с), подтверждается по
  странице флота; чтения на плановое время не тратятся.
- Один запрос страницы флота на экспедицию (внутри раунда слоты не перечитываются перед каждым флотом), так же в
  раунде поиска ТМ.
- Режим «Тёмная материя» ниже резерва зондов ничего не отправляет (раньше улетал последний зонд из резерва).
- Достройка зондов учитывает зонды в шпионских полётах и на странице флота.
- Колонизация с пустым списком целей и поиск ТМ без луны не читают страницы при каждом возврате чужого флота
  (одна запись в журнал в 6 ч); новая луна или цель запускает модуль сразу.
- «Отправок флота в час» по умолчанию 300 (было 30; при обновлении значение ≤ 30 поднимается один раз); отказ по
  лимиту — повтор, когда лимит откроется.

### 8.9. Как прислать логи, если бот сделал что-то не то

1. Нажмите **«Стоп»** (или «Пауза»), чтобы бот не продолжал.
2. Панель → **«Бот» → «Журнал»**: найдите запись и посмотрите причину («почему»). Часто этого достаточно, чтобы
   поправить настройку.
3. Нажмите **«Логи для разбора (сегодня)»** во вкладке «Журнал» (или Панель → **«Логи»** → **«Выгрузить логи»**, раздел 6: в этом файле есть ещё и состояние бота, его очередь,
   последние действия и журнал бота). В файле есть каждое решение бота (почему, какие данные,
   какие варианты он сравнивал) и каждое действие с запросом и ответом сервера. Пароли, cookie и токены туда не попадают.
4. Пришлите файл с коротким описанием: что сделал бот, что вы ожидали, примерное время (серверное). Скриншот вкладки
   «Бот» и вкладки модуля тоже помогает.
