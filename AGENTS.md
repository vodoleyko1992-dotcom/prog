# AGENTS.md — для ChatGPT/Codex и других ИИ-агентов

Над этим репозиторием (бот для браузерной игры l2wap.com) параллельно работает Claude. Ниже — общие правила, чтобы не мешать друг другу.

## Сначала прочитай

0. `docs/WORKLOG.md` — **общий журнал работ с Claude**: последние записи читай перед работой, свою запись добавляй в своём PR. Там же строка **«Ведущий»** и общая команда смены режима: «работаем на ГПТ» / «работаем на Клоде» — получив её, обнови строку в своём PR; не ведущий код без прямой просьбы не правит.
1. `docs/HANDOFF.md` — передача дел: правила пользователя, персонажи, решения, открытые темы.
2. `CLAUDE.md` — полный контекст: структура кода, правила игрока, API игры, история версий.
3. `.claude/skills/l2-fix/SKILL.md` — как вносить правки; `kb/README.md` — база знаний об игре.

Пользователь пишет по-русски: отвечай по-русски, просто, по шагам. Комментарии в коде и журнал бота — по-русски.

## Среда и проверки

- Скрипт установки среды: `bash tests/tools/codex-setup.sh` (Playwright + Chromium для смоуков в `~/.local/l2tools`, без sudo; пути — в `~/.local/l2tools/env.sh`; Node-тестам установка не нужна). Для скачивания Chromium сети среды нужен доступ к `cdn.playwright.dev` и `playwright.download.prss.microsoft.com`.
- Тесты: `node tests/run-all.cjs` — все PASS (на 10.0.11 их 218).
- Синтаксис: `for f in *.js modules/*.js; do node --check $f; done`.
- Геттеры модулей: `node tests/tools/envcheck.cjs .` — все `ok`.
- Браузерные смоуки (по желанию, долго): `bash tests/tools/smokes.sh`. `battle-dom-smoke.py` и `v715-mage-dom-browser.py` требуют снимок страниц игры (`L2_PAGES`), которого у тебя нет: без него они падают, это не ошибка кода.

## Правила

- **Ветка по умолчанию — `claude/l2wap-bot-code-review-t45oon`** (не `main`). Работай в своей ветке (например `codex/<тема>`) от неё и открывай PR в неё. В ветки `claude/*` не пушь.
- **Одно место — один исполнитель.** Перед правкой посмотри открытые PR: если файл или раздел бота уже правит Claude (ветка `claude/*`), не трогай его, а скажи пользователю.
- Пользователь разрешил автоматическое слияние PR (14.10.2026): после успешных проверок и при отсутствии конфликтов вливай свою работу в ветку по умолчанию. Не вливай при красных проверках или незавершённом обсуждении.
- **Перед каждым коммитом:** `node tests/run-all.cjs` (все PASS), `node --check` для каждого изменённого js, `node tests/tools/envcheck.cjs .` (геттеры модулей). На каждое исправление — новый тест в `tests/`. Что не проверено — так и напиши.
- **Zip-пакет не собирай без явной просьбы пользователя** («сборка»). Версию в `manifest.json` не поднимай.
- **Живые бои в игре не запускай** и на l2wap.com из облака не ходи без просьбы пользователя (антибот ставит капчу, а у пользователя в это время работает свой бот).
- **Логины, пароли, токены, cookie никогда не печатай** и не клади в код, журнал, тесты, `base-profile.json` или PR. Капчу и антибот бот не обходит.
- **Все решения пользователя** записывай в нужный раздел `docs/HANDOFF.md` в том же PR (с датой).
- **В каждом PR** добавляй запись в `docs/WORKLOG.md`: дата, время с часовым поясом, автор **Codex**, номер/ссылка PR, что сделано и что осталось. До публикации допустима пометка «PR в подготовке»; до слияния замени её фактическим номером.
- Строку **«Ведущий»** в `docs/WORKLOG.md` меняй только по прямой команде пользователя: «работаем на ГПТ» → **Codex**, «работаем на Клоде» → **Claude**. Самостоятельно ведущего не переключай.
