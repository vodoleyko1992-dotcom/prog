# AGENTS.md — для ChatGPT/Codex и других ИИ-агентов

Эта ветка — **OgameX Suite**: расширение Chrome/Firefox + userscript (разделы Live, Infinity и Бот) для браузерной игры
**ogamex.eu, вселенная Aeternum** (движок GALAXYZ 1.8 — форк 2Moons, адреса `game.php?page=…`). Над кодом параллельно
работает Claude. Основной репозиторий — `vodoleyko1992-dotcom/ogamex-suite`, ветка по умолчанию `main`. (Копия есть в ветке
`ogamex` репозитория `prog`, но она больше не основная: в `prog` — бот для l2wap.com, его не трогай.)

## Сначала прочитай

0. `docs/WORKLOG.md` — общий журнал с Claude: последние записи — перед работой, свою — в своём PR. Там строка
   **«Ведущий»**: команды пользователя «работаем на ГПТ» / «работаем на Клоде». Не ведущий код без прямой просьбы не правит.
1. `README-RU.md` — что умеет Suite и как устроены настройки бота; `CHANGELOG.md` — история версий.
2. `specs/` — устройство ядра (`CORE_API.md`, `SUITE.md`, `DIAG.md`), страницы GALAXYZ (`specs/galaxyz/`), бот (`specs/bot/`).

Пользователь (John) пишет по-русски: отвечай по-русски, просто, по шагам.

## Устройство

- Исходники: `shared/` (ядро, фон, popup), `ogamex-live/`, `ogamex-infinity/`, `ogamex-bot/modules/` (модули бота).
- `ogamex-suite/` — само расширение; копии `ogamex-suite/shared` и `ogamex-suite/modules` генерирует `tests/sync.sh`.
  **Правь исходники, а не копии.**
- `fixtures/` и `specs/galaxyz/fixtures/` — сохранённые страницы игры и макеты для тестов.

## Среда и проверки

- Установка среды: `bash tools/codex-setup.sh` (Playwright + Chromium; Node нужен 20+).
- Все тесты: `node tests/run-all.js` (все PASS). Только GALAXYZ: `node tests/run-all.js gz`.
- На каждое исправление — новый тест в `tests/`. Что не проверено — так и напиши.

## Правила

- Работай в своей ветке `codex/<тема>` от `main`, PR — в `main`. В ветки `claude/*` не пушь.
- **Одно место — один исполнитель.** Перед правкой посмотри открытые PR: если модуль уже правит Claude, не трогай его.
- **Сборку (ZIP, `package.sh`) не делай без явной просьбы пользователя.** Версию в `ogamex-suite/manifest.json` не поднимай.
- На ogamex.eu из облака не ходи и бота против живого сервера не запускай.
- **Логины, пароли, токены, cookie никогда не печатай** и не клади в код, тесты, фикстуры или PR. Репозиторий может стать публичным:
  новые сохранённые страницы игры перед коммитом очищай от сессий/токенов.
- Капчу и антибот бот не обходит.
- В каждом PR добавь запись в `docs/WORKLOG.md`: дата, время (UTC+10), автор **Codex**, номер PR, что сделано и что осталось.

## Правила игрока для бота (не нарушать)

- Все функции бота по умолчанию ВКЛ (автономность); выключены только спящий режим и «не сейвить при слабой атаке».
- Перевозки, рейды, сейвы — **только боевыми транспортёрами**; нет их — пропустить и записать в журнал. Обломки — боевыми переработчиками.
- Застройка: лаборатория ≥ 22, верфь ≥ 14; хранилища — минимум 2 ч производства (лучше 3–4 ч), приоритет хранилищу только если полно или дешевле следующей шахты.
- Темп: 5000 действий/час по умолчанию, пауза между запросами 0,3–0,6 с; шпионских зондов — 1100.
