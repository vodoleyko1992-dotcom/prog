# L2wap Bot v5.6.4 — этап 2: боевые откаты и расходы

Основа: v5.6.3-stage1. Режимы, справочники, пользовательские данные и существующие ключи хранилища сохранены.

## Исправлено

1. **Общий серверный КД:** выделен независимый модуль `battle-cooldown.js`. Отказ `blockedBy: global` с `globalCooldownUntilMs`/`globalRemainingMs` больше не записывает ошибочный индивидуальный откат навыка. Все действия боевого цикла ожидают окончание общего КД, включая зелья. На смене боя память модуля сбрасывается. Существующая обработка индивидуальных навыков сохранена.
2. **Боевые прогнозы РБ:** положительный прогноз победы не выдаётся до накопления как минимум 15 с, пяти замеров и измеримого уменьшения HP босса (0,1%). При явно неэффективном уроне по эпику по-прежнему срабатывает аварийное решение.
3. **Бюджет телепортов на эпиков:** новые необязательные настройки `epicCoinDailyMax` (Coin of Luck) и `epicAdenaDailyMax` (адены), **0 — без лимита**. Считаются попытки платного телепорта со страницы эпиков в скользящем окне 24 часа; резерв выполняется до нажатия, поэтому расход может быть завышен после ошибки сервера. При включённом лимите и неизвестной цене автоматический переход отменяется. Для обычных локаций лимит не действует.
4. **Запас лечебных банок перед эпиком:** новый необязательный порог `epicMinHpPots` (0 — не проверять); учитываются доступные банки HP сверх резерва. Если известного запаса недостаточно, платный переход не выполняется.
5. **Безопасность принудительной атаки:** запасная атака после 10 с бездействия больше не инициируется при известном КД.

## Совместимость

- Новые настройки по умолчанию равны **0**, поэтому старые финансовые/складские ограничения не меняются без явного включения.
- Состояние и настройки по персонажам сохраняют прежний формат.
- Действует защита одной активной вкладки, введённая в v5.6.3.

## Проверки

- `node --check` для всех JS (включая тесты).
- `node tests/stage1.test.js` — блокировки вкладок, сохранение состояния, API и отступление.
- `node tests/stage2.test.js` — ответы API с `blockedBy: global`, индивидуальные КД, смена боя, лимиты валют, отсутствие цены, совместимость с интерфейсом.
- `unzip -t` для итогового ZIP.

**Ограничения:** нет живых испытаний в Firefox/игре; снижение доли HTTP 400 и прирост DPS пока не измерены. Бюджеты фиксируют попытки, а не подтверждённые платежи; маршруты через обычный телепорт не входят в ограничения.
